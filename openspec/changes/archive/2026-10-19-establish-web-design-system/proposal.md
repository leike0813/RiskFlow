## Why

`apps/web` 的令牌、外壳及页面样式尚未统一，风险配色与操作错误容易混用；既有图表与基础组件也缺少统一的消费约束。按修订后的 UI 重做主规格，先完成 CH-1 的设计系统与组件层，给后续导航和业务域 change 提供可运行、可验证的生产接缝，而不是直接提升一次性原型。

## What Changes

- 将选定的 v2 令牌迁入生产 `theme/tokens.css`，以生产文件唯一提供运行值；固定字号/行高、间距、动效、焦点、风险等级与独立操作错误语义。左导航 152px／48px、右停靠区 22rem 作为后续壳层的目标尺寸令牌，不在本 change 提前切换导航结构。
- 引入精确版本的 Ant Design 并在唯一生产宿主接入中文与受控主题；限定用于表单、表格、选择器、日期和对话框等既定强项，不建立第二套业务组件导出层或确认状态机。
- 风险徽章与图表共用受控等级配色，沿已授权记录的精确配置、等级顺序和名称渲染；复用已有动态矩阵与 ChartSurface，清除实际调用链中的固定维度及字面量等级推断，不重算 P/C、分带或风险等级。
- 保留七态、EvidenceDrawer 脱敏语义、既有确认控制器及请求身份；至少通过现有生产页面消费新主题和组件，避免只交付无人使用的目录。
- 删除确定无生产消费者的空壳或过时图表实现；所有受影响调用方与行为测试同时迁移。既有业务页按需收拢，不在 CH-1 全量重写。
- 通过真实浏览器检查键盘、焦点、缩放、错误反馈及历史矩阵显示；记录真实构建分包和依赖/许可证检查，不用原型截图或源码文本断言代替运行证据。

## Capabilities

### New Capabilities

- `web/design-system`：生产令牌、AntD 使用边界、风险与错误色语义、配置驱动图表、共享组件及可访问性的消费契约。

### Modified Capabilities

无。本 change 落实现有壳层、确认、历史矩阵和权限约束，不改变其领域或导航要求。`platform/web-shell-interaction-primitives` 的六导航、区域块组合与新停靠结构由 CH-2 delta 承担；既有四个 `web/*` capability 不拆分、不整份替换。

## Impact

- 代码所有权：仅 `apps/web` 的主题、共享呈现、图表及其实际页面消费者，必要的根依赖政策/锁文件与既有验收接缝；精确文件与符号在 implementation-plan 中固定。
- 新运行依赖：计划精确固定 `antd@6.6.6`（MIT），兼容现有 React 19。业务源码不直接依赖或导入 `@ant-design/icons`；AntD 自身的传递依赖如实登记，不承诺锁文件零 icons。日期库只有真实直接使用时才显式登记，版本、许可证、离线方式和退出条件由 design 固定。
- 无后端接口、领域 Schema、权限、事务、审计或迁移变更；HTTP/SSE、原记录版本与人工决定均不改变。
- RI/RA：横切 RI-S1～RI-S6、RA-S1～RA-S7 的可读性与可追溯呈现，矩阵重点覆盖 RA-S3～RA-S6；不声称本 change 重新验证模型效果或甲方业务配置正确性。
- 明确排除：六导航/新停靠区的正式启用、路由迁移、待办/搜索/仪表盘聚合、处置状态机、移动端、暗色切换、桌面原生能力、原型代码迁入、C38 或整体验收结论。
- 规划基线：`88dce423806dfc34585803ec3f727f8d0d0550cb`。输入为当前已修订的 `.scratch/riskflow-master-plan/prototypes/ui-redesign-spec.md` 与 `design-system-spec.md`；其尚未提交状态不授权提交或覆盖现有改动。采用 `orchestrated-delivery`，只闭合 apply 前置，不提前创建 verification。
