## MODIFIED Requirements

### Requirement: 空、加载、异常、权限四类骨架行为必须逐页一致

各页面 MUST 引用 `platform/web-shell-interaction-primitives` 的区域组合与七态契约，列表 A、详情 B、运行 C、复核 E 作为单区域特例，不再限制为单值骨架。加载时占位不得闪烁为空态；空态只给已登记真实下一步；异常显示安全摘要与可用重试；无权限不得泄露运行数量、标识或对象存在性。`NOT_FOUND` 与 `AUTHENTICATION_REQUIRED` MUST 保留原目标可见性及会话语义。复核入口迁移不得改变五类决定、识别候选分支、历史精确读取、证据与授权所有权。（RI-S61～RI-S65）

#### Scenario: 无权访问识别页面
- **WHEN** 不具备识别读能力的角色打开识别运行列表页
- **THEN** 呈现权限骨架与所需能力提示，页面不显示任何运行数量或标识线索

#### Scenario: 查询失败可重试
- **WHEN** 只读查询因瞬时故障失败
- **THEN** 页面显示结构化错误摘要与重试入口，重试重新发起同一查询，不显示堆栈或内部标识

#### Scenario: UI-S01 公共接缝不撤旧复核
- **WHEN** 新待办与统一覆盖层尚未交付
- **THEN** 原复核队列、两类精确详情及其原类型化决定仍可用；不因取消最终导航位置而删原读取和命令
