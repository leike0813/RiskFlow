## 4. 调用与副作用顺序

schema/冻结策略 → C11授权/版本 → 幂等查询 → C04受权原字节 → 有界源预检 → 独立服务预算/任务 → 原始响应C04写入/回读 → 协议/结构/质量规范化 → 共用JSON-LD与成功诊断C04 → C11原子段集合 → 转换记录/审计。任一步失败沿原finishFailure，不登记部分段；取消只清理当前任务。原成功幂等返回引用；不自动重新提交失败远端任务。
