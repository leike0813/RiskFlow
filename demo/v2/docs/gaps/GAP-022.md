# GAP-022 评估记录入口类别与 contracts kind 字段语义冲突

- 类别：G2 契约字段
- 相关页面：P-RA-04、P-RA-05、P-RA-07

## 缺口

评估记录入口类别与 contracts kind 字段语义冲突

## 依据

packages/contracts/src/records/index.ts:171-225（kind 是风险输入判别字段 standardized-risk-record|external-risk-event）；packages/contracts/src/workflows/index.ts:125-142（入口模式 entryMode 只在准备快照，取值 assess/reassess/historical-backfill）

## 预设

页面（P-RA-04/05/07）以产生记录的评估运行 entryMode 展示入口类别；fixture 沿用契约 kind 判别字段，不新增存储字段，entryMode 仅为投影层派生展示。

## 待确认

C34 是否在查询投影（projection.query）中固化 entryMode 派生字段，避免消费方各自回联运行。

## 风险

投影层口径问题；消费方各自回联可能漂移。
