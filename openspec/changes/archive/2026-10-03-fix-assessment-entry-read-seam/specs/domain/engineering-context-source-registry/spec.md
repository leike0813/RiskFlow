## MODIFIED Requirements

### Requirement: 登记、修订与查询遵守授权幂等和原子审计边界

系统 MUST 在任何目标存在性读取、业务写入或正文读取前调用 C06 `verify` 校验精确工程数据分支、工程、空间和资料授权。仅将 C25 当前来源授权引用定位为来源版本的委托窄读 MUST 复验其原 `risk-assessment.read` 分支和原调用身份，结果只限当前已验证授权范围。每个写能力 MUST 使用 C03 `(projectId, commandKind, idempotencyKey)` 和 strict 载荷摘要；同键同载荷返回原结果，同键异载荷失败。业务事实、当前指针、C07/C03 只追加审计、命令收据和适用 Outbox 事件 MUST 在一个本地事务提交；事件仅含精确引用，不含正文。（RI-S14）

#### Scenario: 重放相同来源交付

- **WHEN** 调用方以相同工程、命令类型、幂等键和相同冻结载荷重试来源交付
- **THEN** 系统返回首次创建的来源交付与资料版本引用
- **AND** 不重复创建资料项、资料 ID、授权绑定、审计或事件

#### Scenario: 同键不同载荷冲突

- **WHEN** 调用方复用已完成幂等键但改变工件、元数据、资料项、工程或空间引用
- **THEN** 系统返回不可重试的幂等冲突
- **AND** 原登记事实和引用保持不变

#### Scenario: 未授权与不存在不可区分

- **WHEN** 无当前工程/空间/资料授权的调用方请求存在或不存在的上下文、资料版本或资料段
- **THEN** 两种情况返回同一外部授权拒绝类别
- **AND** 不产生业务事实或泄露存在性和正文

#### Scenario: 审计或 Outbox 失败整体回滚

- **WHEN** 业务事实、命令收据、审计或必要 Outbox 任一步无法写入
- **THEN** 整个命令事务回滚且不返回业务成功
- **AND** 原命令身份可以安全重试

#### Scenario: 来源授权定位只复用原当前读取身份

- **WHEN** C25 将当前已验证来源授权委托给 C11 定位来源版本
- **THEN** C11 在定位前复验原 queryId 与 risk-assessment.read 分支，不以新的未配对身份或客户端授权声明代替 C06 验证
- **AND** 定位只返回该当前范围的就绪来源引用，不披露正文或产生业务写入

## ADDED Requirements

### Requirement: 评估候选目录必须按登记事实区分输入作用域

系统 MUST 以只读方式列出 C11 已登记评估候选。适用性目录 MUST 按工程、精确工程修订和精确空间筛选；外部事件目录 MUST 按工程和精确空间筛选，不要求或推断未登记的工程修订。每页最多 50 项，且不得产生评估准备、查询结果、业务审计或 Outbox 写入。（RA-S1；RI-S14）

#### Scenario: 两类目录采用各自事实范围
- **WHEN** 当前获授权调用方选择精确空间读取适用性或外部事件目录
- **THEN** 适用性条目匹配提交的精确工程修订，外部事件条目匹配已登记空间和来源版本
- **AND** 不返回正文或拼造工程修订事实

#### Scenario: 候选预览保持零业务写入
- **WHEN** 调用方重复读取目录首页及后续页
- **THEN** 返回已有候选引用且业务事实、查询结果、业务审计和 Outbox 数量不增加

### Requirement: 评估候选目录分页必须稳定有界且绑定当前授权

系统 MUST 使用不超过 512 字符的不透明游标，绑定目录类型、工程、精确筛选及当前授权摘要。每次目录读取 MUST 复验当前授权；单页事实读取规模不得随页码增长。分页 MUST 按登记时间降序、稳定实体标识及版本升序推进，合法长标识不得破坏游标上限。无权、错作用域、伪游标或不可解析锚点 MUST 同形拒绝；损坏登记事实 MUST 类型化失败，不得作为空页隐藏。（RA-S1；RI-S14）

#### Scenario: 深页与同时间条目稳定推进
- **WHEN** 目录超过 50 项且多项登记时间相同，翻页期间新增排序在已消费条目前的登记
- **THEN** 每页最多返回所请求页大小，原有未消费条目稳定推进且不重复已消费条目
- **AND** 数据库单页返回规模保持固定上界

#### Scenario: 长标识与新运行时恢复
- **WHEN** 合法工程或空间标识很长，调用方在新运行时使用同一数据库的下一游标
- **THEN** 游标仍满足 512 字符契约且恢复正确后续页

#### Scenario: 错目录错筛选与撤权拒绝
- **WHEN** 游标用于其它目录、工程、空间、适用性工程修订或授权范围，或当前权限已撤销
- **THEN** 返回不可枚举的授权拒绝，不披露条目或目标存在性

#### Scenario: 登记事实损坏失败关闭
- **WHEN** 页内已登记引用或目录摘要不满足其公共 Schema
- **THEN** 返回类型化技术失败，不丢弃该项后报告成功或伪空结果
