## MODIFIED Requirements

### Requirement: 识别与复核页面必须只经既有 HTTP 面取得业务事实

识别与复核页面 MUST 由 `apps/web` 生产构建交付，只经所属闭合 HTTP 查询/命令取得当前工程的登记事实；API 接入层唯一负责信封、公共 Schema 解码、安全错误与取消，不得使用原型静态数据或页面自拼传输。识别工作区 MUST 保持识别任务、风险记录、关联图谱、工序模型四个二级入口及六条规范地址，视觉与状态沿 `web/design-system`、`platform/web-shell-interaction-primitives`。本包不新增识别启动、重试、取消或治理写入口，不以假按钮宣称能力。既有复核队列、两类精确详情和类型化决定 MUST 保留原所有者、确认、权限及历史读取；待办/覆盖层与六导航组合尚未就绪时不得撤掉它们。（RI-S1～RI-S6）

#### Scenario: 页面渲染当前工程的真实事实
- **WHEN** 获授权用户打开识别或复核任一页面
- **THEN** 页面内容由当前工程上下文的真实查询结果驱动，刷新后按服务端事实和指定精确版本重建，不出现静态样例残留

#### Scenario: 假写入口不存在
- **WHEN** 用户浏览识别工作区与保留的复核入口
- **THEN** 未接线的识别启动、重试、取消和治理操作不作为可用按钮出现；既有复核决定仍走原统一确认和真实命令

#### Scenario: ID-S01 本域入口不要求其它域权限交集
- **WHEN** 用户具有识别读取权但没有知识治理、投影、Agent 或复核中的某项读取权
- **THEN** 已授权识别列表和正文仍可使用；需其它来源的独立区域按其真实授权呈现，不以整页失败、假零或新增权限替代

### Requirement: 识别运行列表与详情必须呈现真实运行事实

识别任务列表 MUST 经 `risk-identification.run-list` 有界分页呈现运行引用、状态、中文阶段、启动者、启动时间、验收/待复核/拒收计数；触发原因仅在登记时存在才显示。用户 MUST 能实际读取后续页，而非只看到有更多数据的说明。详情 MUST 按指定精确运行状态引用直接读取，不依赖列表首页；带版本地址保持同一历史状态快照、不轮询，可显式进入同运行的最新进展。无版本地址 MUST 经所属域窄读同运行最新获权状态，非终态刷新有界且单在途，不写回版本使监控冻在首帧。详情保留头部辅助引用、I0～I9、工序工作项、合并组与验收路由、关联 Agent/复核及结果引用。终态、隐藏、离开或上下文失效停止实时刷新，迟到响应不得覆盖新目标。Agent 失败保留错误码与可重试性，不给跳过、换模型或扩预算入口；已成立事实计数不回退。（RI-S5～RI-S6）

#### Scenario: 列表分页与详情联动
- **WHEN** 用户翻阅运行列表的后续页并打开某条任务
- **THEN** 列表使用服务端游标且单页不超过 50，链接携精确运行版本，详情与刷新均读取同一对象，不在首页查找

#### Scenario: 等待复核如实呈现
- **WHEN** 运行因候选待人工复核而暂停
- **THEN** 详情呈现等待复核与原任务引用，不把暂停伪装为完成或失败；已成立结果仍可读

#### Scenario: Agent 失败无跳过入口
- **WHEN** 运行内必经 Agent 任务以可重试失败终止
- **THEN** 页面呈现失败阶段、错误码与可重试性，不存在跳过、换模型或扩预算按钮

#### Scenario: ID-S02 历史运行直达与单在途刷新
- **WHEN** 用户直达页外历史状态版本，或在无版本地址实时跟踪慢于刷新间隔的非终态任务后切工程、隐藏页面或进入终态
- **THEN** 历史状态保持不变且不轮询；实时跟踪按同一runId重新读取新状态版本而非重复旧快照，不叠加在途请求，旧响应被清理，终态停止

### Requirement: 风险记录列表与详情必须呈现识别侧记录事实

风险记录列表 MUST 经 `risk-identification.record-catalog` 有界分页，呈现记录引用、工序节点、风险事件摘要、综合置信度、验收方式和当前效力，支持工序节点及验收方式筛选；筛选变化清空旧游标，当前页统计不得冒充工程总量。详情 MUST 经 `risk-identification.record-read` 直接读取精确版本，不从目录首页找对象；无版本旧地址经所属授权窄解析，给定版本不变。正文保留七字段（工序节点标识、风险源、风险因素、风险事件、风险要素关系、证据定位信息、模型置信度）、记录信封（版本、机理、来源、识别运行、综合置信度及其形成依据、验收决定）及真实取代/作废关系。`modelConfidence` 只读，人工修正记录并列保留原模型置信度与人工修正标记。正文和 `tab=trace` 同属该风险精确引用，状态独立；正文 MUST NOT 混入评估等级、P/C、预警或处置正文，允许以精确链接穿透已成立事实，不编造缺席内容。（RI-S5～RI-S6）

#### Scenario: 记录详情呈现精确版本正文
- **WHEN** 用户打开目录后续页中的风险记录或直接刷新其历史版本 URL
- **THEN** 七字段、信封、置信度和证据来自同一精确版本，不混入最新版本或其它记录，不以列表页是否包含目标决定存在性

#### Scenario: 评估域内容缺席不编造
- **WHEN** 审查风险记录正文和追溯入口
- **THEN** 正文不显示评估等级徽章、P/C 或处置正文；追溯只链接已成立的精确事实，未成立链尾如实缺席

#### Scenario: ID-S03 筛选与续页保持业务范围
- **WHEN** 用户按工序节点或验收方式筛选并续页，再改变筛选或工程
- **THEN** 请求使用当前筛选及所属游标，切换时重新从首屏读取，不保留旧页条目或把当前页条数称作全工程总数

### Requirement: 关联图页必须只呈现可证明的投影边

关联图页 MUST 经原 `projection.query` 的 `association-graph` 与 `projection.result-read` 读取工序、机理、风险及已成立后续关系的精确链边，提供获权主体选择、节点聚焦、分类图例、精确深链与键盘可访问的节点/边浏览。读取和分页 MUST 保持原上限，不全库展开。图谱不再内嵌按工序分组的第二份风险记录列表；图失败时 MUST 显示真实原因及去同工程规范风险列表的入口，不把列表称作成功图谱。主体不可见、边集合越界或来源资格不能证明时失败闭合，不裁切成伪完整图、不编造边，也不为补图写事实。（RI-S6）

#### Scenario: 可证明关联正常呈现
- **WHEN** 获权用户选定具有可证明链边的精确主体
- **THEN** 图及可访问节点/边浏览只呈现所属查询的正式结果，可下钻同一精确风险记录和机理引用

#### Scenario: 不可证明时失败闭合
- **WHEN** 主体无可证明链边、查询越界、技术故障或授权不足
- **THEN** 分别呈现原结构化失败/空/权限状态和合法风险列表入口，不呈现伪完整图或重复记录列表

### Requirement: 证据追溯页必须呈现固定追溯链并可穿透

证据追溯 MUST 在风险记录详情的 `tab=trace` 中由该记录精确引用发起原 `projection.query` 的 `trace-chain`，再经 `projection.result-read` 有界读取，保持资料段 → 工序节点 → 机理条目 → 风险记录 → 已成立的评估 → 预警 → 建议 → 偏差/校准链；链节点可按授权精确穿透，资料段入口复用证据抽屉与定位/脱敏两态，链尾缺席只按原结果说明。正文成功不等于追溯成功，追溯失败不得抹掉获权正文。旧 `/review-audit/trace` 与已知 `/review/trace` MUST 永久作为解析入口：`subject` 只表示风险记录 ID，有 `version` 时保持该版本，无版本时所属域按当前权限窄解析并替换为 `/identification/records/:recordId?version=:version&tab=trace`；无 subject 到同工程风险列表。有 subject 但无权、不存在、错版或不能定位时 MUST 同形拒绝，不扫描目录首页、不选任意当前对象。迁移保留工程、修订与评估来源选择器；追溯查询始终由当前风险精确引用登记，不接受 URL 注入其它查询结果来替换主体。旧页面正文实现 MUST 与规范详情同版移除。（RI-S6；RA-S5～RA-S7）

#### Scenario: 沿链穿透到详情
- **WHEN** 用户在风险详情追溯位置读取多页链边并点击机理条目
- **THEN** 全部页属于同一精确风险与原查询，机理条目跳其精确治理引用；结果不在首页仍可读取

#### Scenario: 无权限节点只显定位摘要
- **WHEN** 链中资料段没有正文访问授权但可披露定位摘要
- **THEN** 只显示获准资料段及目录定位和脱敏说明，不取正文或从其它路径补齐

#### Scenario: ID-S04 旧追溯永久精确解析
- **WHEN** 用户打开两种已知旧追溯地址，风险对象不在目录首页，且 URL 带工程/修订及可选版本
- **THEN** 所属授权窄解析到同一风险精确版本，在同一详情追溯承载重建；地址 replace 无循环，已有精确版本不改成最新，不消费未约定的 URL 查询结果引用

#### Scenario: ID-S05 无主体与不可披露目标分开处理
- **WHEN** 旧入口没有 subject，或给定主体无权、不存在、错版、引用矛盾
- **THEN** 仅前者进入同工程风险列表；后者同形拒绝且不透露对象或其它工程存在性，不降为列表首条

#### Scenario: ID-S06 追溯独立状态与上下文清理
- **WHEN** 风险正文成功而追溯无权/失败，或者读取时用户切工程、版本或注销
- **THEN** 正文保持其独立合法状态，追溯显示真实拒绝/可重试失败；上下文变化清除旧内容，迟到结果不能复活

### Requirement: 跨页深链必须使用领域标识

页面跳转 MUST 使用所属领域引用：任务列表 → 精确任务详情，风险列表/图谱/追溯 → 精确风险详情，风险详情 → 精确识别任务、工序模型节点定位、机理、证据和本记录 `tab=trace`。风险和任务规范地址保留 `/identification/records/:recordId`、`/identification/runs/:runId`；版本作为明确查询参数，工程/修订/来源选择器不丢。只有已取得精确模型发布时才携其版本，节点入口不能冒充原识别的冻结模型证明。所有生产内部 trace 调用方 MUST 同版迁至规范风险详情，只保留外部旧地址解析；不得以私有页面状态搬运事实、手输技术 ID 或任意默认对象代替业务选择。已知别名继续沿 shell 精确模板边界，未知路径拒绝，复核队列及历史精确详情本包不切换。（RI-S6）

#### Scenario: 参数化深链可直达
- **WHEN** 用户直接打开携精确任务或风险引用的 URL 并刷新
- **THEN** 按该引用查询，目标不在目录首页仍正常；无权或不存在保持同形安全状态

#### Scenario: ID-S07 调用方原子迁移不撤复核
- **WHEN** 从风险、图谱、复核相关入口或浏览器历史打开追溯
- **THEN** 新内部链接指向规范精确详情，旧外部地址仍解析；原复核队列与类型化决定仍可用，不提前启用待办、覆盖层或六导航

### Requirement: 浏览器验收必须使用真实浏览器与正式接缝

系统 MUST 在真实 Chromium、`apps/web` 生产构建、正式 HTTP/授权/投影、真实 PostgreSQL/迁移与 Cookie 登录上验收识别工作区和保留的复核能力。覆盖六条规范地址、两种旧 trace 入口、当前权限、后续页与页外历史精确目标、筛选、正文/追溯独立状态、证据脱敏、图谱失败、复核决定真实提交及幂等、工程切换及迟到响应。桌面三种窗口 1280×720、1440×900、1920×1080 各 100%/200% 原生缩放 MUST 保持本域操作、页签、错误和焦点可达；二维图表/表格局部滚动，正文折行。记录实际浏览器版本、命令、场景与失败 trace，质量/验收材料保留合成样本待甲方复核标注。环境或关键分支未运行不得用原型、Mock、非空截图或 skip 计通过。（RI-S61～RI-S65）

#### Scenario: 真实浏览器完成识别与复核链路
- **WHEN** 测试环境登记了合法识别/复核、页外历史版本、模型与追溯事实
- **THEN** 登录后贯通任务/风险列表与详情、工序模型、图谱、详情内追溯和原复核队列/决定，结果可由真实服务端事实核验

#### Scenario: 环境不可用明确失败
- **WHEN** 必需浏览器、数据库、HTTP 服务或缩放环境不可用
- **THEN** 对应命令非零失败或明确阻塞并保存证据，不把跳过关键场景计作通过

#### Scenario: ID-S08 键盘与原生缩放可操作
- **WHEN** 在三种受支持桌面窗口与两种原生缩放下使用键盘浏览本域列表、详情、页签与二维内容
- **THEN** 操作、错误、分页与焦点均可到达且不遮挡，左右栏可收起，不靠 CSS zoom 或隐藏内容冒充完成

## ADDED Requirements

### Requirement: ID-R1 识别工作区必须使用单一业务标题与只读工序模型

本域路由标题与唯一主标题 MUST 来自同一业务名称，二级导航统一为识别任务、风险记录、关联图谱、工序模型。列表首列使用已有业务摘要或中文阶段与时间组合，不从技术 ID 猜名称，不编造服务端未给的任务名称；编号/精确版本保留辅助复制。工序模型业务视图 MUST 只读呈现所选精确发布版本的节点、输入输出、装备/构件、状态参数、监测指标、依赖和五项最小工序覆盖，版本/节点定位在刷新后保持。无显式模型选择时可使用所属当前发布集合；已有选择缺项、错版或无权不得换另一个模型，显式版本读取不依赖当前集合成功。必含工序种类由既有单一领域词表引用，不把最小覆盖集写成封闭全集；不新增发布/修订按钮，不伪造工程使用关系或版本历史。（RI-S3）

#### Scenario: ID-S09 所选历史模型与节点保持
- **WHEN** 用户携合法精确模型发布和节点进入历史模型，而当前模型已发布新版本
- **THEN** 读取并呈现所选版本与其真实节点/依赖，不替换为当前发布，不以当前模型冒充原识别冻结依据

#### Scenario: ID-S10 用语与模型权限如实呈现
- **WHEN** 用户浏览识别工作区，或没有显式模型选择且当前发布读取无权/技术失败
- **THEN** 合法识别正文不受影响，模型区域保留真实原因；主标题和首列业务化，编号辅助可复制，不泄露其它域对象或出现假治理操作
