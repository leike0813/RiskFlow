# 确定模型、检索与规则质量评测策略

## Question

## Answer

用户已完成对 [模型、检索与规则质量评测策略——待复核推荐记录](../prototypes/model-retrieval-rule-evaluation.md) 中 22 个 HITL 决策问题的集中复核，全部确认推荐方案，不作修改。

确认的策略包括：按能力分别设质量门槛；开发集、冻结评测包和甲方验收包三层隔离；按来源家族防止数据泄漏；覆盖 MVP 实际路径与专利最小集合；解析、知识、检索、标准化风险记录、规则适配、P/C、预警、处置和五类 Agent 任务分别评测；结构、权限、证据、确定性计算与安全约束采用硬门槛；语义链路三次运行并报告波动；高风险全检与分层抽样；LoRA 仅在完整基线稳定失败且满足收益、隔离和可回退条件时准入；质量评测由统一深层模块编排并复用正式业务接口。

本票不新增 Wayfinder 决策前置项；后续“确定 MVP 测试、验收与交付证据”票据引用本评测策略，具体实现由后续 OpenSpec change 承接。
