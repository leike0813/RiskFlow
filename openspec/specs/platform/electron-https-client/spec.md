# platform/electron-https-client Specification

## Purpose

为 RiskFlow 提供加载甲方内网 HTTPS 页面的小型 Electron 桌面客户端，使桌面与浏览器共用完整 Web 业务界面、身份授权和正式 API，同时明确本机能力、连接失败、版本发布及多平台验收的边界，不建立第二套业务事实或本机推理系统。

## Requirements

### Requirement: 桌面与浏览器必须共用完整 Web 业务界面

系统 MUST 由 `apps/web` 唯一提供 C32–C35 的完整业务界面和 C36 质量页面，Electron MUST 加载应用服务器批准的同一 HTTPS 入口。桌面与电脑浏览器 MUST 使用相同的正式 HTTP/SSE、工程上下文、权限、版本追溯和人工确认行为。桌面不得复制业务页面、运行本机领域服务或绕过正式业务命令；Web 业务界面 MUST 能独立于 Electron 运行。（横切 RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 两种入口访问同一业务对象

- **WHEN** 获授权用户分别通过桌面与电脑浏览器打开同一工程和精确对象深链
- **THEN** 两种入口读取相同正式事实与版本，均按当前服务端权限执行，页面不依赖 Electron 专有能力才能完成基础业务

#### Scenario: 原型数据或页面遗漏

- **WHEN** 生产构建缺少已交付业务路由，或页面依赖原型 fixture、审阅注入和静态业务数据
- **THEN** 发布验收失败，不以原型截图、独立 demo 构建或桌面外壳启动证明完整业务界面已交付

### Requirement: 桌面运行必须限制导航与本机能力

客户端 MUST 从受控部署配置读取唯一业务 HTTPS origin，验证协议、目标与用途；普通页面不得重定向到任意 origin、新建任意窗口或调用通用本机能力。业务渲染 MUST 关闭 Node 集成并开启上下文隔离、沙箱及生产内容安全策略。本机能力如被提供，MUST 使用有界具体接口并验证调用来源、参数与当前操作，不暴露通用 IPC、Shell、数据库、模型凭据或任意文件访问；文件选择和下载不得免除服务端授权。

#### Scenario: 越界导航或本机调用

- **WHEN** 页面尝试打开未批准目标、其它协议、新窗口或超出声明范围的本机调用
- **THEN** 客户端拒绝该动作，不使目标页面获得桌面权限，不执行任意代码或文件操作

#### Scenario: 基础上传与下载

- **WHEN** 当前获授权用户选择本地文件或下载正式报告工件
- **THEN** 业务通过既有上传/工件读取契约完成，下载保存位置由用户选择，不通过任意 URL 绕过资料或工件权限

### Requirement: 证书与会话必须沿用安全 HTTPS 边界

客户端 MUST 校验服务器证书与目标身份，私有 CA 通过受控系统信任配置接入，禁止因内网环境关闭 TLS 验证。页面、API 与 SSE MUST 保持同源，Cookie 由专用客户端会话容器管理且不暴露给页面脚本或桌面日志。客户端不得包含服务器秘密，不以安装客户端身份替代登录或工程授权；注销、会话失效和撤权 MUST 遵循既有服务端语义。

#### Scenario: 有效证书与真实登录

- **WHEN** 客户端连接已配置且受信任的业务 origin 并由用户登录
- **THEN** 页面使用真实服务端会话完成同源请求与订阅，桌面和普通浏览器的会话彼此独立

#### Scenario: 证书失败或权限撤销

- **WHEN** 证书不受信任、过期、目标不匹配，或已登录用户的权限被撤销
- **THEN** 前者拒绝业务加载且不降级至 HTTP，后者由服务端拒绝后续访问，不恢复旧权限或接受未经核验的目标

### Requirement: 连接恢复不得重启任务或自动提交写命令

客户端 MUST 在服务器不可达时提供安全连接状态和显式重试入口，不显示旧业务数据为当前正式结果。恢复后 MUST 重新核验会话并沿既有订阅游标和刷新预算读取结果；未知受理状态的命令不得因连接恢复自动重新提交。窗口关闭 MUST 只结束客户端连接，不取消已受理后台任务；业务取消仍须通过正式命令。客户端不维护本地业务事实库或离线写入同步队列。

#### Scenario: 首次连接失败与恢复

- **WHEN** 客户端启动时服务器不可达，随后用户重试连接
- **THEN** 先显示连接状态，再按正常登录/会话边界进入业务界面，不制造本地成功结果

#### Scenario: 窗口关闭后任务继续

- **WHEN** 服务端已受理任务后用户关闭并重新打开客户端
- **THEN** 原任务继续遵守服务端版本、预算与生命周期，新会话按权限读取同一任务，不因窗口重开启动第二个任务

#### Scenario: 命令响应丢失与订阅重连

- **WHEN** 写命令响应丢失或 SSE 断开后连接恢复
- **THEN** 订阅按既有游标恢复；写命令只能按既有确认与原身份重试语义显式处理，不自动复制、改载荷或重新确认
