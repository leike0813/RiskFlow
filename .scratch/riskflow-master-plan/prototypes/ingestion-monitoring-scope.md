# RiskFlow 工程资料与监测数据接入范围

> 状态：Wayfinder 已确认的规划基线；本文不是 OpenSpec 正式规格。

## 1. 范围结论

RiskFlow 使用一套接入模块处理文件、数据库、API 和监测流。不同来源的适配器只负责取得数据及其来源信息；进入系统后，全部数据统一形成不可变工程资料版本或监测批次，再经过解析、资料段登记、Agent 主导清洗和结构校验，成为识别或评估可以冻结引用的输入。

LangGraph 不在运行中直接查询外部系统。每次运行只读取已经登记、具有精确版本和证据定位的输入。

## 2. 输入支持层级

任何“支持某种输入”的声明必须注明以下层级：

1. **登记支持**：保存原件或冻结载荷、元数据、来源、权限和不可变版本。
2. **解析支持**：在登记基础上完成结构保留转换、JSON-LD 输出和资料段登记。
3. **业务可用**：在解析基础上通过系统硬约束，并由 Agent 判定质量足以进入识别或评估运行。

较高层级包含较低层级。允许上传或只保存原件不能笼统称为“已支持自动处理”。

## 3. MVP 输入范围

| 输入 | MVP 层级 | 处理范围 |
|---|---|---|
| DOCX | 业务可用 | 标题层级、正文、表格、图片说明与章节证据定位 |
| 文本型 PDF | 业务可用 | 页码、文本块、表格、图注与章节结构 |
| 扫描型 PDF | 业务可用 | OCR、版面结构、页码、表格与图注 |
| PNG/JPEG 扫描件 | 业务可用 | OCR、版面结构与图像来源定位 |
| XLSX/CSV | 业务可用 | 表头、工作表/数据集、结构化行及批量监测时序 |
| DWG/DXF | 登记支持 | 原件、元数据、权限和版本；不做自动 CAD 标注提取 |
| 数据库/API/实时监测流 | 不提供 MVP 入口 | 不建设空连接器或占位适配器 |

MVP 通过界面完成文件与批量监测导入。日常业务不依赖命令行、直接改库或开发人员手工搬运。

## 4. 完整产品输入范围

完整产品将以下输入提升到业务可用：

| 输入族 | 格式或来源 | 结构保留要求 |
|---|---|---|
| Word | DOC、DOCX | 标题层级、正文、表格、图片说明；旧版 DOC 允许受控转换 |
| PDF | 文本型与扫描型 PDF | 页码、文本块、表格、图注、OCR 与版面结构 |
| 表格 | XLS、XLSX、CSV | 工作表、表头、单元格/结构化行；旧版 XLS 允许受控转换 |
| 演示文稿 | PPT、PPTX | 幻灯片顺序、文本、表格、图片与备注；旧版 PPT 允许受控转换 |
| 扫描图像 | PNG、JPEG、TIFF | OCR、版面结构、表格和图像定位 |
| CAD | DWG、DXF | 图例、标注文本、技术参数、布局/图层与关联对象 |
| 数据库 | 受控只读查询 | 查询条件、游标/水位、结果集和查询版本形成不可变快照 |
| HTTP API | 拉取与接收推送 | 请求/事件来源、分页/游标、载荷和接口版本 |
| 实时监测流 | 持续输入 | 按时间或数量窗口形成不可变监测批次 |

旧版 Office 转换必须保留原件、转换工具及版本、转换参数和转换结果。其它格式在出现真实业务输入前保持登记支持，不预建专用解析分支。

## 5. 统一接入接口

接入模块对外只提供用例级能力：登记来源版本、启动处理、读取处理结果、重处理失败范围和冻结运行输入。文件、数据库、API 与监测适配器位于同一接入缝隙后面，不向风险识别或风险评估暴露各自细节。

每次接入至少登记：

- 工程资料项或监测序列身份；
- 工程、空间区段及来源单位；
- 资料类型、形成时间、工点位置、区间里程和版本信息；
- 文件哈希，或数据库查询/API 游标/流窗口等来源指纹；
- 提供方、系统录入人、接入方式和时间戳；
- 权限、转换/解析配置及其版本；
- 原始内容或可离线复核的冻结载荷。

每次上传、外部快照、重新解析或重处理均创建新的工程资料版本和资料ID。工程资料项保持稳定，用于归集这些版本；旧版本不得覆盖。

## 6. 结构化输出与资料段

所有解析器输出 JSON-LD，至少包含元数据、文本块列表和证据片段列表，并按来源类型增加表格字段、监测字段或工法步骤字段。长文本语义分块不超过 512 字符，相邻块保留前后指针。

资料段标识始终采用 `资料ID-章节ID-资料段ID`。不同来源按以下语义生成章节和资料段：

| 来源 | 章节单元 | 资料段单元 |
|---|---|---|
| Word | 标题章节或表格 | 语义块、表格区域、图片说明 |
| PDF/扫描件 | 章节、页或表格 | 语义块、表格区域、图注 |
| PPT/PPTX | 幻灯片或主题组 | 文本块、表格、图片/备注区域 |
| XLS/XLSX/CSV | 工作表、命名表或数据集 | 表格区域或稳定行组 |
| CAD | 布局、图层或图号 | 标注/参数及其关联对象组 |
| 数据库/API | 冻结查询或数据集 | 稳定记录或分页记录组 |
| 监测数据 | 批次或时间窗口 | 监测对象、指标与时间段样本组 |

证据定位最终指向资料段，并保留页码、单元格、图层、记录键或采样时间等来源内定位信息。

## 7. Agent 主导的数据清洗

数据清洗是必须执行的 Agent 任务，通过统一的 Agent 任务模块运行。任务创建时冻结授权上下文、任务策略、模型与提示模板、工具白名单、资源预算、清洗增量 Schema 和校验器版本；固定算法只是该任务可以调用的领域工具，包括格式归一、去重、时间对齐、单位换算、异常/缺失检测、短期斜率、加速度、频域主峰和异常评分计算等。MVP 不向任务暴露通用文件系统、Shell、任意数据库或自由网络工具。

Agent 可以：

- 选择、组合和重复调用清洗工具；
- 在授权上下文已经提供的原始内容范围内判断固定算法结果并继续处理；
- 修正字段或指标映射、处理异常和缺失、生成监测摘要；
- 判断最终结果是否达到业务可用质量；
- 允许部分资料段先进入业务运行，并记录排除范围和覆盖判断。

Agent 只能返回类型化清洗增量，例如字段映射修订、样本处置、监测摘要、资料段排除和覆盖判断；接入模块应用增量并拥有最终工程资料事实，不接受通用 JSON Patch 或整对象覆盖。不建立“自动清洗决定”领域对象，也不设置独立的确定性质量门槛或人工生效审批。结构、字段类型、资料段标识、引用可达性和审计完整性仍由独立确定性校验器校验；这些硬约束不替 Agent 判断数据质量。

校验器只可把可修复的结构或引用问题返回同一任务，在冻结预算内执行有界修复；权限越界、来源冲突和不可修复的领域约束不得通过循环绕过。Agent 清洗自动产出不可变、版本化结果。每次处理保留可重建输入、原始模型输出、Agent/模型/提示模板版本、使用的工具与版本、调用参数、输入输出引用、前后差异、质量判断、排除资料段、依据证据和预算消耗；不保存模型内部思维链。人工可以事后复查，但不是结果生效的前置步骤。

## 8. 部分可用与失败处理

工程资料版本允许资料段级别的部分可用：

- 结构硬约束通过且被 Agent 判定可用的资料段可以进入识别或评估；
- 失败或被排除的资料段隔离，并保存结构化失败原因和原始定位；
- 工程资料版本明确显示部分可用及排除范围；
- Agent 判断剩余覆盖是否足以继续运行，并保存依据；
- 无可用资料段时处理结果失败，不生成空业务输入。

失败处理必须从字段、实体、关系或资料段回溯到原始资料。Agent 任务失败时只能在已冻结策略与硬预算内幂等重试，不得跳过清洗、切换模型或退回固定算法基线冒充业务可用结果；预算耗尽后记录可重试失败或终止失败，并保留上游事实。选择失败资料段、更换转换/解析/Agent/工具版本或修正元数据后重处理，创建新任务并生成新的工程资料版本、新资料ID和新资料段集合。旧版本及引用它的历史运行保持不变。

## 9. 监测数据契约

### 9.1 三层事实

- **监测序列**：同一工程中某监测对象与指标的稳定归组身份。
- **监测批次**：一次 XLSX/CSV 导入、数据库/API 交付或流窗口形成的不可变样本集合。
- **监测快照**：一次识别、评估、预警或处置效果比较冻结的确定时间窗口及其清洗结果和衍生特征。

完全重复采样按来源标识或序列、采样时间及载荷指纹幂等处理。同一采样时间出现不同数值时，新批次通过更正关系指向旧批次；迟到数据形成历史补录批次，并可产生历史补算原因。任何情况都不覆盖旧采样。

### 9.2 指标范围

接入和 Agent 清洗管线保持指标无关，通过版本化配置映射地表沉降、支护结构变形、地下水位、泥水压力、注浆压力和盾构姿态参数六类专利监测指标。

MVP 验收只强制至少一条“地表沉降”监测序列完整跑通清洗、短期斜率/加速度/异常评分、风险评估、预警和处置反馈。甲方样例中的其它指标可以接入，但不构成 MVP 完成前提。

频域主峰仍是 RI-S2 监测预处理必须产出的时序特征；未用于某次评分时也要保留在监测摘要中。

## 10. 权限与审计

- 工程资料版本冻结当次资料权限，资料段和包含原文的解析/清洗结果继承该权限。
- 多来源派生内容不得扩大任一来源的可见范围；无原件权限的用户只能看到允许披露的证据定位摘要。
- 外部连接的技术配置由系统管理员维护，工程及业务用途由工程风险管理员确认。
- Agent 任务创建时校验一次发起者权限，运行中依靠冻结上下文和工具白名单限制可见与可执行范围；任务随后准备的正式领域命令仍走该命令自身的常规权限校验。
- Agent、Worker 和模型服务在工程授权与完全私有部署范围内处理数据，不把内容发送到公网 SaaS。
- 接入、处理、重试、部分可用、重处理、权限变化和运行引用均写入审计日志。

## 11. 运行冻结与重放

识别或评估启动前生成输入清单，固定：

- 工程与空间区段修订；
- 工程资料版本、包含和排除的资料段；
- 监测快照与相关批次；
- 转换、解析、Agent 任务策略、模型、提示模板、工具白名单、资源预算、增量 Schema 和校验器版本；
- 清洗结果、质量判断和证据引用。

后续来源更新、迟到数据或重处理不能改变已开始的运行。它们只产生新版本和新的待识别、待重新评估或历史补算原因。

## 12. 专利与后续票据接口

- RI-S1：统一覆盖文件上传、数据库和 API 接入、元数据、资料段与权限登记。
- RI-S2：统一覆盖结构保留转换、JSON-LD、OCR、CAD 标注、监测预处理、语义分块、逐项校验和失败回溯。
- RA-S1：统一覆盖工程资料、风险事件、监测量测数据和适用性元数据绑定，监测快照提供斜率、加速度和异常评分。

“核实 TypeScript 私有化数据与检索组件”据此研究不可变业务数据、对象文件、时序与索引组合；“核实 TypeScript 文档解析与前端工程依赖”据此研究具体解析与转换工具；“确定外部系统、实时监测与 MCP 集成契约”细化数据库、API、监测流和 MCP 适配器；“定义 Agent-native 横切运行与治理契约”统一任务状态、工具、预算、增量、校验和审计。后续票据不得缩减本票已确认的 MVP 业务可用格式。
