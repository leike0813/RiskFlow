# risk-assessment/engine Specification

## Purpose
提供从正式风险输入和冻结评估依据到指标实际取值、P/C、风险等级、四类触发及不可变评估记录的确定性能力，保证边界精确、失败闭合、结果可重放且全链路可审计。（RA-S1～RA-S6）

## Requirements

### Requirement: 风险输入与评估准备快照保持正式 XOR 和来源完整

系统 MUST 只接受公共风险输入联合中的一种身份：精确标准化风险记录引用或受控外部风险事件引用；两者必须二选一且仅一个。评估准备命令 MUST 显式提供入口模式、触发原因及可选前次记录/因果运行，并可显式提供调用方已逐序列冻结的非空监测快照引用集合；系统 MUST 校验输入所属工程、工程修订、获准空间和资料可见范围，并把命令字段原样连同适用性元数据快照、来源证据、授权和审计冻结为不可变准备快照。系统不得从风险类型、时间或调用上下文推导或默认入口语义，不得自行选择监测序列/截止点或补造监测快照，也不得复制或修改识别事实正文。（RA-S1）

#### Scenario: 标准化风险记录形成准备快照
- **WHEN** 调用方提交一个可见的精确标准化风险记录版本，并提供同工程的工程修订、空间、适用性元数据和来源证据
- **THEN** 系统返回只含该风险记录分支的精确评估准备快照引用
- **AND** 快照保留全部输入版本、证据、授权和三时态关联

#### Scenario: 受控外部风险事件形成准备快照
- **WHEN** 调用方提交一个已在正式风险输入提供者中登记且可见的外部风险事件版本
- **THEN** 系统返回只含该外部事件分支的精确评估准备快照引用
- **AND** 不建立生产 seed 接口或把测试 fixture 作为事实源

#### Scenario: 正式外部事件事实不可用时失败闭合
- **WHEN** 外部风险事件未登记、正式 reader 不可用或调用方无权读取其精确版本
- **THEN** 系统返回类型化不存在、契约或权限失败
- **AND** 不回退到测试 fixture、内存事实源、标准化风险记录分支或临时登记

#### Scenario: XOR 或作用域不合法时拒绝准备
- **WHEN** 风险输入缺少两个身份、同时含有两个身份、引用未登记，或输入与工程、修订、空间、适用性或权限不一致
- **THEN** 系统返回类型化校验、权限或陈旧版本失败
- **AND** 不保存准备快照、审计成功事实或事务事件

#### Scenario: 入口语义由命令原样冻结
- **WHEN** 调用方显式提交入口模式、触发原因及可选前次评估记录与因果运行
- **THEN** 准备快照中的对应字段与命令逐项一致，未提供的可选字段保持省略
- **AND** 缺少必填入口模式或触发原因时公共 Schema 闭合拒绝且不产生副作用

#### Scenario: 监测快照集合由调用方显式冻结
- **WHEN** 调用方提供一个或多个已通过 C14 按精确序列、策略和截止点冻结的监测快照引用
- **THEN** 准备快照原样保存规范去重后的非空引用集合并逐项校验工程、空间和授权
- **AND** 未提供集合表示本次评估不使用监测输入，空数组、重复、错工程或不可见引用被闭合拒绝

### Requirement: 评估输入快照只由完整且相容的正式版本组成

系统 MUST 使用精确评估准备快照和 C19 `AssessmentBasisReleaseSetRefV1` 组装公共 `AssessmentInputSnapshotV1`。指标体系、字段映射、适用规则集、权重、评分策略、风险矩阵、风险可接受阈值、监测预警阈值、联合触发、措施库、效果预测与偏差策略 MUST 来自相容的 C18/C19 已发布集合；预警归集、通知、处置生成、处置校验、处置 Agent、校准 Agent、重试、复核、模型和提示模板引用 MUST 来自运行时注入的正式策略提供者。系统 MUST 逐项校验发布状态、工程、业务时点、兼容身份和权限；C25 不得定义、默认或内联后续策略。（RA-S2～RA-S4）

#### Scenario: 完整版本集合形成公共输入快照
- **WHEN** 评估依据解析和正式策略提供者返回公共 Schema 要求的全部精确已发布引用，且它们与准备快照属于同工程并在目标时点相容
- **THEN** 系统原子保存一个完整 `AssessmentInputSnapshotV1` 并返回其精确引用
- **AND** 快照逐项保留来源所有者与版本，不按“最新版”重新解析

#### Scenario: 任一版本缺失时失败闭合
- **WHEN** 任一 C18/C19 成员或注入策略引用缺失、未发布、停用、越权、跨工程、超出业务时点或兼容身份不一致
- **THEN** 系统返回类型化失败或公共等待结果
- **AND** 不生成部分快照、不写默认引用、不改变确定性计算规则

#### Scenario: 重评与历史补算不覆写旧快照
- **WHEN** 调用方以新监测、适用性、规则、权重、策略或矩阵版本发起重评，或以明确业务时点发起历史补算
- **THEN** 系统创建新的完整输入快照并关联前次评估或历史时点
- **AND** 旧快照及其评估记录保持不可变，监测集合变化只通过前置契约定义的复数精确引用事件表达

### Requirement: 指标实际取值使用唯一映射和精确单位

系统 MUST 对适用规则集要求的每个可能性与后果指标，按冻结字段映射从正式风险输入事实或精确 C14 监测快照集合读取值；监测输入只读取各快照中的规范值、短期斜率、加速度、主频或异常评分，不读取最新流数据。系统 MUST 先由 C18 field mapping、监测阈值和联合规则确定所需 `monitoringIndicator + parameterCode` 集合，再通过 C14 正式序列 reader 以精确 series ref 核对每个序列的指标、参数、规范单位和版本，并证明每个所需序列恰有一个冻结快照。metric=`value` MUST 使用快照在 cutoff 网格点的 available/interpolated 规范值，末点缺失时不得退回较早值；feature metric MUST 使用同快照对应的 available feature。每个指标 MUST 恰好解析一个有效来源，按配置的 identity 或 affine 规则转换到指标规范单位，并保存原始来源引用、映射版本、实际值和证据。缺失所需序列快照、重复序列快照、序列身份/规范单位不一致、cutoff 值缺失、重复映射、无效类型、不可转换单位、不可用特征或证据缺失 MUST 使整次评估失败。（RA-S1、RA-S4、RA-S5）

#### Scenario: 文档与监测值共同形成完整取值集
- **WHEN** 所有适用指标都能从正式风险输入或显式冻结监测快照集合按唯一映射取得可转换值，且所有配置要求的监测序列均恰好有一个快照
- **THEN** 系统生成一个不可变指标实际取值集并逐项关联来源、单位、映射和证据
- **AND** 后续评分只消费该取值集，不再次读取源事实

#### Scenario: 单位冲突不产生部分评分
- **WHEN** 任一数值指标的来源单位与映射声明不符或无法精确转换为规范单位
- **THEN** 系统返回类型化单位冲突失败
- **AND** 不保存部分指标结果、P/C、风险等级或正式评估记录

#### Scenario: 缺值或映射歧义不被忽略
- **WHEN** 任一适用指标没有值、命中多个未闭合来源、引用不可用特征，或缺少合格证据
- **THEN** 系统返回类型化输入不完整失败并指出稳定指标身份
- **AND** 不以零、均值、旧值或模型推断补齐

#### Scenario: 所需监测序列覆盖不完整时失败
- **WHEN** C18 映射或阈值需要的任一监测指标与参数没有精确快照，或同一指标与参数对应多个快照
- **THEN** 系统返回类型化监测快照覆盖失败并指出稳定序列身份
- **AND** 不自行选择序列、读取最新快照或产生部分评估等级

#### Scenario: 序列身份或 cutoff 值不合法时失败
- **WHEN** C14 正式 reader 返回的指标、参数或规范单位与 C18 映射不一致，或快照 cutoff 网格点为 missing
- **THEN** 系统返回类型化序列/单位/缺值失败
- **AND** 不从 series entityId 猜语义、不退回较早值、不做隐式单位换算

### Requirement: 结构化规则与权重确定性计算 P/C

系统 MUST 仅消费 C19 已发布适用规则集中的结构化评分规则，并复用 C19 同时供冲突检测与评分使用的规范边界求值事实源，按每个指标的量化阈值、分级区间和例外条款确定恰好一个基础分；C25 不得重写开闭边界比较。grade interval MUST 遵循 C19 的左闭右开、无下界为负无穷、无上界为正无穷、连续无重叠无空洞语义，scoring threshold/between MUST 遵循 C19 已归档 spec 与纯 helper 的唯一闭合语义。随后系统 MUST 按 C18 评分策略分别聚合发生可能性 P 与后果严重性 C。加权平均 MUST 使用基点权重、规范十进制运算和配置声明的 half-away-from-zero 精度；maximum MUST 取对应轴的最大基础分。输入数组顺序、运行次数、主机浮点表示或 Agent 可用性不得改变结果。（RA-S2～RA-S5）

#### Scenario: 加权平均在舍入边界精确收口
- **WHEN** 某一 P 或 C 轴使用加权平均，且未舍入结果恰好位于正数或负数半单位边界
- **THEN** 系统按冻结小数位和 half-away-from-zero 规则得到唯一规范结果
- **AND** 权重总计、逐项基础分与加权贡献均可由记录证据重建

#### Scenario: maximum 与输入顺序无关
- **WHEN** 某一轴使用 maximum 且调用方以不同顺序提供相同完整取值与规则集合
- **THEN** 系统返回相同轴分值
- **AND** 每项 `weightedScore` 等于其 `baseScore`，不读取权重、置信度或数组首项作为替代

#### Scenario: 规则覆盖不完整时不产生 P/C
- **WHEN** 任一适用指标未命中恰好一个闭合评分区间，规则版本与取值集不相容，或仍存在未决冲突
- **THEN** 系统返回类型化规则失败
- **AND** 不保存部分 P、部分 C 或后续风险等级

#### Scenario: 规则端点与无穷边界复用 C19 语义
- **WHEN** 指标值位于 C19 规范区间的下端点、非末上端点、无下界区间或无上界区间
- **THEN** C25 使用 C19 同一纯 helper 得到与规则校验及冲突检测一致的唯一 score/grade
- **AND** 不在 C25 维护第二套开闭边界或对越界值夹取

### Requirement: 风险矩阵覆盖全配置空间并精确处理边界

系统 MUST 复用 C18 的规范十进制矩阵映射语义，以 P、C 在连续有序分带中的位置选择唯一矩阵单元。所有非末分带 MUST 左闭右开，末分带 MUST 两端闭合；共享边界只能归入一个单元。P 或 C 超出配置范围、矩阵单元缺失或矩阵版本不相容 MUST 失败，不得夹取、外推或采用默认等级。（RA-S5）

#### Scenario: 共享边界只进入后一分带
- **WHEN** P 或 C 精确等于相邻非末分带共享边界
- **THEN** 系统把该值映射到后一分带并选择唯一矩阵单元
- **AND** 相同规范十进制输入在重复运行中得到相同风险等级

#### Scenario: 末分带上界可映射
- **WHEN** P 或 C 精确等于对应轴末分带上界且另一轴也在范围内
- **THEN** 系统使用末分带的闭合上界完成映射

#### Scenario: 越界不产生风险等级
- **WHEN** P 或 C 低于首分带下界、高于末分带上界或找不到完整矩阵单元
- **THEN** 系统返回类型化矩阵失败
- **AND** 不保存评估记录或部分等级

### Requirement: 四类触发由冻结配置独立且可组合判定

系统 MUST 针对完整评估结果确定性判定四类公共触发：风险等级超过适用的风险可接受阈值、监测原始值阈值越限、趋势/加速度/异常评分等冻结特征阈值越限，以及多指标联合规则命中。风险等级比较 MUST 使用冻结矩阵等级序；单阈值 MUST 使用配置的 `gt`、`gte`、`lt`、`lte` 或 `outside` 精确边界；联合规则 MUST 只组合其引用的单阈值命中事实并执行 `all-of`、`any-of` 或 `at-least`。每个命中 MUST 保留触发类型、指标或规则身份、实际值和证据；未命中可产生空集合。（RA-S6）

#### Scenario: 四类触发可以同时命中
- **WHEN** 同一完整评估同时超过风险可接受等级、命中原始监测阈值、命中特征阈值且满足联合规则
- **THEN** 系统保留四类独立触发事实并去除同一规则的重复命中
- **AND** 任何一类都不能覆盖或吞并其它类别

#### Scenario: 比较运算符边界精确
- **WHEN** 实际值精确等于单边阈值或 `outside` 区间边界
- **THEN** `gte`/`lte` 按包含边界判定，`gt`/`lt` 按排除边界判定，`outside` 仅在闭区间之外命中

#### Scenario: 不满足触发时保留无预警评估
- **WHEN** 风险等级未超过适用阈值且所有监测、特征和联合规则均未命中
- **THEN** 系统保存触发集合为空的完整评估记录
- **AND** 不创建预警记录、处置任务或 Agent 任务

#### Scenario: 阈值适用性不唯一时失败
- **WHEN** 风险可接受阈值或联合规则按冻结适用性元数据无法解析为闭合、唯一且相容的集合
- **THEN** 系统返回类型化配置失败
- **AND** 不猜测优先级或选择输入数组首项

### Requirement: 评估记录、决策工件、审计和事件原子成立

系统 MUST 在所有指标、P/C、矩阵与触发判定全部成功后，原子保存不可变指标实际取值集、评估决策工件、公共 `RiskAssessmentRecord`、只追加审计、命令回执与 `assessment.recorded.v1` Outbox 事件。记录 MUST 保留风险输入 XOR、适用性元数据值、逐指标结果、P/C、风险等级、触发指标、证据、适用规则集、权重和矩阵精确版本；事件只携带公共精确引用及评估运行引用，不复制正文。没有合法评估运行引用时 MUST 失败闭合。（RA-S5、RA-S6）

#### Scenario: 完整评估一次提交
- **WHEN** 确定性评估全部成功且授权上下文或准备快照提供相同的合法评估运行引用
- **THEN** 指标集、决策工件、评估记录、审计、回执和待发布事件在同一业务事务中成立
- **AND** 下游只能在记录可靠入库后消费事件

#### Scenario: 任一原子成员失败时整体回滚
- **WHEN** 记录、审计、回执或 Outbox 任一写入失败
- **THEN** 整个业务提交失败或回滚
- **AND** 不留下可被下游视为正式结果的孤立指标集、决策或记录

#### Scenario: 触发事实不越权创建预警
- **WHEN** C25 评估记录含一个或多个触发事实并发布评估已记录事件
- **THEN** C26 可以凭精确记录引用幂等创建预警、处置任务和通知意图
- **AND** C25 不直接写入 C26 所拥有的预警记录或通知状态

### Requirement: 幂等、并发与重放只由冻结输入决定

系统 MUST 以工程、命令种类、业务幂等键和规范输入摘要收口准备与评估。相同键同载荷重试 MUST 返回原引用且不重复写入；同键异载荷 MUST 返回幂等冲突。对同一完整输入快照的重复评估 MUST 得到字节级等价的指标、P/C、矩阵与触发决策内容；审计记录时间等事务元数据不得参与业务结果身份。版本或适用性变化 MUST 创建新快照和新记录，不覆盖历史事实。（RA-S1～RA-S6）

#### Scenario: 相同冻结输入精确重放
- **WHEN** 调用方在不同进程或时间以同一输入快照重新执行评估
- **THEN** 系统返回同一逻辑结果引用，且决策内容摘要完全相同
- **AND** 不读取当前最新版配置、监测数据或策略

#### Scenario: 同键不同载荷冲突
- **WHEN** 调用方复用已完成命令的幂等键但改变风险输入、快照、依据或业务时点
- **THEN** 系统返回不可重试的幂等冲突
- **AND** 原快照、记录、审计和事件保持不变

#### Scenario: 并发重复只产生一份事实
- **WHEN** 两个调用并发评估同一工程、输入快照和幂等身份
- **THEN** 数据库约束与事务使两者观察同一逻辑结果
- **AND** 不重复产生记录、审计或 Outbox 事件

### Requirement: 权限与错误边界不泄露受限事实

系统 MUST 在读取风险输入、适用性、监测快照、评估依据和后续策略前校验工程、空间、资料授权及 `risk-assessment.prepare` 或 `risk-assessment.evaluate` 能力，并在提交前复验引用仍有效。错误 MUST 使用闭合代码、稳定原因和精确诊断引用表达校验、缺值、单位、规则、版本、权限、幂等、暂时或终止失败；不得复制风险正文、监测序列、配置正文、凭据或数据库内部信息。

#### Scenario: 跨工程或越空间评估被拒绝
- **WHEN** 任一输入引用所属工程或空间超出冻结授权范围
- **THEN** 系统返回不可重试的权限失败
- **AND** 不暴露目标是否存在或其正文，不产生任何业务副作用

#### Scenario: 提交前引用变为无效
- **WHEN** 读取后、事务提交前任一要求仍有效的引用被停用或判定不兼容
- **THEN** 系统返回陈旧版本或业务阻断失败
- **AND** 不以已缓存正文完成提交

### Requirement: 确定性评估计算链不得创建 Agent 任务

指标取值、结构化规则匹配、P/C 聚合、矩阵映射、四类触发、Schema 校验、持久化和重放 MUST 全部由确定性领域模块完成。正式策略提供者只提供精确已发布引用，不得调用 Agent 生成、补全、选择或复审评估值；Agent 失败、不可用或预算状态不得成为评估计算前置条件。

#### Scenario: Agent 运行时不可用仍可完成完整评估
- **WHEN** 所有冻结事实与正式策略引用齐全，但 Agent 运行时不可用
- **THEN** 系统仍能得到相同指标、P/C、风险等级、触发与评估记录
- **AND** 不创建 Agent 任务或使用模型输出补值

#### Scenario: 缺失事实不能用 Agent 降级
- **WHEN** 任一指标值、规则、单位或正式策略引用缺失
- **THEN** 系统按对应类型化原因失败闭合
- **AND** 不调用 Agent 猜测或把基线结果冒充正式结果

### Requirement: 早期纵向验收使用正式契约与测试夹具

系统 MUST 提供不进入生产写接口的验收 fixture，以公共标准化风险记录 Schema、正式 `RiskInputVersionRefV1`、真实 PostgreSQL 事实存储和已发布配置引用验证“风险记录 → 准备/输入快照 → 指标取值 → P/C → 矩阵 → 触发事实 → `assessment.recorded.v1` → 审计”链路。fixture MUST 标明适用性、规则与配置版本；它不得成为生产 seed API、内存事实源、默认配置或 MVP 完成替代证据。（RA-S1～RA-S6）

#### Scenario: 正式标准化风险记录 fixture 跑通纵向链
- **WHEN** 验收环境加载一条合法标准化风险记录、完整已发布依据、精确策略引用和覆盖配置所需序列的边界监测快照集合
- **THEN** 系统通过生产端口与 PostgreSQL 生成可重放评估记录、事务事件和审计证据
- **AND** 所有 P/C、矩阵和触发结果可由固定输入独立重算

#### Scenario: fixture 不可通过生产接口注入
- **WHEN** 生产调用方尝试使用测试 fixture 路由、内存仓储或未发布配置启动评估
- **THEN** 系统拒绝该路径或不存在该生产入口
- **AND** 只有正式领域接口和持久化事实可产生正式评估记录

### Requirement: C25 加法式证明已成立实际评估结果

系统 MUST 由 C25 所有者提供独立、strict 的精确评估记录只读证明：请求只携带工程、`RiskAssessmentRecordRefV1`、请求时间与当前版本化授权；成功只返回该记录精确引用、风险输入、空间、冻结评估依据、所用监测快照、偏差策略、校准 Agent 策略及所属运行的精确引用。读取 MUST 在披露前复验当前主体、工程、空间和资料权限，并核对持久记录正文与索引身份、摘要和引用一致；不得提供 latest、列表、跨工程扫描或完整评估正文。现有评估写命令、输入快照窄读和公共结果签名保持不变。（RA-S1、RA-S5、RA-S7）

#### Scenario: 精确实际评估返回最小证明
- **WHEN** 获授权调用方用同工程已成立的实际评估记录精确版本请求证明
- **THEN** C25 返回足以与执行、执行后监测和冻结依据逐项对账的最小精确引用投影
- **AND** 不重评估、不改写历史记录或复制指标正文

#### Scenario: 无权、缺失或内容不一致时失败关闭
- **WHEN** 记录不存在、越权、版本失效，或持久记录与其索引引用/摘要不一致
- **THEN** C25 返回安全的类型化失败，不披露目标存在性或正文
- **AND** 不以调用方提供的评估值、基线记录或最新版本补足证明

### Requirement: 预测风险状态使用冻结评分依据进行纯计算

评估模块 MUST 为正式处置预测提供受权、精确版本的风险状态计算能力，以建议追溯的基线实际指标和原适用规则、权重、评分策略、矩阵为依据，仅将明确声明的预测指标替换为合法预测值后重新计算 P/C 与风险等级。该计算 MUST 复用正式评估的确定性算法，不改变基线实际指标、记录、准备或输入快照，不保存新的实际评估、预警或业务事件。（RA-S3～RA-S5、RA-S7）

#### Scenario: 预测值改变风险状态并可重放
- **WHEN** 模型提供同单位、受支持目标指标的预测值，其余基线指标和冻结依据完整
- **THEN** 系统按原规则、权重和矩阵计算预测风险状态，相同输入重放得到相同 P/C 和风险等级
- **AND** 预测值跨越原评分边界时，风险状态按相同确定性口径变化

#### Scenario: 依据或指标不相容时拒绝
- **WHEN** 基线、建议、工程、精确评估依据、指标、单位或预测值不相容，或原依据无法按当前权限完整读取
- **THEN** 系统返回类型化失败，不返回部分计算、不沿用基线风险状态冒充预测

#### Scenario: 计算不产生正式实际事实
- **WHEN** 调用方重复执行预测风险状态计算
- **THEN** 实际评估记录、指标取值登记、准备快照、预警、命令成功收据及 Outbox 数量不增加
- **AND** 必需的 C04 受权工件读取审计按其原契约保留
