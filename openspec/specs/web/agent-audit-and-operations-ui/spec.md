# web/agent-audit-and-operations-ui Specification

## Purpose
为 RiskFlow 提供使用真实版本化事实的 Agent、复核审计、报告与最小系统管理界面，复用 v2 prototype 的布局和交互，并与既有工程、识别、评估及处置页面连通，使任务执行、人工决定和导出结果可授权、可解释、可追溯。

## Requirements

### Requirement: C35 页面必须复用 v2 设计并保持既有应用接线

系统 MUST 在 `apps/web` 生产应用中复用 v2 的 Agent、复核审计、报告及系统管理页面分区、视觉层级和键盘交互，使用真实服务端事实和七态骨架。七项业务导航 MUST 保持原顺序；Agent 和系统管理只能从辅助入口进入。页面 MUST NOT 将原型 fixture、角色/状态注入、契约镜像、假回答或假操作作为交付能力。（横切 RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 已接通页面与 v2 分区一致
- **WHEN** 用户打开 C35 Agent、复核详情、审计、报告或系统管理页面
- **THEN** 页面保持 v2 对应设计的主分区和操作位置，事实来自正式 HTTP 接缝，现有 C32–C34 深链仍可达

#### Scenario: 刷新切换与服务异常
- **WHEN** 用户刷新精确版本深链、切换工程，或读取失败/无权/端口未接入
- **THEN** 页面先恢复真实会话和工程上下文，再显示该引用或对应七态，迟到响应不覆盖新上下文，不用静态事实填充
### Requirement: Agent 三种视图必须共享同一任务及有界刷新

停靠栏、全屏工作台和任务详情 MUST 共享当前工程内的精确任务选择，呈现发起者、父运行、冻结输入与策略引用、任务状态、工具行动、已用/已预留资源及上限、候选增量/逐项校验、提案和正式结果引用。刷新 MUST 单在途且有固定间隔，隐藏、卸载或终态时停止；切换视图不重新启动任务，切换工程或注销立即清除任务、提案和证据。（RI-S1、RI-S4～RI-S6；RA-S6～RA-S7）

#### Scenario: 停靠与全屏共享任务
- **WHEN** 用户从一个任务的停靠栏展开全屏并打开任务详情
- **THEN** 三个视图指向同一任务版本、预算台账和候选结果，最多存在一个该任务的刷新请求

#### Scenario: 预算或确定性拒绝
- **WHEN** 任务预算耗尽、授权撤销或候选被确定性拒绝
- **THEN** 界面呈现安全原因、校验及预算事实，不显示跳过、换模型、扩预算或强制接受操作

### Requirement: Agent 操作必须使用真实类型化入口与提案确认

系统 MUST 只为已登记且当前可执行的任务定义提供启动、恢复、取消或交互确认入口；启动需绑定服务端提供的完整冻结上下文与策略，禁止自由文本到任意业务命令的隐式转换。写入前 MUST 展示工程、对象、精确版本、效果和副作用；交互确认 MUST 绑定当前提案版本。拒绝或关闭确认不得执行提案。会话展示 MUST 来自任务/动作的安全摘要，不创建第二套聊天事实，不展示原始模型响应或思维链。

#### Scenario: 启动入口如实反映定义支持
- **WHEN** 页面没有已登记输入上下文或定义只支持内嵌模式
- **THEN** 不提供将该定义作为交互任务启动的按钮，仍可读取已有获准任务

#### Scenario: 确认与重放
- **WHEN** 用户确认当前交互提案并重试同一命令
- **THEN** 只通过原有确认端口执行领域动作，重放复用原身份且不重复产生效果；取消对话框零写入

#### Scenario: 提案陈旧
- **WHEN** 提案、目标版本或当前权限在确认期间变化
- **THEN** 请求以结构化失败收口，不把确认转移到新提案，刷新后需用户重新确认

### Requirement: 统一复核详情必须保持五类决定的原语义

系统 MUST 复用真实有界队列并按精确任务打开详情，展示目标、验证/证据快照、等待运行、复核策略、状态和历史决定。操作 MUST 按任务类型绑定既有五类决定联合，修正识别只接受上游生成的精确修正候选引用，不编辑正式风险记录或模型置信度；知识批准不直接发布，校准批准不直接改配置，处置决定不绕过三项校验。批量决定逐项独立授权、幂等、事务和结果。（RI-S6；RA-S6～RA-S7）

#### Scenario: 五类任务按类型决定
- **WHEN** 复核人查看识别、知识、规则冲突、处置或校准任务
- **THEN** 只显示该任务联合允许的决定和必需精确输出引用，不把所有批准统称为原样通过

#### Scenario: 修正并通过使用候选
- **WHEN** 复核人选择已获准的识别修正候选并确认通过
- **THEN** 命令携带该候选引用，正式记录由所属用例验收，旧版本和模型置信度保持可追溯

#### Scenario: 陈旧任务与部分批量失败
- **WHEN** 任务已决定/被替代，或批量中一项提交遇到版本冲突
- **THEN** 该项不能覆盖历史决定，其它项独立返回结果，界面保留逐项成功/失败事实

### Requirement: 运行审计与证据必须按所属事实分别分页

系统 MUST 保留识别与链运行的独立有界分组，并增加按精确主体和时间边界查询的业务/安全/复核拒绝活动。审计 MUST 显示活动码、安全原因、操作者、精确版本、命令及三类时间；业务追溯继续使用 C31 已成立链边及缺席原因。审计引用不得充当时间线正文，任一来源失败不得由另一来源冒充完整。证据抽屉继续只披露定位与脱敏摘要。

#### Scenario: 独立来源与续页
- **WHEN** 运行、活动或链路超过单页上限，且一个来源失败
- **THEN** 各分组使用自己的游标和错误状态，由用户续页，已成功来源不被清空或标为全部完成

#### Scenario: 历史与无正文权限
- **WHEN** 用户追溯历史版本但无资料正文权限
- **THEN** 页面保留原版本、获准定位及缺席原因，不展示原文、原始日志或凭据

### Requirement: 报告必须导出可审计的完整有界工件

报告页 MUST 复用 v2 范围/版本预览/产物/历史分区，以精确已登记 C31 查询结果与服务端版本化导出策略生成 JSON 报告。生成前 MUST 确认范围和副作用；成功后提供真实工件读取及下载，显示来源、策略、范围、缺席项和审计引用。格式、章节与范围只能使用当前策略支持值；超预算、不可读取或未完成分页不得导出伪完整报告。报告不包含资料原文、模型正文或思维链。（RI-S6；RA-S5～RA-S7）

#### Scenario: 正式报告可重放下载
- **WHEN** 用户对同一登记查询与策略生成并重试下载
- **THEN** 返回同一逻辑报告工件，内容由原精确事实重建，下载前重新校验权限且不通过任意 URL 取数

#### Scenario: 超限或权限收窄
- **WHEN** 报告超过策略页数/条目/字节上限，或生成/读取中权限被撤销
- **THEN** 不返回部分成功报告，页面显示可操作的范围缩小或安全失败，不用浏览器打印代替成功

### Requirement: 最小系统管理必须使用当前服务端身份

系统管理页 MUST 由服务端当前系统管理员身份控制，提供账号创建/停用/重置、工程开通/暂停及成员修订六项真实动作，使用预期版本和统一确认。系统级访问 MUST 不依赖工程上下文，且不授予管理员工程业务或资料访问。数据源、健康和模型页只呈现已有登记元数据或显式注入的安全状态；未提供备份恢复协议时该页显示未接入，不提供假恢复按钮。

#### Scenario: 无工程的管理员管理账号
- **WHEN** 当前有效系统管理员没有工程成员身份
- **THEN** 可经系统入口执行管理动作，但进入工程业务页仍按工程权限拒绝

#### Scenario: 角色判断不可用能力集合替代
- **WHEN** 普通用户业务能力为空，或拥有工程写能力
- **THEN** 均不会因此获得系统管理入口或执行权限，服务端仍拒绝管理命令

#### Scenario: 管理变更影响当前会话
- **WHEN** 账号停用/重置或工程成员权限修订成功
- **THEN** 后续请求立即使用服务端新权限，界面不恢复旧会话或旧目标，历史操作者保持不变

#### Scenario: 运维能力缺席
- **WHEN** 健康提供者、模型配置或备份恢复协议未注入
- **THEN** 对应分区如实显示未接入，不伪造正常状态、部署版本、连接检查或恢复点

### Requirement: C35 验收必须覆盖真实接缝和可访问性

系统 MUST 在真实 Chromium、`apps/web` 生产构建、PostgreSQL、正式迁移与真实 Cookie 会话上验收上述页面、类型化操作、审计、JSON 下载、撤权和工程切换竞态。合成资料与模型结构化候选 MUST 标明待甲方复核，不把随机模型回答作为期望。键盘可完成停靠切换与确认、取消恢复焦点；关键环境不可用 MUST 非零失败。

#### Scenario: 真实浏览器完成 C35 链路
- **WHEN** 固定环境中登记了合法任务、五类复核、历史活动、报告输入及管理员
- **THEN** 可从登录贯通任务详情/确认、复核、审计、报告工件下载与六项管理动作，证据对应实际入库结果

#### Scenario: 慢读和环境缺失
- **WHEN** 任务查询慢于刷新间隔、页面隐藏/卸载，或数据库/浏览器不可用
- **THEN** 慢读不叠加请求，隐藏/卸载清理刷新；环境缺失不以 skip 或 Mock 计作通过
