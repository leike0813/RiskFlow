# 07 工程知识检索效果

系统可以同时按文字关键词和语义含义查找资料，帮助工程人员从风险机理、规范和案例中找到与当前问题相关的依据。

本轮从15项知识中选取10个问题开展测试，逐项确认相关资料，再检查系统返回的前5条结果。当前测试使用的知识关联到25份来源资料。

| 检查内容 | 本轮结果 |
| --- | --- |
| 前5条结果对已标注相关资料的平均覆盖率 | 96.7% |
| 相关资料排在前面的表现 | 达到预先设定的要求 |
| 两种检索方式中的资料一致性 | 15项知识全部一致 |
| 越权资料泄露检查 | 测试中为0 |
| 检索服务查询耗时 | 约0.05秒 |

这里的耗时是检索服务完成查询的时间；用户提问到收到完整回答的耗时，将在连续业务演示中另行记录。

最初测试发现规范资料较难被找到。补齐条款正文、续表后，又逐条复核了“能直接回答问题”和“一般背景相关”的区别。经过确认，保留原有六个问题，增加四个规范问题，重新确定应命中的资料后完成上述测试。

下一轮会把新增监测资料纳入当前工程的资料范围，再复查检索结果和权限。甲方实际工程问题也将用于扩充测试，检验更多场景下的表现。
