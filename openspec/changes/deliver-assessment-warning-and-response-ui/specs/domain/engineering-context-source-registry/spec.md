## ADDED Requirements

### Requirement: 评估启动候选必须从所属登记事实有界读取

系统 MUST 为评估启动提供已登记适用性快照与外部风险事件的独立只读接缝。快照候选 MUST 限定精确工程与空间修订，包含精确快照引用及三个必含适用性维度；外部事件候选 MUST 限定当前获准工程、精确空间及来源，不要求未登记的工程修订，包含精确事件、空间、来源与证据引用，不披露原始事件工件正文。两类目录 MUST 各自分页，每页至多 50 项，游标绑定目录类型、实际精确筛选和当前授权范围。预览不得创建快照、事件、评估准备或业务成功写回。（RA-S1、RA-S4）

#### Scenario: 已登记候选可分别续页

- **WHEN** 获授权调用方选择精确空间，并为适用性目录提供精确工程修订，查询快照或外部事件候选
- **THEN** 返回该目录的真实精确引用、获准字段和独立下一页游标
- **AND** 空目录保持空，不从另一目录补齐或自动登记缺失输入

#### Scenario: 撤权错配或游标越界失败闭合

- **WHEN** 工程或空间修订错配、来源权限撤销，或游标来自其它目录或授权范围
- **THEN** 读取在披露目标前以既有安全错误失败
- **AND** 不全库读取后截断、不解析 latest、不扩大来源范围或泄露对象存在性
