# GAP-002 复合骨架 A+C / A+B 无法由单值枚举表达

- 类别：G1 外壳契约
- 相关页面：P-PJ-08、P-RV-05、P-OP-02

## 缺口

复合骨架 A+C / A+B 无法由单值枚举表达

## 依据

apps/web/src/app/routes.ts:32（WebShellKindV1 为单值枚举）；docs/page-manifest.json 中 P-PJ-08、P-RV-05、P-OP-02

## 预设

manifest.skeleton 允许组合记法（A+C / A+B），shellKind 映射主骨架 list，loading 骨架屏按主从布局同时渲染两半。

## 待确认

C32 / C35 的 design 裁决 shellKind 契约是否引入组合机制。

## 风险

若契约不允许组合，三页需拆为两个路由或降级为单骨架。
