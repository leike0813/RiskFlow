## ADDED Requirements

### Requirement: 复核详情深链不依赖队列页

两种复核详情页 MUST 由深链任务实体及身份版本直接调用所属详情窄读，以受权返回的完整引用构造原类型化决定。读取范围 MUST 固定为当前工程的该任务；不得扫描历史页或只在首队列页定位。错版、无权及缺身份版本沿原缺席/拒绝界面呈现。

#### Scenario: 待审任务位于队列第一页之外

- **WHEN** 当前有权用户打开该任务精确深链
- **THEN** 显示同一任务详情及原决定确认入口，不因队列页外而误报不存在

### Requirement: 生产Agent三视图必须可自然到达

系统 MUST 在唯一生产外壳注册真实任务贡献，使普通业务页可打开Agent、选择任务及进入工作台，侧栏/工作台/详情共享精确任务、行动、安全工具引用、预算、候选校验和结果。缺证据不得误关闭面板，终态历史可读，候选投影失败不得误报为确定的角色权限不足。不得复制会话、重新启动任务或暴露原响应/思维链。

#### Scenario: 由业务页查看已完成清洗

- **WHEN** 当前有权用户自然打开Agent并选择已有清洗任务
- **THEN** 三视图展示同一任务与正式用量，行动可分页读完，候选校验按实际契约读取

#### Scenario: 待复核动作

- **WHEN** 当前用户查看pending复核并具有决定分支权限
- **THEN** 服务端返回实际动作判定，界面可经确认提交原类型化决定，权限判定自身不提交决定
