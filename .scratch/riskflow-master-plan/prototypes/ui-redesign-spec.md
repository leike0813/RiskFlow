# UI 重做规格 · 主文档

本文件是 UI 重做 effort 的规格总纲。**章节附件不重复正文内容，只在本文件给出结论与链接。**

## 1. 目的地与边界

RiskFlow 的界面从「对话技术对象」（`runId`、快照 ID、发布集合、复核任务 ID）改为「对话工程业务对象」（标准化风险记录 / 风险评估记录 / 预警处置任务 / 处置闭环），服务对象是工程风险管理员的日常办公与甲方验收演示。

**本 effort 到规格为止。** 按规格切分并开 OpenSpec change 是施工期的事，本 effort 不写生产代码。

**已排除**：施工与实现、后端接口的实际改动、移动端适配（`AGENTS.md` §4.6 要求另定）、矩阵形态变更与由此产生的重新取证（属配置治理，见 §7）、`demo/v1` 复用。

## 3. 新信息架构

**一级导航六项**：风险总览 / 工程 / 识别 / 评估 / 预警与处置 / 治理。

**辅助入口**：全局搜索（主入口之一）、停靠区（待办 + 助手工作）、用户菜单（系统管理）。最多两层。

**壳层形态**：左导航 152px 带文字／48px 图标折叠，右停靠区 22rem 可收起；命令面板位于顶栏。桌面缩放、焦点和滚动边界以设计系统附件为准，原型的 64rem 自动换列不采纳。

**日常主路径**：风险总览 → 上传资料 → 启动识别 → 风险记录 → 评估 → 预警 → 处置任务。投料入口在总览仪表盘内。

**处置任务详情是全站闭环枢纽**：七类关系对象与八环时间轴；视觉合并不取消子记录的精确身份、版本和直接读取。合法独立行动及其反馈／校准仍以原精确地址共享详情组件，不强制绑定任务。复核详情保留精确 URL，页内打开为全屏覆盖层，刷新或直达由同一视图重建。

**构建顺序不等于发布顺序**：

- CH-3…CH-8 可在公共接缝上并行实施；各自新承载完成真实权限、正文、历史精确深链和原命令验收后，才在同一发布单元中启用对应解析规则、更新所有调用方并移除被替代页面实现。保留地址解析，不保留两套业务页面。
- CH-9 的搜索与聚合可以并行实施，最终负责待办／助手与六导航的组合启用，须证明 CH-3…CH-8 的目标承载均已就绪。旧复核入口在此之前继续可用；未完成组合验收不得以隐藏入口包装完工。
- 历史运行摘要由 CH-3 保留有界读取；CH-6 保留历史矩阵的精确只读入口；CH-7 保住任务与所选子记录的两套版本；CH-9 保住队列外与已决定复核任务的精确读取。具体地址以路由附件为准。

## 7. 风险登记

1. **普通业务页面不额外标合成状态**：保留来源误解风险；质量页面、试运行报告、验收记录及其导出或截图证据必须标注“合成样本，待甲方复核”、来源与候选资格。开场说明不替代材料标注，技术演示不等于最终业务验收。
2. **AntD 覆写成本未实测**：本决定基于"表单类自建成本更高"，未实测主题覆写工作量。若施工期发现覆写视觉类成本超过自建，走 CH-1 change 的移除条件退回自建。
3. **AntD 包体积**增加首屏负载，需按需引入 + 构建分包缓解，施工期实测。
4. **导航授权传递待实际验收**：CH-2 核对生产已有 branch／角色授予与会话传递，只修实际缺口；CH-9 组合启用前证明原角色不因新增聚合入口或缺少 Agent 权限而失去本域能力。
5. **矩阵形态变更**属配置治理，不在本 effort。UI 侧的义务只有一条：图表与等级显示由数据驱动、不得硬编码档位——已在 CH-1。
6. **旧地址长期可达**：旧链接作为永久精确解析入口，不再绑定已结束的 C38 自动移除；保留有界解析成本，不保留重复页面实现。无法授权解析时同形拒绝，不披露解绑或其它工程的事实。

## 8. 决议完成与施工就绪的区别

**本轮交付是决议修正，不是 OpenSpec apply 就绪证明。** 主文档、八份章节附件及页面原型构成 planning 输入；附件中的既有源码位置是调查证据，不是已批准施工图。

- 决议层：权限、版本身份、来源资格、最终布局、规格所有权和切换责任已明确；不把查明已有的后端读面再次列为新建能力。
- Change planning 层：创建各 change 时，按项目 CLI 与 workflow 生成 proposal、specs、design、implementation-plan、tasks；基于固定代码基线补齐文件清单、现有符号、Requirement／Scenario、IP-ID 和真实可执行验证命令。`applyRequires` 未闭合不得实施，不将本表当作施工授权。
- 发布层：每个被替代入口须有新承载、精确历史目标和权限/错误行为证据；CH-9 保存六导航与停靠区组合验收。仅编译、原型可点击或“页面非空”不能证明可用。
- 产品反馈：CH-3／CH-7／CH-9 的真实主路径验收记录信息组织和术语反馈，交付时统一回灌本地图；影响领域事实的意见进入对应 change，不加独立甲方用词审批关口。
