## ADDED Requirements

### Requirement: 评估读取按实际记录来源检查当前权限

系统 MUST 从查询目标所属准备中定位真实来源，沿C06当前权限检查，不得把空授权增量当完整可读清单。精确读取先限定记录标识；目录、历史和摘要在分页或聚合前过滤全部来源可见的记录。来源发现沿既有256项上限，不枚举全资料库；越界明确拒绝。工件仍按C04登记来源当前检查，历史授权包含关系不得取代当前权限。

#### Scenario: 空授权增量读取原正式评估

- **WHEN** 当前身份授权没有来源增量，但对目标准备实际来源均有权
- **THEN** 正式详情、目录及摘要可读，返回保存的评分解释，不重跑评分

#### Scenario: 当前来源撤权或空间不符

- **WHEN** 记录任一真实来源当前无权或记录空间不在当前范围
- **THEN** 精确读取不可枚举拒绝，目录和摘要过滤该记录，分页不泄漏隐藏行

### Requirement: 评估消费准备中显式冻结的工程字段事实

系统 MUST 支持C11评估准备显式冻结sourceFieldFacts，复用唯一RiskInputFactFieldV1的类型、documentType、fieldPath、值与证据。字段键唯一，禁止覆盖标准化风险自身字段，字段不超过1024、唯一证据不超过256；当前权限、资料版本/段与空间由C11核验，缺失或不合格不得形成准备。资料事实值和证据 MUST 纳入准备不可变摘要及审计，不从其它运行、最新资料或模型分数补值。

C25 MUST 将本次准备中显式冻结的资料事实与正式风险事实组合后执行原确定性映射、单位、指标、规则、权重和矩阵；重复字段、总量越界、当前撤权或证据不符 MUST 拒绝。标准化风险记录保持原字段与版本。

#### Scenario: 已识别风险使用施工及地质资料值

- **WHEN** 当前有权调用方冻结了带真实资料段证据的施工压力和围岩等级，字段对应已发布映射
- **THEN** 评估使用该准备精确资料值，并保存字段/来源/配置追溯，风险置信度不被当作这些工程值

#### Scenario: 字段无权重复或覆盖风险事实

- **WHEN** 字段键重复、尝试覆盖标准化风险字段、总量超限，或者资料/段/空间/版本当前不合法
- **THEN** 冻结或读取拒绝，原准备、风险记录及业务结果不变
