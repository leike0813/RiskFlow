## ADDED Requirements

### Requirement: 已完成清洗任务支持当前授权下独立完成准备

C15 MUST 提供complete-identification-preparation冻结分支，仅接收精确完整agentTaskRef，并使用新命令当前engineering-data.freeze授权。系统 MUST 验证原发起人/工程一致、真实completed任务、冻结清单/策略及正式结果匹配，当前空间/资料权限、C04消费完成和原覆盖校验通过后复用原摘要形成唯一准备快照；不得重新发起清洗或以过期原授权执行。已有快照在当前复验后返回，新的完成命令单独审计；并发与重投 MUST 不重复快照或inputs-ready。事件继续保留真实完成命令及可验证原父运行因果，不新增任意父运行输入。

#### Scenario: 启动授权到期后完成准备

- **WHEN** 原清洗任务completed而原命令授权已到期，原发起人以当前有效会话提交精确完成命令
- **THEN** 原任务/输入/结果和当前权限通过验证后返回正式准备，模型/工具用量不变，旧命令仍按原期限拒绝
- **AND** 当前复验按实际资料与空间范围返回授权增量，完成准备不要求其与入口的完整授权快照逐字段相等；脱敏或当前拒权仍阻止收口

#### Scenario: 完成资格不足或并发重投

- **WHEN** 任务未完成/失败/取消、主体/工程/引用/策略不符、当前撤权、C04损坏/超限或原因果未证明，或者完成命令并发/重投
- **THEN** 前述失败不生成准备或就绪事件；合法并发/重投只引用首次正式快照并保留各命令审计，同键异载荷冲突

### Requirement: 清洗必须观察未识别表格图片及其冻结变化

冻结文档可包含unrecognizedTableImageCount，MUST 从受权JSON-LD真实引用计算并在初始模型定位消息显示。受选表格切片 MUST 包含同表纯图单元格的逻辑位置和未识别引用；不得因缺少textBlock丢弃。读取严格限于当前选择关联表格并计入原对象/字节预算，超限拒绝。相关段parsedFingerprint MUST 纳入同表图片引用，无图片沿原含义；完整JSON-LD指纹继续冻结全部结构。不得新增通用读取工具或推断图形值。

#### Scenario: 读取带纯图单元格的表格

- **WHEN** 清洗Agent在原预算内选择含未识别图片的表格段
- **THEN** 源级数量及切片行列和图片引用可观察，纯图单元格不混同于空值，原权限和工件验证生效

#### Scenario: 图片变化或资源不足

- **WHEN** 同表图片引用改变，或关联观察超过原对象/字节预算
- **THEN** 前者改变相关冻结指纹，后者明确失败，不截断观察或扩容；没有图片的历史输入保持原语义

### Requirement: 清洗定位按冻结资料有界分页

系统 MUST 在版本化工具白名单声明定位工具时，提供read-cleaning-preparation-catalog-slice动作，以精确冻结sourceVersionRef及offset读取最多maxSegmentsPerRead个真实段标识/种类，并返回明确nextOffset。读取 MUST 复验当前授权及冻结清单，保留C04消费完成与访问记录；初始消息保留全部资料身份和规模，完整清单留在冻结输入，不截断或拆分任务绕过预算。

#### Scenario: 读取冻结资料定位下一页

- **WHEN** Agent使用登记的定位工具及合法offset
- **THEN** 返回该资料有界页及下一页位置，行动计入原调用/字节/对象预算，重放不改变冻结集合

#### Scenario: 定位超范围或工具未登记

- **WHEN** 资料不在冻结集合、offset越界、当前撤权，或策略未声明该工具
- **THEN** 读取被结构化拒绝，不返回其它资料定位或扩大范围

### Requirement: 清洗模型获得真实有界定位与观察

系统 MUST 在可信组合根经原冻结输入与当前受权读取提供清洗模型选择原领域工具所需的真实资料版本、资料段或监测样本定位。上一轮观察 MUST 经同任务冻结清单绑定、精确C04用途和读取完成后进入模型消息；消息继续受原字节、token与上下文预算约束，超限不得截断或扩大预算。任务信封 MUST 继续只保存引用，不增加模型通用工件、数据库或文件工具。

#### Scenario: 模型选择真实资料段

- **WHEN** 模型请求清洗工具前需要资料段身份
- **THEN** 宿主提供当前冻结集合内的真实定位，工具继续复验版本、授权及上限
- **AND** 不把清单工件当作资料版本，不伪造资料段标识

#### Scenario: 观察越界或消息超预算

- **WHEN** 观察来自其它冻结清单、读取被拒绝或损坏，或渲染消息超过原预算
- **THEN** 请求以原错误类别失败并留证，不发起模型推理、扩大输入范围或跳过读取校验

#### Scenario: 多次读取后仍保留已完成定位

- **WHEN** 清洗任务完成多个有界目录、资料段或监测读取，并继续或从原行动账本恢复
- **THEN** 模型获得同任务已成功调用的结构化读取进度与原观察引用，目录定位按冻结集合重建，最近观察仍经原C04完整读取
- **AND** 失败/未完成调用不作为已读事实，错源/错段/错工具或超预算拒绝；不增加通用存储工具、模型思考或第二套任务记忆

#### Scenario: 生成工具行动时只允许冻结资料身份

- **WHEN** 清洗模型生成目录或资料段读取行动
- **THEN** 生成Schema绑定本任务实际资料版本及原单次上限、目录offset绑定冻结段数，监测行动只在存在实际冻结快照时提供
- **AND** 原注册动作Schema与工具来源/成员/权限复验继续执行，不允许清单工件冒充资料版本，也不把未分页的全量段定位写入Schema
