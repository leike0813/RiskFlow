## Purpose

为工程风险管理员及其他获权工程成员提供以业务事实为中心的风险总览，在同一工程内查看态势分布、变化、待办摘要和接入概况；各来源保留自身权限、统计单位、时间与精确版本，并承接历史运行入口而不替代可重放报告。

## ADDED Requirements

### Requirement: OV-R1 总览必须组合真实来源且分别呈现状态

系统 MUST 在 `/overview` 以生产设计系统和公共区域组合呈现态势分布、变化时间线、待办摘要、资料／监测接入概况与真实下一步。各来源 MUST 分别表达加载、就绪、空、异常、拒权和不可用，页面沿公共七态契约；成功空集合才可显示零。来源无权或故障不得被相邻来源掩盖，不披露无权对象的名称、数量、引用或关联存在性。当前工程／空间变化、注销或新请求替代旧请求时 MUST 清除不匹配内容并忽略迟到响应。（RI-S5～RI-S6；RA-S3～RA-S7）

#### Scenario: OV-S01 单来源失败不伪造零值
- **WHEN** 评估来源读取失败而预警与资料来源可读
- **THEN** 评估区显示安全失败和可重试入口，其余区保留各自成功结果、范围及统计时点
- **AND** 不产生完整态势总量、零评估或静态趋势

#### Scenario: OV-S02 跨上下文迟到结果不能闪回
- **WHEN** 用户切工程、空间或注销后旧请求才返回
- **THEN** 新页面不呈现旧统计、事件、分页位置或来源链接，重新按当前上下文读取

### Requirement: OV-R2 分布必须与所属目录同口径

态势分布 MUST 由服务端在来源所属模块聚合完整的当前授权候选集，而非累计目录页或在浏览器遍历全部记录。风险等级分布的统计单位 MUST 是对应评估记录目录的已入库记录版本；工序分布的统计单位 MUST 是对应风险记录目录的记录版本，保留有效／被取代／作废状态口径。重评版本不得被当作不同风险事件去重或把两个分布相加。等级 MUST 使用正式记录冻结的配置身份与可用等级元数据分组；不同矩阵版本及不可比较等级不得混画为统一严重度。分组超过受控输出边界 MUST 显式不可用，不截断为完整统计。统计须标明当前获准范围、单位与时点，不宣称跨域原子快照。（RI-S6；RA-S3～RA-S6）

#### Scenario: OV-S03 超过一页仍与目录一致
- **WHEN** 当前可见评估和风险记录均超过目录页大小，并含重评版本、非有效风险记录及另一区段不可见记录
- **THEN** 两类分布分别等于所属目录相同过滤条件下的完整可见集合，不只统计第一页，不计入不可见记录

#### Scenario: OV-S04 多版本等级不得混算
- **WHEN** 两个冻结矩阵使用相同等级标识却有不同含义，或等级名称／颜色元数据缺失
- **THEN** 等级分布保留各配置身份与原等级，分别呈现可比较组；缺元数据给出可读说明，不按标识猜档位或伪造名称

#### Scenario: OV-S05 分组超界不报部分成功
- **WHEN** 某来源分组数超过公开结果上限
- **THEN** 仅该来源返回可识别的不可用结果，不把被截断分布、残缺分母或部分和标为完整总量

### Requirement: OV-R3 变化时间线必须有界且指向正式事实

变化时间线 MUST 只组合已经提交的风险记录版本、评估记录版本和预警记录的登记变化；每项须含来源种类、变化类型、真实时间及精确主体引用，不用运行状态、审计引用或读取时刻伪造事件正文。首页及续页 MUST 有上限，稳定排序并固定本次读取时间上界；每次独立读取重新裁剪当前权限。游标须绑定工程、业务筛选与排序位置，不绑定不断变化的完整权限摘要；错工程、错范围、错位置或非法游标安全失败。技术故障导致某可读来源缺席时 MUST 标明时间线不完整，不允许越过该来源继续翻页；重试从原位置恢复。不得轮询全库、请求模型或生成占位事件。（RI-S6；RA-S5～RA-S7）

#### Scenario: OV-S06 同时刻事件和新增事实可稳定分页
- **WHEN** 多种来源在相同时刻登记且超过一页，续页前又登记新事实
- **THEN** 原时间上界内的可见精确事件按稳定次序无重复翻页，新事实通过显式刷新进入新一轮；详情链接仍指向事件原版本

#### Scenario: OV-S07 时间线来源失败与重试
- **WHEN** 首次或续页的某个已获权来源发生技术失败
- **THEN** 页面显示该来源失败及成功来源的有限事件但不宣称完整，不发出越过失败位置的下一页；重试不遗漏该来源事实

#### Scenario: OV-S08 游标越界或读取中撤权
- **WHEN** 游标被用于另一工程／空间，或用户失去某来源及对象读取权
- **THEN** 前者安全拒绝，后者不再返回受限事件、计数或引用；其余合法来源可继续按自身范围读取，不使用历史授权放行

### Requirement: OV-R4 待办摘要必须区分对象和实际可执行权限

总览 MUST 服务端统计当前可见的 pending 复核任务、尚未确认的正式预警、open 处置任务及有正式等级依据的分组计数，并明确这些是当前可见事项而非个人分派。三类数量可能重叠，MUST NOT 相加为统一待办或风险事件总数；无等级的知识／治理复核不得伪造等级。读取资格不表示可复核、可确认或可处置；来源入口沿既有目录及原命令，不能由摘要创建决定、确认、采纳、执行、关闭或 Agent 任务。四来源待办明细与 `/overview?tab=todo` 的正式承载归后续搜索／停靠 change，本 change MUST 保留原复核队列。（RI-S6；RA-S6～RA-S7）

#### Scenario: OV-S09 重叠事项与无等级复核
- **WHEN** 同一风险具有未确认预警和开放任务，另有知识类待审复核
- **THEN** 分别呈现两类预警／任务数量及无等级复核，不去重猜测统一事项、不补风险等级、不写成已分派给当前人

#### Scenario: OV-S10 有域读权无域写权仍可查看
- **WHEN** 现场处置人员或查看者能读预警但不能确认预警或决定复核
- **THEN** 可读摘要与来源链接可用，写操作不因入口或读权被开启；无 Agent 权不阻断可读来源

### Requirement: OV-R5 接入概况和投料动作必须连接现有真实能力

资料／监测概况 MUST 使用所属目录相同可见性和计数单位，资料解析／清洗状态与监测序列、批次及冻结数据状态只能来自真实登记，缺席不能用健康值或假曲线补齐。总览 MUST 提供通向现有资料接入和监测接入承载的可操作入口；不在本页建立平行上传命令、自动提交或客户端接入事实。入口须按当前资格及现有承载实际能力呈现，只读或未接入时给出清晰说明。（RI-S1～RI-S2；RA-S1）

#### Scenario: OV-S11 接入入口保留工程且不自动写入
- **WHEN** 用户从总览打开资料或监测入口
- **THEN** 到达当前工程的真实现有承载并保留合法上下文；点击导航不产生接入、识别、快照或模型调用

#### Scenario: OV-S12 无资料权不披露资料存在性
- **WHEN** 用户有预警读取资格但无资料目录或某指定资料可见性
- **THEN** 总览不返回该受限资料的数量、状态、名称或链接，预警读取不被资料来源拒权阻断

### Requirement: OV-R6 历史运行入口必须原子迁到同一总览承载

`/overview?tab=runs` MUST 完整承接旧运行页的识别任务与链运行独立分组、原查询能力、用户续页和精确详情引用。`/review-audit/runs` 与已知 `/review/runs` MUST 永久 replace 到该位置，保留工程、给定修订、评估来源及其它原有效上下文；给定历史修订不得换成当前修订。C31 原查询引用、时间与游标不得被仪表盘统计改写。切换须同批迁移生产内部链接并移除重复旧页面实现，不借保留地址继续维护两份正文；旧复核队列、审计、追溯与报告仍按原所属能力提供。（RI-S6；RA-S5～RA-S7）

#### Scenario: OV-S13 历史旧地址直达和刷新
- **WHEN** 有权用户打开任一旧运行地址并携带历史修订与工程选择器，之后刷新或前进后退
- **THEN** 地址规范化到同工程总览运行位置，识别与链运行各自有界可读，原精确任务和版本不丢失，不替换为当前修订

#### Scenario: OV-S14 只有运行读权仍可读历史
- **WHEN** 历史运行来源可读但评估、预警或工程当前上下文来源不可读或失败
- **THEN** 已明确给定的历史修订与原投影仍能按其所属授权读取，不因仪表盘权限交集或其它来源故障被封锁；未给修订时仅用既有合法解析，不扫描目录猜测

### Requirement: OV-R7 总览必须用真实生产路径验收

验收 MUST 使用正式 Web 构建、真实 PostgreSQL／迁移、Cookie 会话及公开 HTTP，覆盖统计与目录一致、独立来源权限／故障、事件分页、接入入口、历史运行地址和上下文竞态。新总览须支持键盘、图表文字替代及三种桌面窗口在 100%／200% 原生缩放下的操作。质量与验收材料 MUST 保留“合成样本，待甲方复核”、来源及版本；关键环境缺失非零失败，不以原型、Mock、关键 skip 或非空截图代替。新增聚合与分页须记录真实数据规模、响应量、耗时与读取边界。（横切 RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: OV-S15 完整读链与缩放证据
- **WHEN** 在真实生产面运行本 change 验收及原生缩放用例
- **THEN** 指标、事件和历史引用与持久事实一致，关键动作及分页可键盘到达；性能证据来自实际查询，材料明确合成资格

#### Scenario: OV-S16 环境或关键路径缺失不能通过
- **WHEN** 必需数据库、HTTP、浏览器或统计／历史／权限关键路径未运行
- **THEN** 验收明确失败或阻塞并保存原因，不将工件齐备或构建成功等同功能交付
