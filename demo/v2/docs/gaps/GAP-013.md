# GAP-013 三个 .read 能力位无 branch 授予通路，导航可达性与导航所需能力不一致

- 类别：G3 未建能力
- 相关页面：全局

## 缺口

三个 .read 能力位无 branch 授予通路，导航可达性与导航所需能力不一致

## 依据

packages/contracts/src/ports/index.ts:482-535（MODULE_BRANCH_CAPABILITY_V1 中无任何 branch 映射到 risk-identification.read / risk-assessment.read / warning-response.read）；apps/web/src/shell/navigation.ts:34、:44、:54（三项导航的 requiredCapability 恰为这三个能力位）

## 预设

v2 严格按策略镜像照实渲染：风险识别 / 风险评估 / 预警处置三项导航对全部预设角色（含 project-risk-manager）呈现 denied，对应页面默认 forbidden；审阅这些页面的设计经状态矩阵 ?state= 强制注入（强制态优先于门控）。不手写「读能力由同模块其他能力隐含」之类的修补逻辑。

## 待确认

控制面裁决：在 branch 映射中补授予通路（如新增只读 branch），或调整导航 / 路由所需能力位；属契约演进 change。

## 风险

若裁决为补 branch 映射，v2 零改动；若裁决为调整导航所需能力，shell/navigation.ts 与 page-manifest.json 的 capability 同步更新。
