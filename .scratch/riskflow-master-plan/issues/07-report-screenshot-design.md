## Answer

五张 1920×1080 高保真截图从 `demo/` 真实页面取景导出，页面到截图的派生关系固定如下（与 `demo/scripts/capture.sh` 一致）：

| 截图 | 文件 | 来源页面（路由） |
|------|------|------------------|
| 风险态势总览 | `demo/screenshots/01-risk-overview.png` | `/`（风险态势首页） |
| 智能 Agent 工作台 | `demo/screenshots/02-agent-workbench.png` | `/agent`（P-AG-02 全屏工作台） |
| LangGraph 智能识别中心 | `demo/screenshots/03-identification-center.png` | `/identification/runs/RUN-20260827-001` |
| 风险评估与预警中心 | `demo/screenshots/04-assessment-warning.png` | `/assessment/records/ASSESS-2026-001` |
| 风险详情 / 处置建议 / 证据追溯 | `demo/screenshots/05-risk-response-trace.png` | `/risks/RISK-2026-001` |

汇报叙事沿用 05 号票确定的“变径空间扩挖—地表沉降风险”单一主线：态势总览（风险已触发红色预警）→ Agent 工作台（一次可审计的识别评估运行）→ 识别中心（`RI-S1–RI-S6` 与工序风险关联图谱）→ 评估预警（P=4 / C=4 / I 级、四类触发与版本依据）→ 风险详情（处置建议三重校验、端到端证据链与审计时间线）。早期草案 `prototypes/report-screenshot-design.md` 保留为内容密度参考，最终依据以真实页面与本派生关系为准；后续如需重新取景，运行 `demo/scripts/capture.sh` 即可按同一关系再导出。
