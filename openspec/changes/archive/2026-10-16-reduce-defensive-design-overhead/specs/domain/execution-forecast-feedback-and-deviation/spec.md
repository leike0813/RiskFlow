## MODIFIED Requirements

### Requirement: 效果预测冻结建议、监测和评估依据

系统 MUST 以已采纳建议、采纳决定、执行前 C14 监测快照、建议所追溯的 C25 评估输入快照以及在预测阶段从选定运行清单冻结的 C18 预测策略形成不可变预测输入。预测策略 MUST 与建议目标指标、单位、时域和精确 `requiredRef` 相容；所有输入、策略、授权和证据均按精确版本保存，后续监测、评估或配置发布不得改写旧预测。（RA-S7）

#### Scenario: 冻结完整预测输入

- **WHEN** 已经采纳的建议目标指标可由同工程执行前监测快照和冻结评估依据支持，且预测策略引用的执行方法版本可用
- **THEN** 系统保存不可变预测输入及其精确建议、决定、监测、评估、策略和执行方法引用
- **AND** 重放只读取这些冻结版本

#### Scenario: 预测依据不完整时显式不可用

- **WHEN** 建议未采纳，目标指标或单位不匹配，监测快照不可用，策略版本缺失，或者 `requiredRef` 指向的方法不可执行
- **THEN** 系统保存或返回稳定的预测不可用原因且不创建效果预测
- **AND** 不使用零值、历史均值、最新配置、其它工程模型或 Agent 输出补齐

### Requirement: 偏差事实按冻结策略确定性计算

系统 MUST 只在正式效果预测和相容反馈均存在时，按本次偏差阶段从选定运行清单冻结的精确 C18 偏差策略比较同一目标指标、单位、时域和风险等级序。`absolute` MUST 计算实际值与预测值之差的绝对值；`relative` MUST 以预测值绝对值和正最小基线中的较大者为分母计算绝对相对偏差；`risk-level-step` MUST 按冻结风险矩阵等级序计算预测与实际风险等级的绝对步数。结果 MUST 保存稳定偏差事实标识、处置建议与执行引用、预测/实际值和风险状态、偏差值、阈值版本、是否越限、方向、证据及版本。（RA-S7）

#### Scenario: 三类策略精确判定阈值边界

- **WHEN** 预测和反馈完整相容，且计算结果恰好等于或越过冻结阈值
- **THEN** 系统按该策略的规范十进制或整数等级步数得到唯一偏差值与 `thresholdExceeded` 判定
- **AND** 相同冻结输入重放得到相同偏差事实

#### Scenario: 无预测或比较口径不一致时不造偏差

- **WHEN** 执行没有合法预测，预测与反馈的目标指标、单位、时域或评估依据不一致，或偏差策略缺失/不相容
- **THEN** 系统返回显式不可用或类型化失败且不保存偏差事实
- **AND** 不用零值、历史均值、当前风险等级或其它策略替代

#### Scenario: C28 不伪造公共偏差记录

- **WHEN** C28 保存未越限或已越限的确定性偏差事实
- **THEN** 系统不创建公共 `DeviationRecord`，也不填充 `calibrationRecommendation` 或 `reviewStatus`
- **AND** 不创建校准 Agent 任务、校准建议或配置发布事实
