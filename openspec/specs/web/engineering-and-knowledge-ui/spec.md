# web/engineering-and-knowledge-ui Specification

## Purpose

本能力在既有 demo 应用（riskflow-demo）上交付"工程项目"与"知识与规则"两块业务导航的只读界面：九个既有页面改由 apps/api 真实只读面驱动，新增检索结果查看页，统一证据抽屉脱敏两态与空/加载/异常/权限骨架行为，并提供真实浏览器验收链路。

## Requirements

### Requirement: 页面必须只经既有 HTTP 只读面取得业务事实

全部页面 MUST 只经闭合路由清单中的只读 query branch 与既有查询取得业务事实，不得 import `demo/src/content/` 静态内容模型作为业务事实来源，不得渲染与当前工程无关的写死样例。页面 MUST 由 `apps/web` 的生产构建交付，数据接入 MUST 集中在其唯一 API 接入层：查询提交、传输信封组装、错误脱敏映射与取消语义唯一实现，页面不得各自拼装 HTTP 细节。本 change 全部页面只读：MUST NOT 提供任何会产生业务事实的操作入口；既有静态原型中的假写操作按钮（登记资料、新建机理条目等）MUST 移除，不以占位或禁用态冒充已接线能力。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 页面渲染当前工程的真实事实

- **WHEN** 获授权用户打开任一业务页面
- **THEN** 页面内容由当前工程上下文的只读查询结果驱动，刷新后按服务端当前事实重建，不出现静态样例残留

#### Scenario: 写操作入口不存在

- **WHEN** 审查九个既有页面与检索结果页的可点击操作
- **THEN** 不存在任何提交业务命令的入口；原静态原型的假确认按钮已移除而非改头换面
### Requirement: 会话与工程上下文必须显式且可切换

界面 MUST 提供登录页，经既有 `session/login` 建立会话；未认证或会话失效时跳转登录页，不把认证失败呈现为普通业务错误。工程上下文 MUST 以 URL 查询参数选择（工程与工程修订），切换工程只改变后续查询上下文并停留在当前页面重新加载；服务端返回的会话元数据不得被页面扩展为工程列表之外的含义。无工程上下文时页面呈现引导空态而非报错。（RI-S14、RI-S61～RI-S65）

#### Scenario: 未登录访问业务页

- **WHEN** 浏览器无有效会话直接打开业务页面
- **THEN** 跳转登录页，登录成功后回到原目标页面

#### Scenario: 切换工程重新加载

- **WHEN** 用户在资料目录页切换工程
- **THEN** 页面停留原地并按新工程重新查询，旧工程内容立即清除，不短暂残留

### Requirement: 空、加载、异常、权限四类骨架行为必须逐页一致

各页面 MUST 遵循对应骨架（列表 A / 详情 B / 治理 D）的状态约定：加载时骨架占位不闪烁切换空态；空态说明当前筛选下无数据并给出最可能的下一步入口；异常显示结构化错误摘要与重试，不显示技术堆栈；权限不足显示权限骨架并提示所需能力，不披露目标存在性。`NOT_FOUND` 与 `AUTHENTICATION_REQUIRED` MUST 映射为权限/会话语义而非普通错误。（RI-S61～RI-S65）

#### Scenario: 无权访问知识页面

- **WHEN** 不具备知识读能力的角色打开机理库页
- **THEN** 呈现权限骨架与所需能力提示，页面不显示任何条目数量或名称线索

#### Scenario: 查询失败可重试

- **WHEN** 只读查询因瞬时故障失败
- **THEN** 页面显示结构化错误摘要与重试入口，重试重新发起同一查询，不显示堆栈或内部标识

### Requirement: 证据抽屉必须经 evidence-access 呈现脱敏两态

证据抽屉 MUST 经 `engineering-data.evidence-access` 查询与结果再读取打开：呈现资料段标识（资料ID-章节ID-资料段ID）、章节路径等定位摘要，以及引用该证据的业务对象；段正文原文无 HTTP 通路，抽屉在任何授权状态下都 MUST NOT 呈现段正文原文。无资料访问授权时 MUST 只显示定位摘要（资料名称、章节路径、资料段标识）并给出固定脱敏提示，不得呈现"加载失败"歧义，不得经其它路径绕取原文。抽屉内 MUST 可跳转资料详情页并携带资料段锚点。（RI-S1～RI-S2、RI-S6）

#### Scenario: 有授权时呈现定位与引用

- **WHEN** 用户对证据来源版本具备访问授权并打开证据入口
- **THEN** 抽屉显示段标识、章节路径等定位摘要与引用该证据的业务对象清单，不显示段正文原文

#### Scenario: 无授权时固定脱敏

- **WHEN** 用户无该来源版本访问授权
- **THEN** 抽屉只显示定位摘要与固定脱敏提示，不发起任何替代取数

### Requirement: 工程概览页必须呈现当前上下文与发布集合

工程概览页 MUST 经 `engineering-data.context-read` 呈现工程身份、适用性元数据三维度（施工工法/地层条件/工程阶段）与空间区段树，经 `knowledge-modeling.governance-read` 的当前发布集合呈现发布版本引用（版本徽章），并以资料/监测目录统计呈现接入概况。适用性维度缺失时 MUST 逐项标出。页面只读，不提供上下文修订或开通操作。（RI-S1；RA-S1）

#### Scenario: 上下文完整时呈现概览

- **WHEN** 工程上下文已生效且适用性三维度齐备
- **THEN** 页面呈现工程身份、三维度、区段树、发布集合版本徽章与接入统计

#### Scenario: 适用性维度缺失逐项标出

- **WHEN** 适用性元数据缺少任一必含维度
- **THEN** 页面逐项标出缺失维度，不用默认值补齐

### Requirement: 资料目录与资料详情必须呈现登记、解析与清洗事实

资料目录页 MUST 经 `engineering-data.source-catalog` 分页呈现资料版本条目（类型、形成时间、来源单位、版本、解析状态、清洗可用性摘要），行点击进入资料详情。资料详情页 MUST 呈现资料元数据、章节结构树与资料段列表，段列表经 `source-segments` 查询与结果再读取驱动，每段提供证据入口；重复内容 MUST 呈现为关联既有版本而非重复条目。（RI-S1～RI-S2）

#### Scenario: 目录分页与详情联动

- **WHEN** 用户翻阅资料目录并点击某行
- **THEN** 目录按游标分页返回有界条目，详情页展示该精确版本的元数据与段列表

#### Scenario: 清洗可用性如实呈现

- **WHEN** 资料版本存在正式清洗结果
- **THEN** 目录与详情呈现可用性判定与排除计数；部分可用时排除范围有明确标记，无正式清洗结果时标注未清洗

### Requirement: 监测序列详情必须呈现快照与越限事实

监测序列详情页 MUST 经 `engineering-data.monitoring-catalog` 选择序列，经 `monitoring-snapshot` 查询与结果再读取呈现冻结快照的统计事实（时间窗、样本量、短期斜率/加速度/异常评分等快照载荷内字段）、阈值引用与越限标记；批次与更正关系按登记事实呈现。契约载荷不含的原始点序列 MUST NOT 编造；页面在无快照时呈现空态并说明原因。（RI-S1～RI-S2；RA-S1、RA-S6）

#### Scenario: 快照统计与阈值同屏

- **WHEN** 序列存在冻结快照与监测预警阈值版本
- **THEN** 页面呈现快照统计、阈值版本徽章与越限标记，越限判定与快照载荷一致

#### Scenario: 无快照空态

- **WHEN** 序列尚无冻结快照
- **THEN** 页面呈现空态并说明缺少快照，不以插值或样例曲线填充

### Requirement: 工序模型页必须呈现已发布模型与证据定位

工序模型页 MUST 经 `knowledge-modeling.governance-read` 读取当前发布的工序模型版本，呈现工序节点（含输入/输出描述与状态参数）、装备部件、构件与三类依赖关系（时间先后、资源依赖、受力依赖），节点提供证据定位入口；五个必含工序节点 MUST 有覆盖核对呈现。模型未发布时 MUST 显示治理空态而非样例模型。（RI-S3）

#### Scenario: 已发布模型完整呈现

- **WHEN** 当前工程存在已发布工序模型版本
- **THEN** 页面呈现节点、装备、构件、三类关系与版本徽章，必含五节点覆盖核对全部标出

#### Scenario: 未发布时治理空态

- **WHEN** 当前工程无已发布工序模型
- **THEN** 页面呈现治理空态与"未发布"说明，不渲染任何样例节点

### Requirement: 知识治理四页必须呈现列表、详情与版本事实

机理库、规则集、风险矩阵、措施库四页 MUST 经 `knowledge-modeling.governance-read` 呈现：对象列表（审核状态筛选：草稿/待审核/已发布/已停用）、条目详情（当前精确版本的正文与证据定位）、版本徽章。机理条目呈现机理类型枚举、适用工序、地质水文适用、触发条件/监测征兆/风险事件表达与证据需求；规则集页呈现结构化评分规则与适用规则集成员版本及适用性元数据快照；风险矩阵页呈现矩阵版本网格与分级区间；措施库页呈现措施项适用条件（风险事件/工法/地层/阶段）与资源约束。四页只读，不提供修订、送审、发布、停用或回滚入口。（RI-S4；RA-S2～RA-S4、RA-S7）

#### Scenario: 按审核状态筛选列表

- **WHEN** 用户在机理库页按"已发布"筛选
- **THEN** 列表只呈现该状态条目，条目含版本徽章与审核状态标记

#### Scenario: 详情呈现精确版本正文

- **WHEN** 用户打开任一治理条目详情
- **THEN** 正文来自该精确修订/发布引用，刷新后按同一版本重建，不混入其它修订内容

### Requirement: 检索结果查看页必须只呈现已登记检索事实

检索结果查看页 MUST 作为深链目标，按 URL 中的精确 `knowledgeQueryResultRef` 经 `knowledge-modeling.retrieval-result` 呈现：混合检索的命中列表（条目引用、融合得分、证据定位入口）或关系上下文的邻接节点、依赖边与机理条目入选/筛除及原因。页面 MUST NOT 提供自由文本检索或脱离识别运行的临时检索入口；引用无效或无权时呈现权限/空态骨架。（RI-S5；RA-S3）

#### Scenario: 深链打开混合检索结果

- **WHEN** 用户经深链打开混合检索结果引用
- **THEN** 页面呈现命中列表与策略版本引用，命中证据可打开证据抽屉

#### Scenario: 无临时检索入口

- **WHEN** 审查检索结果查看页的交互元素
- **THEN** 不存在查询输入框或"发起检索"操作，页面只呈现已登记结果

### Requirement: 跨页深链与版本追溯必须使用领域标识

页面间跳转 MUST 使用领域标识深链：资料详情可跳到引用它的业务对象，治理条目详情可经 `trace-chain` 投影查询与结果读取呈现关联对象（如机理条目被引用的风险记录、规则/矩阵版本被引用的评估记录），证据入口就地出现在每个结论与版本旁。跨页跳转不得用页面私有状态搬运业务事实；关联对象区在投影不可用时呈现结构化原因，不降级为编造链接。（RI-S6；RA-S5～RA-S7）

#### Scenario: 治理条目关联对象可点透

- **WHEN** 机理条目详情存在引用它的风险记录
- **THEN** 关联对象区经投影读取呈现记录引用，点击沿深链跳转；无引用时显式呈现空态

#### Scenario: 关联读取失败不编造

- **WHEN** 投影查询或结果读取失败
- **THEN** 关联对象区呈现结构化失败原因与重试，页面主体事实不受影响

### Requirement: 浏览器验收必须使用真实浏览器与正式接缝

系统 MUST 提供可运行的真实 Chromium 验收命令，在 `apps/web` 生产构建与真实 HTTP/授权/投影接缝（真实 PostgreSQL、真实迁移、真实会话登录）上验证：登录、七项业务导航中本 change 页面的可达性、工程切换、权限降级、证据脱敏两态与跨页深链。验收记录 MUST 包含浏览器版本、命令与失败 trace；浏览器或必需服务不可用时 MUST 明确失败，不以 Mock 浏览器、Mock 后端或跳过关键断言代替通过结论。（RI-S61～RI-S65）

#### Scenario: 真实浏览器完成只读链路

- **WHEN** 固定测试环境具备真实 Chromium、PostgreSQL 与已登记夹具事实
- **THEN** 验收从登录走到工程概览、资料详情、监测详情与知识治理页，核对真实事实渲染、无权脱敏与深链跳转

#### Scenario: 环境不可用明确失败

- **WHEN** 浏览器二进制、数据库容器或 API 服务不可用
- **THEN** 命令以非零状态退出并保留失败证据，不把跳过场景计作通过
