# module-interfaces-events-workflows Specification

## Purpose

为 RiskFlow 六个领域模块及应用模块提供闭合、版本化、可运行时校验的跨模块调用、领域事件和有限工作流契约，使后续实现保持事实所有权、权限、幂等、追溯与暂停恢复语义一致。

## Requirements

### Requirement: 六个领域模块只暴露用例级 interface

系统 MUST 为工程数据、知识建模、风险识别、风险评估、预警处置、复核审计六个领域模块分别提供少量用例级命令或查询分支。每个分支 MUST 是闭合的可辨识联合类型，输入和输出只包含调用所需的身份、精确版本、授权上下文、幂等身份和结果引用；不得暴露通用 `execute`、任意仓储/查询器、SQL、文件、URL、JSON Patch 或自由字段袋。工程数据 MUST 以独立的 `StructuredDocumentConversionPortV1` 暴露结构化文档转换，保持既有 `EngineeringDataPortV1` 的分支与签名不变；该转换端口 MUST 以共享 strict Schema 表达 DOCX、文本型 PDF、XLSX、CSV 与 OCR 版面结果输入，使 C12 和 C13 复用同一结构化块、坐标、资料段与失败诊断契约。

工程数据拥有工程资料、资料段、监测与适用性快照；知识建模拥有工序模型、风险机理、检索证据、评估知识与措施的受治理版本；风险识别拥有候选/合并工件、标准化风险记录和关联事实；风险评估拥有评估快照、指标结果和风险评估记录；预警处置拥有预警、处置、预测、反馈、偏差与校准建议；复核审计拥有复核任务、类型化决定和只追加审计。一个模块不得通过 interface 修改另一个模块拥有的事实。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 调用所属模块完成用例
- **WHEN** 调用方提交一个已声明的模块命令或查询分支，并提供合法授权上下文与精确输入引用
- **THEN** interface 返回该分支声明的类型化结果引用或类型化错误
- **AND** 调用方无需了解事务、重试、持久化或第三方协议

#### Scenario: 结构化转换使用独立共享端口
- **WHEN** C12 转换结构化文档或 C13 规范化 OCR 版面结果
- **THEN** 两者调用 `StructuredDocumentConversionPortV1` 并返回相同契约定义的转换、工件、资料段或诊断引用
- **AND** 既有 `EngineeringDataPortV1` 的命令和查询分支保持不变

#### Scenario: 拒绝开放式调用
- **WHEN** 调用方尝试提交未声明的动作、任意对象补丁、存储查询或契约外字段
- **THEN** 运行时 Schema 拒绝该输入
- **AND** 不把未知字段透传给领域实现

#### Scenario: 评估不复制识别事实
- **WHEN** 风险评估模块接收识别产生的风险输入
- **THEN** 输入只引用标准化风险记录的身份与精确版本
- **AND** 不复制或改写风险事件、证据或模型置信度正文

### Requirement: 应用模块只能组合领域 interface

系统 MUST 为 Agent 任务、LangGraph 工作流、查询与交付投影提供独立应用 interface。Agent 任务只管理有界任务与任务产物引用；LangGraph 只管理有限运行、阶段、检查点关联和路由；查询与交付投影只组合已成立事实的只读引用。应用模块 MUST 依赖领域模块公开 interface，领域模块不得反向依赖应用模块、应用、适配器或 LangGraph。

#### Scenario: 工作流通过公开 interface 编排
- **WHEN** 工作流推进识别、评估、预警或处置阶段
- **THEN** 它只提交已声明的领域命令或查询并保存返回引用
- **AND** 不直接读取数据库、Qdrant、文件工件或模块内部结构

#### Scenario: 查询投影不成为事实源
- **WHEN** 查询投影被删除后重建或返回组合视图
- **THEN** 所有业务事实仍由六个领域模块拥有
- **AND** 投影不能反向写回任何领域对象

#### Scenario: Agent 不能越权写事实
- **WHEN** Agent 任务产生任务类型化候选或命令提案
- **THEN** 正式写入仍调用原领域 interface 并重新执行其权限与确定性校验
- **AND** Agent 任务引用不能代替正式业务结果引用

### Requirement: 每次跨模块调用携带冻结授权上下文

每个命令和受保护查询 MUST 携带版本化授权上下文，至少固定发起主体、工程、获准空间范围、资料可见范围、授权策略版本与因果运行引用。接收模块 MUST 在副作用前校验工程作用域和所需能力；下游调用只能保持或收窄授权范围，不能扩大权限。无资料正文权限的调用方可以获得获准的定位与脱敏摘要，但不得通过事件、错误、审计、Agent 或图状态取得正文。

#### Scenario: 获授权调用成功
- **WHEN** 发起主体在目标工程和空间范围内拥有命令所需能力，并可访问输入引用
- **THEN** 模块可以处理该命令并把授权策略版本写入审计关联

#### Scenario: 跨工程调用被拒绝
- **WHEN** 授权上下文的工程与目标实体所属工程不一致
- **THEN** 模块返回不可重试的权限错误
- **AND** 不产生业务事实、领域事件或待通知副作用

#### Scenario: 下游不能扩大证据可见性
- **WHEN** 工作流、Agent 或投影使用比上游更宽的资料范围继续调用
- **THEN** 接收模块拒绝该调用
- **AND** 错误详情不泄露无权资料正文或存在性

### Requirement: 命令、结果和错误具有稳定幂等语义

每个写命令 MUST 携带命令标识和业务幂等键，并使用闭合、类型化的结果联合表达成功、等待、冲突或失败。相同工程、命令类型与幂等键重试同一有效载荷 MUST 返回同一逻辑结果；同键不同载荷 MUST 返回不可重试的幂等冲突。错误 MUST 以稳定代码、类别、可重试性、阶段及精确诊断引用表达，不得要求调用方匹配完整文案，也不得使用开放 `Record<string, unknown>` 详情决定业务路由。

#### Scenario: 重复命令返回原结果
- **WHEN** 调用方以相同作用域、命令类型、幂等键和有效载荷重试已完成命令
- **THEN** 模块返回原业务结果引用
- **AND** 不重复写事实、审计、事务事件或外部意图

#### Scenario: 同键不同载荷冲突
- **WHEN** 调用方复用同一幂等键提交不同的类型化载荷
- **THEN** 模块返回幂等冲突错误
- **AND** 保留原命令与结果不变

#### Scenario: 陈旧版本提交被拒绝
- **WHEN** 命令目标的精确版本已被取代、作废或不再可决定
- **THEN** 模块返回类型化陈旧版本或并发冲突
- **AND** 不把提交静默应用到当前版本

### Requirement: 已入库事实通过事务领域事件衔接

系统 MUST 使用版本化事务领域事件表达已可靠成立的跨阶段事实。事件信封 MUST 固定事件身份、事件类型、契约版本、工程、聚合身份与版本、业务发生时间、系统记录时间、因果/关联运行、生产命令和业务幂等键；事件载荷只包含下游所需的精确事实引用和原因，不复制完整业务记录。业务事实、审计和待发布事件 MUST 原子提交；事件至少一次投递时，消费者 MUST 幂等处理。

事件至少覆盖：资料输入已就绪、标准化风险记录已验收入库、评估输入变化、受治理识别知识基础已发布、受治理评估版本已发布、风险评估记录已入库、预警信息已入库、处置反馈已记录、校准建议已创建、复核已请求和复核已解决。（RI-S14、RI-S53～RI-S56、RI-S62～RI-S65；RA-S4～RA-S7）

#### Scenario: 风险记录事件启动评估候选
- **WHEN** 标准化风险记录通过 RI-S61 完整性检查并与事务事件原子入库
- **THEN** 评估消费者只使用风险记录身份与精确版本创建评估候选
- **AND** 不从事件载荷复制风险事件定义

#### Scenario: 识别知识基础发布事件只携带精确引用
- **WHEN** `retrieval-evidence-base` 经 C16 发布或历史版本重新发布，并形成覆盖 `process-model`、`risk-mechanism`、`standard-library`、`case-library`、`retrieval-evidence-base` 的完整唯一识别知识发布集合
- **THEN** 系统在同一发布事务中产生 `knowledge.identification-basis-published.v1`，以事件信封固定工程、聚合、审计、命令、幂等和版本，并在载荷中固定五类定义及其精确 `KnowledgeReleaseRefV1` 和精确 `RetrievalEvidenceBaseReleaseRefV1`
- **AND** 事件不包含知识正文、证据正文、检索片段、模型响应或契约外自由字段

#### Scenario: 事件发布失败不伪装成功
- **WHEN** 业务事务无法同时保存事实、审计和待发布事件
- **THEN** 整个业务提交失败或回滚
- **AND** 不留下下游不可追踪的孤立事实

#### Scenario: 重复投递不重复产生事实
- **WHEN** 同一事件因至少一次投递语义被重复消费
- **THEN** 消费者以事件身份和业务幂等键返回原处理结果
- **AND** 不重复创建评估、预警、处置任务、索引代际或通知意图

### Requirement: 识别工作流具有 I0 至 I9 的版本化阶段契约

系统 MUST 以 `I0`～`I9` 闭合阶段表示一次有限识别运行：I0 资料准备与输入冻结，I1 知识就绪，I2 工序工作项规划，I3 混合/关系检索与必经 Agent 审阅，I4 五项上下文组装与 RI-S57 专用 LLM 推理，I5 有界结构修复与确定性校验，I6 全运行重复检测与多来源合并，I7 综合置信度与验收路由，I8 业务入库与评估事件，I9 结果汇总。

每阶段 DTO MUST 只携带精确快照、工作项、候选集、正式零结果、Agent 任务、合并计划、复核任务、业务结果、路由、错误或汇总引用；识别分析结果 MUST 用闭合联合区分非空候选成功与正式零结果终态。I0 的 `IdentificationPreparationSnapshotV1` MUST 以非空 `sourceVersionRefs` 和非空 `includedSourceSegmentSetRefs` 冻结资料输入；两个数组 MUST 等长并按相同索引一一对应，每个资料段集合引用 MUST 属于配对的精确资料版本。一次识别运行 MUST 以单个 `IdentificationInputSnapshotV1.preparationSnapshotRef` 引用该聚合准备快照，不得拆成每个资料版本一个准备快照。I0～I9 MUST 完整追踪 RI-S1～RI-S6；任一技术错误不得伪装成业务复核或正式零结果。（RI-S1～RI-S6）

#### Scenario: 识别正常完成

- **WHEN** 冻结输入与知识版本兼容，全部必经 Agent/LLM 和确定性校验完成，且所有合并组均达到终态
- **THEN** 运行依次形成 I0～I9 的阶段结果引用并返回识别汇总
- **AND** 每个已验收合并组只产生一个标准化风险记录版本及评估事件

#### Scenario: 多资料版本形成单个可重放准备快照

- **WHEN** I0 为多个精确资料版本冻结输入，且每个版本都有一个属于该版本的不可变资料段集合引用
- **THEN** `IdentificationPreparationSnapshotV1` 按相同索引保存等长的 `sourceVersionRefs` 与 `includedSourceSegmentSetRefs`
- **AND** I1 仍通过单个 `preparationSnapshotRef` 冻结整组准备结果

#### Scenario: 拒绝不完整或错配的资料段集合引用

- **WHEN** `includedSourceSegmentSetRefs` 为空、与 `sourceVersionRefs` 数量不同，或任一资料段集合不属于相同索引的精确资料版本
- **THEN** I0 在形成准备快照前返回类型化校验失败
- **AND** 不创建有损准备快照或为各资料版本拆分准备快照

#### Scenario: 知识未就绪时暂停

- **WHEN** I1 发现发布版本缺失、停用或与冻结输入不兼容
- **THEN** 运行保存知识准备任务与复核引用并进入等待
- **AND** 恢复时重新校验精确版本，不自动切换到“最新版”

#### Scenario: 争议合并组不阻塞其它组

- **WHEN** I6/I7 中一个合并组等待复核而其它合并组通过全部约束
- **THEN** I8 可以幂等入库其它合格组
- **AND** 运行在 I9 汇总中明确区分已验收、等待复核、拒绝、跳过和失败

#### Scenario: 必经检索审阅失败不降级

- **WHEN** I3 的检索审阅 Agent 预算耗尽或重试耗尽
- **THEN** 相应工作项进入类型化失败
- **AND** 不以基线检索冒充最终检索继续 I4

#### Scenario: I4 返回正式零结果引用

- **WHEN** RI-S57 专用推理返回合法零候选且 C22 已正式登记对应事实
- **THEN** 分析端口返回独立的零结果成功分支，I4 阶段结果只保存该精确零结果引用而不伪造候选集引用
- **AND** 工作流状态、恢复与 I9 汇总均能从该引用回到授权范围内的原始推理证据

### Requirement: 评估工作流具有 A0 至 A9 的版本化阶段契约

系统 MUST 以 `A0`～`A9` 闭合阶段表示一次有限评估运行：A0 输入准备，A1 知识就绪，A2 输入冻结，A3 指标取值，A4 确定性评分与触发判定，A5 评估入库，A6 预警入库与任务归集，A7 处置建议候选，A8 三项约束校验与建议入库，A9 结果汇总。处置效果预测和处置反馈 MUST 作为使用同一图契约的独立有限入口，不跨越数日等待现场动作。

A0～A9 MUST 完整追踪 RA-S1～RA-S7。A3～A6 不创建必经 Agent 任务；P/C、矩阵、四类触发、三项处置约束与业务入库 MUST 由领域模块确定性完成。预警和处置只能在已入库风险评估记录之后推进。（RA-S1～RA-S7）

#### Scenario: 无预警的确定性评估完成
- **WHEN** A3/A4 产生完整 P/C、风险等级和空触发指标集合
- **THEN** A5 原子保存完整风险评估记录并直接进入 A9
- **AND** 不创建预警、处置任务或 Agent 任务

#### Scenario: 预警先入库再通知
- **WHEN** A4 命中一个或多个触发类型
- **THEN** A5 先保存包含触发指标的评估记录，A6 再幂等保存预警与处置任务关联
- **AND** 只有预警可靠入库后才安排通知意图

#### Scenario: 处置候选不能越过三项校验
- **WHEN** A7 形成处置建议候选但 A8 任一确定性约束失败
- **THEN** 候选保持为运行工件并创建复核任务
- **AND** 任何人工决定都不能把失败结果强制标记为正式处置建议

#### Scenario: 反馈运行不自动校准
- **WHEN** 独立反馈入口形成偏差记录且超过冻结阈值
- **THEN** 系统创建有界校准建议 Agent 任务及待审核建议引用
- **AND** 不覆盖当前规则、权重、阈值、区间或矩阵版本

### Requirement: 图状态只保存小型版本化引用

识别、评估和顶层图状态 MUST 由 Zod Schema 定义并派生 TypeScript 类型，固定 schema/graph 版本、运行与线程、触发/入口模式、授权主体引用、阶段、有限状态、快照/工件/业务结果/Agent/复核/路由/错误引用及因果关系。图状态 MUST 拒绝原始文档、完整 JSON-LD、监测序列、完整检索片段、模型响应、业务记录正文、规则正文、建议正文、通用对象袋和模型内部思维链。

#### Scenario: 小型引用状态通过校验
- **WHEN** 状态只包含声明的标识、版本引用、枚举状态、阶段与结果引用
- **THEN** 对应图状态 Schema 接受该对象

#### Scenario: 大对象不能进入检查点
- **WHEN** 调用方把标准化风险记录正文、风险评估记录正文、检索片段或任意未知对象加入图状态
- **THEN** strict Schema 拒绝该状态
- **AND** 调用方必须先把内容交给事实所属模块或工件存储并取得引用

#### Scenario: 检查点不替代业务事实
- **WHEN** 检查点存在但其引用的业务提交不存在
- **THEN** 恢复流程返回结构化不一致错误
- **AND** 不从检查点内容伪造业务记录

### Requirement: 暂停、恢复、重试和取消保持业务事实完整

工作流运行 MUST 使用闭合有限状态表达待运行、运行中、等待、可重试失败、已完成、终止失败和已取消，并用类型化等待原因区分知识准备、人工复核和交互确认。恢复 MUST 沿用原线程、冻结输入、策略、模型、提示模板和业务幂等键；需要更换任一冻结版本时 MUST 创建新运行。取消只停止未开始或可协作终止的工作，不回滚已可靠成立的事实、决定、审计或事务事件。

#### Scenario: 人工复核后幂等恢复
- **WHEN** 复核模块保存指向精确目标版本的类型化决定并发布复核已解决事件
- **THEN** 原线程从等待点恢复并复用已完成工件
- **AND** 不重复调用已完成模型步骤或重复入库

#### Scenario: 技术故障按原策略重试
- **WHEN** 可重试技术错误发生且冻结重试策略仍有预算
- **THEN** 运行在原工作项和原业务幂等键下重试
- **AND** 不切换模型、知识、工具、预算或输入版本

#### Scenario: 取消保留已入库事实
- **WHEN** 用户取消仍在运行的识别或评估流程
- **THEN** 未开始的工作被停止并生成取消汇总
- **AND** 已入库风险、评估、预警、决定和审计仍可追溯

### Requirement: Agent 与人工复核使用不同引用和决定边界

系统 MUST 在既有预警处置 `record` interface 中提供 `acknowledge` 写命令分支。该分支的 strict payload MUST 且只能包含 `warningRecordRef` 与 `warningResponseTaskRef` 两个精确版本引用，并 MUST 沿用公共命令信封的命令标识、业务幂等键、工程、操作者、发起时间和版本化授权上下文；两个引用 MUST 属于同一获授权工程和空间，且任务精确版本 MUST 归集该预警精确版本。成功结果 MUST 是 `{ kind: "acknowledgement", status: "acknowledged", warningRecordRef, warningResponseTaskRef }` 的 strict 分支，只返回已确认配对的精确引用与确认状态。（RA-S6、RA-S7）

- **AND** 不从当前监测流或其它版本自动补齐

#### Scenario: 缺失或错配引用安全拒绝
- **WHEN** 启动缺少无法获权解析的工程修订/历史适用性，单数与集合相冲突，或任一引用跨工程、越空间、版本不相容或不可见
- **THEN** 系统在创建该风险的正式评估准备、P/C 或评估成功事实前拒绝，并如实登记已存在的父运行失败或等待原因
- **AND** 无权与不存在目标对调用方不可枚举

#### Scenario: 多空间识别评估逐项配对
- **WHEN** 一次识别运行覆盖多个空间，调用方为每个空间提供不同的精确适用性快照与监测集合
- **THEN** 每条验收风险只以其空间的配对上下文冻结评估输入
- **AND** 缺少配对空间、重复配对或错误复用别的空间快照时阻断该风险的评估

#### Scenario: 分段入口冻结评估依据
- **WHEN** 预测或正式反馈入口携带精确评估依据集合引用
- **THEN** 父运行将该引用原样冻结并传给独立子运行
- **AND** 缺少该引用时在运行副作用前以入口引用不完整拒绝，不回退到当前发布集

交付归属：缺少评估依据的前置拒绝由 C30 交付；两个入口携带完整合法引用并成功运行的路径由后续 C41 `wire-human-decision-and-feedback-commands` 承接。C30 当前仅证明依据引用解析与冻结，不能据此认定成功路径已实现。

### Requirement: 父运行只以精确识别结果启动独立评估子运行

系统 MUST 使 `identify-and-assess` 入口先建立同工程且当前获权的父运行，再以该父运行身份调用既有识别子图。每条经识别验收的标准化风险记录精确版本 MUST 对应一个独立评估子运行；评估输入只引用该版本，不复制识别事实。父运行 MUST 保存识别、各评估子运行、等待和终态的精确引用，并允许已验收记录推进而其它识别组仍待复核。（RI-S1～RI-S6；RA-S1、RA-S5）

#### Scenario: 多条已验收风险分别评估
- **WHEN** 一次识别运行验收多条标准化风险记录且其它组仍待复核
- **THEN** 父运行按每条精确风险记录幂等建立独立评估子运行并保留待复核引用
- **AND** 重复验收事件或父运行恢复不产生第二个相同子运行或重复评估事实

交付归属：真实 C24 与 C30 同容器的多风险扇出和待复核检查点边界由后续 C40 `fix-c24-nested-graph-interrupt-checkpoint-boundary` 承接；C30 的受控端口切片不得作为本场景通过证据。

#### Scenario: 没有合格风险时不伪造评估
- **WHEN** 识别运行没有已验收风险，或只剩待复核、拒绝、失败记录
- **THEN** 父运行如实保存等待或终态汇总
- **AND** 不以空风险、外部事件或已拒绝候选创建评估子运行

### Requirement: 评估子图按有限入口组合已成立的领域事实

系统 MUST 按公共入口语义冻结同工程、同空间、当前获权的风险输入、适用性、监测、评估依据与运行策略精确版本，并以 `A0`～`A9` 的有限阶段调用已归档的指标取值、确定性评估、预警、处置候选及三项约束用例。`assess`、`reassess`、`historical-backfill`、`forecast-response` 和 `record-response-feedback` MUST 使用各自声明的有限入口，预测、执行和反馈不得跨日等待在同一运行内。缺失、错配、未发布、不可见或超出适用时点的引用 MUST 失败或按既有契约等待，不得选择当前最新值。（RA-S1～RA-S7）

#### Scenario: 无预警的完整评估
- **WHEN** 正式冻结输入经 C25 得到完整评估记录且触发集合为空
- **THEN** 评估运行保存记录和阶段/汇总引用并完成
- **AND** 不创建预警、处置建议或必经 Agent 任务

#### Scenario: 有预警时依次形成处置链
- **WHEN** 已入库评估记录包含一个或多个触发事实
- **THEN** 运行先取得持久化预警与任务引用，再以冻结候选和正式处置结果推进汇总
- **AND** 处置候选任一约束失败时只保留候选和复核/失败引用，不成为正式建议

#### Scenario: 重评估与历史补算保留旧结论
- **WHEN** 显式监测、适用性或评估依据变化触发重评，或以历史业务时点和精确适用性/依据补算
- **THEN** 系统建立新的冻结输入与评估记录，关联前次记录或历史时点
- **AND** 原记录及其 P/C、等级、预警和审计不被覆盖

#### Scenario: 反馈越限只形成校准候选
- **WHEN** 独立反馈入口取得执行后实际评估、正式反馈与偏差，且偏差超过冻结阈值
- **THEN** 系统驱动有界校准建议任务并保留待人工审核的精确引用
- **AND** 不自动发布或覆盖权重、阈值、区间、矩阵或人工决定

交付归属：从合法人工决定、执行后评估到正式反馈的成功路径由后续 C41 承接；C30 已成立反馈引用之后的偏差与待审校准切片可独立核验，不代表该入口成功路径已闭合。

### Requirement: 工作流生命周期以耐久业务事实和冻结身份收口

系统 MUST 以公共 `startRun`、`resumeRun`、`cancelRun` 语义只追加记录父子运行身份、输入快照、阶段、路由、等待、错误、汇总、审计及命令回执；LangGraph 检查点只保存公共小型引用状态，不代替业务事实。恢复与可重试故障 MUST 使用原线程、输入、图版本、策略、模型/提示、预算和业务幂等身份；同键异载荷或预期状态版本陈旧 MUST 拒绝。取消只停止未开始或可协作终止的动作，不撤销已成立领域事实。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 等待决定后以原运行恢复
- **WHEN** 精确复核或 Agent 任务完成，且运行仍等待该引用、当前授权有效
- **THEN** 原线程继续并复用已提交阶段结果
- **AND** 不重复模型调用、正式写入、审计或事务事件

#### Scenario: 检查点与业务事实不一致
- **WHEN** 检查点引用不存在的业务提交，或业务提交领先检查点且无法由已登记事实证明
- **THEN** 恢复返回稳定不一致错误并保留已提交事实
- **AND** 不从检查点伪造记录、不猜测最新状态或补写无依据结果

#### Scenario: 取消和技术失败保留追溯
- **WHEN** 父运行或子运行在部分领域事实提交后取消，或在冻结预算内遇到瞬态失败
- **THEN** 已提交事实、审计、事件及父子关联保持可查询，未开始动作被停止或以原身份重试
- **AND** 权限、版本和业务规则冲突不通过自动重试绕过

### Requirement: C30 自有运行与追踪投影有界且只读

系统 MUST 为获权调用方提供 C30 运行视图和链路追踪视图，按当前工程、空间、资料权限和精确版本组合父子运行、识别、评估、预警、建议、偏差与校准的公开事实引用、阶段状态、审计引用及允许披露的证据定位。投影 MUST 可由已成立事实重建，且不得反写领域对象、复制领域正文或直接读取其它模块私有表；投影记录和受保护读取 MUST 使用最小权限与只追加审计。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 已授权调用方查询历史运行
- **WHEN** 调用方按精确父运行或链路目标查询并具备对应工程、空间、资料读取权限
- **THEN** 投影返回版本化父子运行、结论与审计引用，以及其获准的定位或脱敏摘要
- **AND** 后续领域版本发布或投影重建不改变历史链指向

#### Scenario: 无权或跨工程读取不可枚举
- **WHEN** 调用方无权限、目标跨工程/空间或来源资料不可见
- **THEN** 投影在披露目标或证据前安全拒绝或仅返回获准的最小视图
- **AND** 错误、订阅事件和普通日志不暴露受限目标存在性或正文

#### Scenario: 精确结果引用可读取有界内容
- **WHEN** 获权调用方按精确查询结果或风险记录引用请求页面与链路内容
- **THEN** 独立只读接缝返回有界、分页的版本化摘要及获准证据定位
- **AND** 原查询端口签名保持不变，读取不造成跨模块 N+1、全库投影或领域事实反写

### Requirement: 端到端链路可以按精确引用重放

系统 MUST 使每条完整路径从资料段标识、工序节点、风险机理条目、标准化风险记录、评估记录、预警、处置建议至偏差/校准建议均可用领域事实引用、冻结版本、运行阶段、审计与事件证据核验；分支未触发或正式事实尚未成立时 MUST 明示缺席原因，不得补造占位事实。可重复的验收命令 MUST 在真实持久化和公开端口下证明路径、幂等及失败收口。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 完整链路具有耐久证据
- **WHEN** 合成样本、待甲方复核的识别记录和甲方已审核或明确标注版本的评估依据完成预警、建议及反馈/校准路径
- **THEN** 验收可逐跳读取精确引用、证据定位、冻结规则/权重/矩阵版本、决定、审计和事件
- **AND** 同一输入重放不增加正式事实或改变 P/C 与等级

交付归属：真实 C24→C30 同容器链路依赖 C40；人工决定及正式反馈命令成功链路依赖 C41。C30 分段验收与缺席链尾证据不能替代这两段，完整端到端通过结论由后续 change 承接。

#### Scenario: 无触发和失败路径不伪造链尾
- **WHEN** 评估无预警、建议三项校验失败、偏差不可计算或必经 Agent 失败
- **THEN** 追踪结果保留最后成立的事实及类型化原因
- **AND** 不把缺席链尾展示成已产生的预警、建议、偏差或校准结果

### Requirement: C31 工序风险关联图按已成立的精确链边呈现

系统 MUST 使获权调用方以精确主题引用查询工序风险关联图，并分页取得同一工程、同一授权范围内已成立的工序、机理、风险记录、评估、预警、建议及后续反馈关系。节点身份 MUST 来自版本化事实引用，边 MUST 带关系、阶段/审计引用及当前允许披露的证据定位；关系不能被证明时 MUST 明确失败或标注缺席原因，不得补造边、风险等级或领域正文。（RI-S3～RI-S6；RA-S1～RA-S7）

#### Scenario: 获权主题返回可追踪关联图
- **WHEN** 调用方持有当前工程、空间、资料读取权限，并以精确风险记录引用查询已有跨阶段关系
- **THEN** 返回的每条边均指向已成立的版本化事实，包含可核验的关系及审计引用
- **AND** 资料段、工序、机理、风险、评估及后续已成立关系可沿获准引用追踪，不暴露领域正文

#### Scenario: 未触发或未能证明的分支
- **WHEN** 主题所在运行尚未产生预警、建议或反馈，或某条关系的来源资格无法证明
- **THEN** 结果仅呈现最后成立的事实及其已登记缺席原因，或者以稳定的不完整失败收口
- **AND** 不把空链尾、猜测的图节点或推断等级当作正式结果

### Requirement: C31 工程风险总览和报告投影可由同一事实重放

系统 MUST 接受精确工程修订和可选空间范围，以只读方式提供有界的风险总览/报告投影。每项 MUST 由已成立的运行、标准化风险记录、评估及后续结果引用组成，并保留可获准的证据、版本与审计引用；聚合值只能从实际披露的事实计算，不能用链边代替评估记录的 P/C、等级或预警判定。投影 MUST 可在历史时点和原版本组合下重建，不反写领域事实。（RI-S6；RA-S5～RA-S7）

#### Scenario: 同一修订生成一致报告
- **WHEN** 同一调用方按同一工程修订、空间、授权范围与查询结果引用重复读取报告页面
- **THEN** 返回稳定排序的事实引用、已成立结论与可核验审计/证据引用
- **AND** 后续领域发布不改变原查询所指向的历史版本

#### Scenario: 结果缺失或依据不足
- **WHEN** 修订下尚无已成立风险，或风险存在但评估/预警/反馈尚未成立
- **THEN** 返回真实的空结果或最后成立的结果及明确缺席原因
- **AND** 不生成占位评估、预警、处置或所谓默认风险等级

### Requirement: C31 投影读取保持当前权限、有限读取与既有端口兼容

系统 MUST 通过既有查询登记和独立有界读取接缝交付关联图、总览与报告结果；公共查询/结果类型仅作加法式扩展，既有运行视图与链路追踪结果保持原语义。每页 MUST 重新校验当前主体、工程、空间和资料权限，并将游标绑定精确查询结果与授权范围；无权、跨工程、错空间或资料不可见 MUST 在披露目标前安全收口。未知查询类型 MUST 稳定失败；报告数据结果不要求生成文件产物。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 历史查询在撤权后不可继续读取
- **WHEN** 查询登记已成立而调用方随后失去该工程、空间或资料权限
- **THEN** 后续分页不披露历史目标或证据，且与目标不存在的失败对调用方同形

#### Scenario: 有界分页和伪游标
- **WHEN** 图谱或报告超过单页上限，或调用方提交伪造、错查询、错授权范围的游标
- **THEN** 合法游标只取得稳定的下一页，非法游标以稳定错误拒绝
- **AND** 不发生全库投影读取、跨模块逐项查询或因截断而报告伪完整结果

#### Scenario: 旧分支和未知分支
- **WHEN** 调用方继续查询 `run-view`、`trace-chain` 或提交契约未声明的查询类型
- **THEN** 旧分支仍返回原有结果，未知类型被 Schema 或端口稳定拒绝
- **AND** 查询不写入领域对象或扩大既有权限能力

### Requirement: C30 加法式证明决定所需的真实路由与运行

系统 MUST 由工作流所有者提供独立、strict 且有界的只读证明，按工程和精确正式建议引用读取已经登记的路由决定、预测运行、空间及冻结输入身份。读取只允许使用既有 C30 持久运行事实，必须核对引用、正文、运行状态和摘要一致；不得从当前最新状态、客户端字段、任意图检查点或其它工程合成绑定。现有 `WorkflowPortV1` 写命令和 `ProjectionPortV1` 查询结果保持原样，新增只读证明不得写入 C30 或 C28 事实。（RA-S7）

#### Scenario: 精确正式建议取得真实决定绑定
- **WHEN** 获授权调用方针对同工程、同空间的正式建议精确版本读取已登记决定路由与预测运行
- **THEN** C30 返回匹配该建议的路由决定、运行、空间、版本和审计引用
- **AND** C28 可据此对账人工决定命令，不需要调用方伪造运行身份

#### Scenario: 事实缺失、越权或内容不一致时失败关闭
- **WHEN** 目标路由或运行尚未成立、跨工程或空间、当前授权不足，或持久引用与正文/运行状态不一致
- **THEN** C30 返回安全的类型化失败，不披露目标存在性或内部正文
- **AND** 不创建路由、运行或默认引用来满足读取

### Requirement: C30 预测运行允许人工采纳前等待

系统 MUST 允许 C41 通过公共 `WorkflowPortV1.startRun` 以精确正式建议和决定幂等身份创建真实的 `forecast-response` 运行，并在人工采纳事实形成之前停留在等待态；此时不得执行预测、形成正式效果预测或自动提交采纳。重复的同一命令身份 MUST 返回同一运行引用，采纳成立后才按既有触发语义继续。若现有入口需要表达等待意图，只允许增加不改变原有调用方默认语义的可选闭合参数。（RA-S7）

#### Scenario: 采纳前等待与幂等重放
- **WHEN** C41 针对同一工程、正式建议和决定幂等身份调用 `startRun`，随后在 C28 决定提交前重试
- **THEN** C30 返回同一精确运行引用，并保持等待、不执行效果预测
- **AND** C41 可在采纳事实成立后通过既有恢复语义推进该运行

### Requirement: C32 查询结果再读取必须有界且复验当前授权

系统 MUST 为 engineering-data 已登记查询提供只读结果再读取：调用方提交精确 `queryResultRef`，服务端按登记时的授权摘要复验当前调用方授权，仅对 `source-segments` 返回段集正文与来源访问授权引用，仅对 `evidence-access` 返回有界证据条目（证据引用、来源版本引用、段集引用、访问授权引用与获准段正文），仅对 `monitoring-snapshot` 返回该快照的监测结果。再读取 MUST 复用拥有方既有校验实现，不重新执行查询、不产生新业务事实、不返回登记范围之外的条目；引用不存在、查询类型不符、授权摘要漂移或当前调用方越权时 MUST 返回同形安全失败，不披露目标存在性。（RI-S1～RI-S2；RA-S1）

#### Scenario: 授权一致时返回登记范围内的正文

- **WHEN** 调用方持有精确 `queryResultRef` 且当前授权与登记授权摘要一致
- **THEN** 按登记的查询类型返回对应内联结果，条目集合与登记时一致，重放得到同一内容

#### Scenario: 越权、漂移或类型不符同形失败

- **WHEN** 引用不存在、属于其它工程、授权摘要漂移、当前授权被撤销，或该引用登记的查询类型与请求读取分支不符
- **THEN** 返回同形安全失败，响应不可用于区分目标是否存在或属于哪种查询

### Requirement: C32 工程上下文与资料监测目录只读必须有界

系统 MUST 提供三类只读目录：工程上下文读返回当前工程身份、当前工程修订引用、适用性元数据（施工工法/地层条件/工程阶段三维度）与空间区段树；资料目录按工程返回有界分页的资料版本条目（来源版本引用、类型、形成时间、来源单位、解析状态与清洗可用性摘要）；监测目录按工程返回有界分页的监测序列条目，并按精确序列引用返回其批次与冻结快照列表。列表页大小 MUST 有上界（不超过 50）并使用稳定游标；每条目 MUST 在返回前按当前授权复验工程、空间与资料可见性；无权、跨工程或不存在的目标 MUST 同形失败且不可枚举。目录只组合拥有方既有登记事实，不反写领域对象。（RI-S1；RA-S1）

#### Scenario: 获授权调用方读取目录页

- **WHEN** 调用方在当前工程具备读能力并请求目录首页或后续游标页
- **THEN** 返回有界条目与稳定下一游标，条目只含获准摘要，重复读取不追加业务事实

#### Scenario: 清洗可用性摘要来自已成立清洗事实

- **WHEN** 资料版本已有正式清洗结果
- **THEN** 目录条目呈现其可用性判定（可用/部分可用/不可用）与排除计数；无正式清洗结果时显式标注未清洗，不猜测状态

#### Scenario: 越权或跨工程不可枚举

- **WHEN** 调用方请求其它工程目录、被撤销授权后再次请求，或翻页游标指向已不可见区段
- **THEN** 返回同形安全失败，不返回条数、名称或存在性线索

### Requirement: C32 知识治理只读必须覆盖列表、精确读取与当前发布集合

系统 MUST 为受治理定义提供只读取面：按工程与定义类型（`KnowledgeDefinitionTypeV1` 全集）列出有界分页的定义条目，支持按治理生命周期状态（草稿/待审核/已发布/已停用）与关键字筛选，条目含定义标识、当前修订/发布引用、审核状态与版本摘要；按精确修订引用或发布引用返回该版本的条目正文（机理条目、工序模型、结构化评分规则、适用规则集、风险矩阵、措施库等各自的已治理形态）；按工程返回当前治理发布集合引用。已发布版本 MUST 只读且不可变，返回内容 MUST 可由该精确版本重放；列表不返回正文；无权、跨工程或不存在目标 MUST 同形失败。该读面 MUST 由知识治理拥有方实现，不得由调用方直读治理私有表，不得反写治理事实。（RI-S3～RI-S4；RA-S2～RA-S4、RA-S7）

#### Scenario: 按类型与状态筛选定义列表

- **WHEN** 调用方在当前工程具备知识读能力并按定义类型、生命周期状态或关键字请求列表
- **THEN** 返回有界条目与稳定游标，条目只含标识、版本与审核状态摘要，关键字只匹配获准条目

#### Scenario: 精确版本读取可重放

- **WHEN** 调用方按精确发布引用读取机理库或风险矩阵版本
- **THEN** 返回该版本完整条目正文，同一引用重放得到同一内容；发布后任何时刻读取不回退到旧版本也不混入新修订

#### Scenario: 越权或不存在同形失败

- **WHEN** 调用方请求其它工程的定义、无知识读能力，或引用不存在
- **THEN** 返回同形安全失败，列表与精确读取均不可用于推断目标存在性

### Requirement: C32 检索结果再读取必须限于已登记检索事实

系统 MUST 为 `hybrid-evidence` 与 `relationship-context` 已登记检索结果提供只读再读取：调用方提交精确 `knowledgeQueryResultRef`，服务端复验当前授权与登记授权摘要后返回对应载荷——混合检索返回有界命中列表（条目引用、融合得分、证据定位）与策略/代引用，关系上下文返回邻接工序节点、依赖边、入选与筛除机理条目及筛除原因。再读取 MUST 复用拥有方既有读取实现，不触发新检索、不调用模型、不产生新事实；引用不存在、类型不符或越权时同形失败。界面 MUST NOT 经此读面发起脱离识别运行的临时检索。（RI-S5；RA-S3）

#### Scenario: 授权一致返回检索载荷

- **WHEN** 调用方持有精确检索结果引用且授权摘要一致
- **THEN** 按登记类型返回混合命中或关系上下文载荷，重放内容一致

#### Scenario: 越权或类型不符同形失败

- **WHEN** 引用不存在、跨工程、授权漂移，或以混合结果引用请求关系上下文读取
- **THEN** 返回同形安全失败，不披露检索是否发生或命中数量

### Requirement: C32 投影结果读取必须沿既有端口语义公开

系统 MUST 为既有 `ProjectionResultReadPortV1.readPage` 提供公开只读通路：输入精确 `queryResultRef`、可选游标与不超过 100 的页大小，输出保持既有 `ProjectionResultReadResultV1` 判别（`queryType` 限于 `run-view`、`trace-chain`、`association-graph`、`risk-overview`；条目为既有 `run-summary`、`trace-link`、`report-fact`、`report-absence` 分支）。通路 MUST 复用端口的授权摘要比对与游标绑定，不改变既有查询登记语义，不引入新的物化结果表，读取不造成跨模块逐项查询或全库投影。（RI-S6；RA-S5～RA-S7）

#### Scenario: 按登记查询分页读取投影条目

- **WHEN** 调用方先经既有投影查询登记，再持 `queryResultRef` 分页读取
- **THEN** 返回该查询类型对应的有界条目与下一游标，条目只含公开事实引用与获准证据定位

#### Scenario: 未登记、漂移或越权同形失败

- **WHEN** 引用未登记、游标被篡改、授权摘要漂移或调用方越权
- **THEN** 返回同形安全失败，不披露登记是否存在或其条目数量

### Requirement: C33 识别运行与风险记录只读必须有界且复验当前授权

系统 MUST 为风险识别域提供四类只读：运行列表按工程返回有界分页的识别运行条目（运行引用、状态、阶段、启动者、启动时间、验收/待复核/拒收计数；触发原因仅在有登记事实时输出，无登记事实时不得伪造）；运行详情按精确运行引用返回该运行的阶段进度（I0–I9）、工序工作项覆盖、合并组与验收路由摘要、关联 Agent 与复核任务引用及结果汇总；风险记录目录按工程返回有界分页的标准化风险记录条目（记录引用、工序节点、风险事件摘要、综合置信度、验收方式、当前效力），支持按工序节点与验收方式筛选；记录详情按精确记录版本引用返回该版本的识别侧正文（七字段、记录信封、证据定位、机理条目与资料来源引用、识别运行引用、验收决定与取代/作废关系）。列表页大小 MUST 有上界（不超过 50）并使用稳定游标；每条目 MUST 在返回前按当前授权复验工程可见性；无权、跨工程或不存在的目标 MUST 同形失败且不可枚举；返回内容 MUST 可由精确版本重放。该读面 MUST 由识别拥有方模块内部组合既有登记事实实现，不反写领域对象、不触发新识别、不调用模型。（RI-S5～RI-S6）

#### Scenario: 获授权调用方读取运行与记录

- **WHEN** 调用方在当前工程具备识别读能力并请求列表首页/游标页或精确详情
- **THEN** 返回有界条目或该精确版本正文，重复读取得到同一内容，不追加业务事实

#### Scenario: 越权或跨工程不可枚举

- **WHEN** 调用方请求其它工程的运行或记录、被撤销授权后再次请求，或引用不存在
- **THEN** 返回同形安全失败，不返回条数、名称或存在性线索

#### Scenario: 等待复核与失败状态如实呈现

- **WHEN** 运行处于等待复核或 Agent 可重试失败状态
- **THEN** 运行详情如实返回该状态、关联复核任务引用或失败阶段与错误码，已入库事实计数不回退，不把暂停或失败伪装为完成

### Requirement: C33 复核队列只读必须携带可决定的精确任务引用

系统 MUST 为复核域提供队列只读：按工程返回有界分页的复核任务条目，每条 MUST 携带完整 `ReviewTaskRefV1`（含复核类型、目标引用与等待运行引用）、复核类型、提交时间与状态；复核对象标签由调用方从目标引用确定性渲染；触发原因仅在有登记事实时输出，不得伪造；目标版本已被取代的任务 MUST 由拥有方计算并标记过期。队列 MUST 支持按复核类型与状态筛选，页大小有上界（不超过 50）并使用稳定游标；条目在返回前按当前授权复验；无权、跨工程或不存在 MUST 同形失败且不可枚举。该读面 MUST 由复核审计拥有方实现，只组合既有复核任务与决定登记事实，不反写、不代为决定。（RI-S6）

#### Scenario: 队列条目足以构造既有决定命令

- **WHEN** 获授权复核人读取队列页
- **THEN** 条目携带的完整任务引用可直接作为既有 `decide-review` 命令的 `reviewTaskRef`，无需第二次取数

#### Scenario: 过期任务显式标记

- **WHEN** 任务目标版本已被更新版本取代
- **THEN** 条目携带过期标记，调用方无需自行比对版本

#### Scenario: 越权或不存在同形失败

- **WHEN** 调用方无复核读能力、请求其它工程队列或游标指向不可见区段
- **THEN** 返回同形安全失败，不披露任务数量或类型分布

### Requirement: 受保护读端口必须以当前调用的领域标识复验签发身份

投影查询与结果再读取端口（`ProjectionPortV1.query`、`ProjectionResultReadPortV1.readPage`）与风险记录窄读端口（`RiskRecordTraceReadPortV1.readBatch`）在复验授权上下文时，MUST 使用当前这次领域调用的调用标识（查询的 `queryId`）与当前调用入口的路由 branch 作为复验身份对——与 C06 归档语义（`invocationId` 即该次调用的 commandId/queryId/toolCallId，verify 精确绑定 branch）和 HTTP 外壳按路由 branch 以领域 `queryId` 签发的规则配对。端口 MUST NOT 由 capability 反推 branch（能力位与 branch 一对多），也 MUST NOT 使用没有配对签发方的派生身份字符串；确需派生身份的进程内配对（签发方与复验方使用同一导出函数）不受本条限制。复验失败 MUST 维持既有同形失败闭合语义，不因此条改变任何数据可见性判断。（RI-S6；RA-S5～RA-S7）

#### Scenario: HTTP 签发的授权可通过投影复验

- **WHEN** 调用方经 HTTP 提交投影查询，服务端以该查询的领域 `queryId` 签发授权上下文
- **THEN** 投影端口复验该上下文成功，查询进入既有的可见性判断与登记流程，不在数据判断之前失败闭合

#### Scenario: 结果再读取以本次调用身份复验

- **WHEN** 调用方经 `projection.result-read` 分页读取已登记查询结果
- **THEN** `readPage` 以这次读取调用的 `queryId` 复验授权，授权一致则返回登记范围内条目，授权漂移或越权仍同形失败

#### Scenario: 无配对签发方的派生身份不得复现

- **WHEN** 审查投影与窄读端口的复验实现
- **THEN** 不存在仅由复验方自造、无任何生产签发方配对的 `invocationId` 派生字符串

### Requirement: 评估候选公共输入与授权调用身份必须闭合

评估候选读取 MUST 使用 strict 操作判别输入：C11 适用性目录要求精确工程修订与空间，外部事件目录要求精确空间且拒绝工程修订字段；C25 pending-catalog 的外部事件分支要求空间，风险记录分支可选空间，均拒绝工程修订字段。C25 对每次 C11 目录读取 MUST 以该次 queryId 与精确 branch 签发下游授权，并只保持或收窄当前已验证范围；拒绝必须返回闭合类型化失败。（RA-S1；RI-S14）

#### Scenario: strict 输入拒绝缺失与伪造范围
- **WHEN** 外部事件候选缺少空间，适用性目录缺少工程修订，或外部事件目录携带工程修订
- **THEN** 公共 Schema 拒绝输入
- **AND** 风险记录候选仍允许省略空间

#### Scenario: 两类入口目录各自获得配对授权
- **WHEN** C25 entry-context 组合适用性与外部事件目录，或 pending-catalog 读取外部事件
- **THEN** 每次 C11 调用的 queryId 与 C06 签发 invocationId 完全一致
- **AND** 业务空间修订映射到当前已验证的同一授权空间身份，不扩大工程、空间或资料范围

#### Scenario: 下游拒绝保持公共失败语义
- **WHEN** 当前授权或下游目录读取被拒绝
- **THEN** C25 返回类型化失败，不报告成功空目录且不抛出未闭合异常

### Requirement: 评估候选来源授权必须通过所属事实有界继承

系统 MUST 由 C11 提供有界窄读取，以 C25 当前读取的原调用身份和 risk-assessment.read 授权复验工程、主体与空间，将当前已验证的来源授权引用定位为精确来源版本，最多 256 项。C25 MUST 仅用这些版本重签每次目录授权并检查空间及来源授权保持或收窄原范围；定位不得读取跨域私表、产生业务写入或增加页面必填字段。（RA-S1；RI-S14）

#### Scenario: 真实来源范围继承
- **WHEN** C25 当前授权包含外部事件证据所需的来源授权，且对应 C11 就绪来源登记存在
- **THEN** C11 返回匹配来源版本，C25 以这些版本为每个目录签发配对授权，外部事件目录可以复验实际来源
- **AND** 页面无需提交额外来源版本字段

#### Scenario: 缺失错配或越界来源不得继承
- **WHEN** 来源授权已撤销、登记不存在或引用错配，或者下游签发包含原范围外的来源授权或空间
- **THEN** 读取返回安全类型化失败，不补成全工程资料权限或成功空目录

#### Scenario: 无来源授权保持空范围
- **WHEN** 当前获权上下文没有来源授权引用
- **THEN** 定位返回空来源集合，不扫描工程资料以自动扩大授权
