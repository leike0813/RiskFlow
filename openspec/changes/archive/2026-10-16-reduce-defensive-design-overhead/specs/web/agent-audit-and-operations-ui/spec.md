## MODIFIED Requirements

### Requirement: Agent 三种视图必须共享同一任务及有界刷新

停靠栏、工作台和详情 MUST 共享工程内精确任务选择及单在途刷新，显示任务进度、动作、预算、校验、提案和结果。详情直接读取目标任务，不依赖目标在当前列表页；旧长编号正常可读，分页能够处理系统实际生成的游标。读取失败显示明确错误和重试入口；切工程、注销、隐藏或终态按现有规则停止和清理刷新。

#### Scenario: 停靠与全屏共享任务

- **WHEN** 用户从一个任务的停靠栏展开全屏并打开任务详情
- **THEN** 三个视图指向同一任务版本、预算台账和候选结果，最多存在一个该任务的刷新请求

#### Scenario: 预算或确定性拒绝

- **WHEN** 任务预算耗尽、授权撤销或候选被确定性拒绝
- **THEN** 界面呈现安全原因、校验及预算事实，不显示跳过、换模型、扩预算或强制接受操作

#### Scenario: 旧任务直接打开

- **WHEN** 用户从历史深链进入不在列表第一页的任务
- **THEN** 直接加载该任务及动作，不先在第一页查找

#### Scenario: 正常游标可翻页

- **WHEN** 列表产生超过旧512字符的合法分页编码
- **THEN** 下一页正常显示，页大小仍受限

#### Scenario: 故障有明确反馈

- **WHEN** 任务读取返回系统异常
- **THEN** 结束加载并显示错误、重试及定位信息
