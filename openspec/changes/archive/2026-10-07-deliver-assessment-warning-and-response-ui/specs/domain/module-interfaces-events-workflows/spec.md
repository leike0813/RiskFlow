## ADDED Requirements

### Requirement: C34 评估只读端口必须解释精确版本并提供有界候选

系统 MUST 提供独立风险评估只读端口，包含评估候选、启动上下文、记录目录、精确记录解释和重评历史的闭合操作，复用既有风险输入 XOR、风险评估记录、版本/证据/错误 Schema。目录 MUST 有界分页并限定当前授权空间；启动上下文只提供已成立输入引用和部署注入的运行策略，不创建快照。解释 MUST 由评估所属模块读取保存的实际值、决策工件与冻结准备/输入，矩阵定义由知识所属接口读取；识别与外部输入由各自所属公共读取接缝验证，不跨表反查。（RA-S1～RA-S6）

所有成功读取，包括显式版本解析，MUST 返回当前已验证主体与最多八项动作可用性。启动上下文的图版本和重试策略 MUST 与既有启动命令使用同一种精确版本引用形状，调用方可原样提交，不补造引用种类。pending-catalog 的外部事件分支 MUST 选择精确空间，风险记录分支空间可选；两分支均不要求或接受工程修订。下游目录 MUST 逐次使用与签发身份一致的 queryId，并保持或收窄当前已验证权限范围。

#### Scenario: 有界目录与精确解释
- **WHEN** 获授权用户查询一个候选页或精确记录版本
- **THEN** 返回有界条目或真实冻结解释，游标绑定工程、筛选与授权作用域
- **AND** 不改历史记录、不读取全库再由 UI 截断

#### Scenario: 版本权限或解释不完整
- **WHEN** 输入跨工程、授权失效、引用错配、解释缺失或超界
- **THEN** 返回既有类型化安全失败
- **AND** 不解析 latest、不重新评分或用当前发布补齐

#### Scenario: 预览策略可原样启动
- **WHEN** 获授权调用方取得可用的启动策略与完整登记输入
- **THEN** 图版本与重试策略引用可原样用于既有启动命令
- **AND** 无需包装、解包或猜测策略引用种类

### Requirement: C34 重评入口事实必须原样保存并可恢复

系统 MUST 在重评产生运行副作用前固定精确前驱、调用方显式原因及一至六十四项变化引用，并在既有运行工件与登记事务中保存。父运行、评估子运行、等待/失败恢复和历史解释 MUST 使用同一入口事实；变化引用不得由冻结输入并集反推或被静默裁切。公开原因使用既有工作流原因集合，进入评估用例时只作明确的原因码映射，不按引用类别重新判断原因。工程、空间、来源授权及历史不可变约束保持成立。（RA-S1、RA-S5～RA-S7）

运行入口身份 MUST 区分不同前驱、显式原因或变化集合。原命令身份与原载荷重试返回同一运行；同键异载荷 MUST 在创建另一运行或调用评估前失败。已保存输入只包含精确引用，不复制领域正文。

#### Scenario: 重评原因和变化引用经过恢复仍一致
- **WHEN** 重评在运行中等待或失败，随后按合法精确运行引用恢复
- **THEN** 父子运行和历史解释保留原前驱、原因及变化引用，评估用例取得与该原因对应的既有码
- **AND** 矩阵变化不会被解释为适用性变化，变化引用不会混入全部基础输入

#### Scenario: 原因或前驱变化不会复用旧入口
- **WHEN** 新命令改变前驱、原因或变化集合，或者原幂等键被用于不同载荷
- **THEN** 新身份的合法命令使用相应入口，原键异载荷安全失败
- **AND** 不复用错误运行，不覆盖原入口事实

#### Scenario: 缺失历史重评事实时失败闭合
- **WHEN** 已保存重评记录没有可核对的原入口元数据，或父子入口事实错配
- **THEN** 精确解释或重评历史查询返回既有安全失败
- **AND** 不从引用数量、准备快照触发码、checkpoint 或当前配置补猜原因及变化引用

#### Scenario: 不使用监测输入时仍可冻结入口
- **WHEN** 合法初评或重评无需监测输入且未提交监测引用
- **THEN** 入口按已声明的无监测语义继续冻结与运行
- **AND** 显式空数组和互相冲突的监测引用仍被拒绝，不自动选择快照

### Requirement: C34 预警处置只读端口必须组合所属事实

系统 MUST 提供独立预警处置只读端口，包含预警/任务有界目录、预警/任务精确详情、建议、预测、执行、反馈偏差和校准精确读取。各拥有方 MUST 解析自身保存的 Schema 并经公开只读接缝组合；应用组合层不得直接读取跨域私表或原始模型响应。任务状态保持 open/closed，确认、采纳、执行、反馈和校准保持独立引用；通知只披露当前用户获准事实，未投递意图不等于送达。（RA-S6～RA-S7）

所有成功读取，包括显式版本解析，MUST 返回当前已验证主体与最多八项动作可用性；读授权不得被当作写授权。

#### Scenario: 所属事实经公开接缝组合
- **WHEN** 用户读取一个有合法预警与反馈链的任务或建议
- **THEN** 返回精确且有界的领域结果、确认/决定/执行/反馈关联与获准解释
- **AND** 缺席关系显式呈现，未越限偏差不生成公共校准记录

#### Scenario: 非法读取不泄露存在性
- **WHEN** 目标不存在、跨工程、无空间/来源权限或调用方请求契约外字段
- **THEN** 输入被拒绝或返回不可枚举失败
- **AND** 不暴露正文、私有状态、SQL 或目标计数

### Requirement: C34 态势摘要与 C31 历史投影必须保持独立口径

系统 MUST 保留既有风险总览投影的查询登记、精确结果引用、查询时点和有界分页。新增评估与预警任务摘要 MUST 只描述当前获准空间的已入库评估记录版本及开放任务关联事实，明确统计时点和口径；不得覆盖既有历史投影、改变报告重放输入，或将不同口径相加为风险事件总数。运行和证据链 MUST 继续从原投影取得，P/C 与阈值解释从所属精确记录取得。（RI-S6；RA-S5～RA-S7）

#### Scenario: 当前摘要与历史引用同时可读

- **WHEN** 获授权用户读取当前态势摘要及原风险总览的一页事实引用
- **THEN** 各来源分别返回其统计时点或精确查询结果，并按自身授权与分页规则呈现
- **AND** 当前新增领域事实不改写原查询的历史内容

#### Scenario: 独立来源失败不冒充完整态势

- **WHEN** 一个摘要或历史投影来源失败、权限失效或仍有后续页
- **THEN** 对应来源显示失败或可继续分页，其它来源保持各自有效范围
- **AND** 不用当前计数替代历史投影，不循环读尽投影取得全工程总量
