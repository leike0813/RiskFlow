# GAP-041 系统管理六动作无能力位映射，动作级门控缺身份信号

- 类别：G2 契约字段
- 相关页面：P-OP-01

## 缺口

系统管理六动作无能力位映射，动作级门控缺身份信号

## 依据

demo/v2/src/app/contract-mirror.data.json（systemAccessActions 与 branchCapability 无交集、roles[system-administrator] 为空数组）；packages/core/src/access/policy.ts:42-49（SYSTEM_ACCESS_ACTIONS_V1）

## 预设

P-OP-01 动作名严格取 SYSTEM_ACCESS_ACTIONS 六项；三态判定为：capabilities 为 null 时 unknown，能力并集为空集（仅 system-administrator）时 allowed，其余角色 denied 并附原因「需系统管理员身份」。不用能力位近似（GAP-015 的项目管理四动作才用 engineering-data.write 近似）。

## 待确认

系统管理动作的身份信号是否由会话/角色显式传入页面（而非以空能力集代理）；是否在契约中登记系统管理面的授权通道。

## 风险

以「能力并集为空」代理系统管理员身份是原型期启发式；若将来出现其他空能力角色，门控语义会漂移。
