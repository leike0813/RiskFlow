## 2. 全局画布与应用框架

### 2.1 画布

- 画布：1920×1080，16:9，sRGB，不透明背景；最终交付 PNG。
- 截图只包含应用，不包含浏览器标签栏、地址栏、操作系统任务栏或设计工具边框。
- 以 100% 缩放检查；页面不得出现滚动条、被遮挡内容或鼠标悬停态。
- 页面固定左侧导航和顶部工程上下文。五张图的框架、项目、区段、工序与数据时点完全一致。

## 3. 视觉设计令牌

### 3.1 色彩

| 用途 | 色值 | 使用范围 |
|---|---|---|
| 导航底色 | `#0E2238` | 左侧导航与品牌区 |
| 顶栏底色 | `#15324D` | 工程上下文顶栏 |
| 工程蓝 | `#2166D1` | 当前导航、主按钮、运行中状态、主图表 |
| 深正文 | `#172B4D` | 标题与关键字段 |
| 次正文 | `#63758A` | 字段名、说明和时间 |
| 页面底色 | `#F3F6FA` | 主画布 |
| 卡片底色 | `#FFFFFF` | 业务卡片、表格和图表 |
| 边框 | `#DCE4EE` | 卡片与分隔线 |
| I级/红色预警 | `#D9363E` | 仅用于 I 级风险、越限和红色预警 |
| II级风险 | `#F97316` | II 级风险 |
| III级风险 | `#E7AC08` | III 级风险；浅底时使用深色文字 |
| IV级风险 | `#20A464` | IV 级风险 |
| 完成 | `#1B9A6C` | 图节点完成、校验通过 |

风险红、橙、黄只表示风险等级、越限和预警。普通数量卡、选中状态、LangGraph 运行状态使用工程蓝；不要把红色当装饰色。

### 3.2 字体与密度

- 字体栈：`Inter, "Noto Sans SC", "Microsoft YaHei", sans-serif`。
- 页面标题：24 px / 32 px，600；关键数字：32–36 px / 40 px，700。
- 卡片标题：16 px / 24 px，600；正文和表格：14 px / 22 px；辅助信息不得小于 12 px。
- 页面标题区高 40–44 px；卡片内边距 20 px；卡片间距 16 px；小元素间距遵循 8 px 基线。
- 卡片圆角 8 px，1 px 弱边框，阴影最多 `0 2px 8px rgba(18, 45, 72, .06)`；不要玻璃拟态、霓虹描边和大面积渐变。
- 关键结论最多两行；表格单元格最多两行；超出内容以省略号截断，禁止缩小字号硬塞。

### 3.3 通用组件

- 风险等级：实心小标签，格式为 `I级风险`，不得只显示颜色圆点。
- 预警状态：图标 + `红色预警 · 待处置`，与风险等级标签分开。
- 证据引用：文档图标 + 资料段标识 + 证据名称；标识使用等宽数字样式。
- 版本：中性描边标签，例如 `规则集 V1.3`；版本标签不使用风险色。
- 状态：运行完成使用绿色对勾；运行中使用蓝色；人工复核使用紫灰；失败使用红色。
- 图标使用同一套 18–20 px 线性图标，不使用 Emoji、3D 图标或照片素材。

   - 开头两句：“当前工序识别到 1 项 I 级风险。地表沉降、支护结构变形和注浆压力共同满足预警条件，建议进入现场确认与处置。”

   - 输入框占主要宽度，预置占位“继续询问当前风险…”；发送按钮使用工程蓝。

   - `RUN-20260827-001`、状态“已完成”、本地推理 `Qwen3.8-27B`。
   - 显示 `riskFlowGraph V1`，不显示未经实测的耗时或 token 数。

   - 纵向五步：加载工程上下文；完成风险识别与证据校验；完成适用规则匹配与 P/C 计算；生成预警与处置建议；结果和运行记录已关联入库。
   - 每步使用绿色对勾和可审计动作名称；不显示推理草稿、内部提示词或“思考中”。
