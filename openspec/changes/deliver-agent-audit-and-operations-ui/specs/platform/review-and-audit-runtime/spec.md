## ADDED Requirements

### Requirement: C35 复核详情与活动读取必须有界且不复制上游正文

系统 MUST 提供精确任务详情和按工程、可选主题、类型/结果及固定记录时点分页的活动读取。详情保留原任务/目标/快照/策略/等待运行/决定引用与状态，活动组合 C03 业务、C06 安全和 C07 拒绝事实并使用类型化安全参数。读取 MUST 在定位对象前复验当前授权，来源资格不能证明时失败关闭；不得复制候选、规则、证据正文或扩大现有五类决定与事务语义。

#### Scenario: 任务详情足以提交精确决定
- **WHEN** 获权复核人读取 pending 任务
- **THEN** 返回原完整任务引用及状态、决定所需引用和当前动作可用性，不以队列索引或 latest 重建目标

#### Scenario: 业务安全和拒绝活动续页
- **WHEN** 同一时间边界内活动超过单页上限
- **THEN** 游标沿固定排序且绑定筛选、工程、主体及授权，后续新增活动不污染本次历史分页

#### Scenario: 脱敏与独立失败
- **WHEN** 某活动参数不可安全披露、来源资格不足或调用方已失去权限
- **THEN** 不返回任意 payload/错误正文，不用只包含审计引用的 trace 结果冒充活动明细
