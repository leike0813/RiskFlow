## MODIFIED Requirements

### Requirement: 校准入口只接受精确且已越限的偏差事实

系统 MUST 通过 C28 公共只读接缝按工程、稳定身份和精确版本读取私有偏差事实，并在启动校准任务前验证当前 C06 授权、`thresholdExceeded=true`、处置建议、冻结评估输入、目标指标、阈值策略和证据链均闭合。系统 MUST 由该不可变事实确定性派生公共 `DeviationRecord` 的标识和首版本；相同事实不得派生不同身份，未越限、错工程、越权、缺失或不完整事实不得启动任务或创建公开记录。（RA-S7）

校准 Agent、模型、提示及预算策略 MUST 在本校准阶段从指定运行清单冻结，原评分快照只提供风险输入与评分依据，不提前要求校准配置。

#### Scenario: 已越限事实进入校准

- **WHEN** 获授权调用方提交同工程、精确版本、证据完整且 `thresholdExceeded=true` 的偏差事实引用
- **THEN** 系统形成稳定的公共偏差记录引用并冻结校准输入
- **AND** 重试读取相同事实得到同一公共记录身份

#### Scenario: 冻结评估输入与目标依据精确匹配

- **WHEN** C28 偏差事实引用的 C25 精确输入快照属于同一工程和空间，且调用方提交的依据集合、目标发布和内容摘要均与 C25 窄读投影一致
- **THEN** 系统才可冻结校准输入并继续读取目标正文
- **AND** 相同命令重放复用同一冻结工件和公共记录身份

#### Scenario: 其它有效依据不能替代冻结依据

- **WHEN** 调用方提交同工程另一份有效依据集合或目标发布，或者快照缺失、版本陈旧、跨工程或跨空间
- **THEN** 系统拒绝且不创建冻结工件、Agent 任务、校准建议或公开记录
- **AND** 不仅凭调用方提供的 release set 引用组装校准快照

#### Scenario: 未越限事实不进入校准

- **WHEN** 精确偏差事实的 `thresholdExceeded=false`
- **THEN** 系统返回稳定的不适用结果且不创建 Agent 任务、校准建议、公开偏差记录或复核任务

#### Scenario: 无权或错配事实不可枚举

- **WHEN** 授权过期、被撤销、分支或工程不匹配，或者偏差事实不存在、版本错误或证据不完整
- **THEN** 系统在披露事实正文或产生业务副作用前失败关闭
- **AND** 不改读 latest、其它工程事实或重新计算偏差来补足
