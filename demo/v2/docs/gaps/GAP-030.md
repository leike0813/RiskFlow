# GAP-030 标准化风险记录封套无 evidenceReferences 字段

- 类别：G2 契约字段
- 相关页面：P-RI-05、P-RI-06

## 缺口

标准化风险记录封套无 evidenceReferences 字段

## 依据

packages/contracts/src/records/index.ts:38-59（封套仅 record.evidenceLocator 单值定位与 sourceIds）；demo/v2/src/content/identification.ts（RISK_RECORDS 的 evidenceReferences 投影）

## 预设

v2 在记录视图层提供 evidenceReferences 投影（evidenceLocator 定位 + sourceIds 对应资料版本展开），页面证据卡从投影渲染；封套本身不新增字段。

## 待确认

封套是否固化多证据引用（I8 入库时写入验收时刻证据集快照），还是维持单值 + 投影派生。

## 风险

若生产端封套扩展，投影层需一次性切换到封套字段，无运行时影响。
