## ADDED Requirements

### Requirement: 精确对象读取与分页使用业务必要输入

HTTP MUST 沿用当前会话、闭合路由和原请求信封。精确查询及报告读取的来源范围由所属服务端解析，客户端只提供对象引用、分页及业务参数；目录和新业务输入仍按明确筛选处理。合法游标 MUST 不受额外 512 字符门槛阻断，请求大小、页大小、结构和所属查询检查保持。

#### Scenario: 已有报告直接读取

- **WHEN** 当前合法会话按精确引用读取报告，未重建历史来源选择
- **THEN** 服务端按实际来源检查当前权限并正常返回，客户端不能提交授权决定

#### Scenario: 合法长游标续页

- **WHEN** 服务端生成的合法游标超过 512 字符但请求在既有大小上限内
- **THEN** 结果序列化及下一页请求均正常完成

#### Scenario: 非法输入仍在边界拒绝

- **WHEN** 请求超限、游标结构不符或属于另一查询
- **THEN** 明确失败，不返回跨范围内容
