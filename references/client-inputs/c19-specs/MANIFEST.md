## 4. ⭐【推荐夹具】GB 50911-2013 城市轨道交通工程监测技术规范

### 推荐理由

GB 50911-2013 是本次候选清单中**最适合作为 C19「结构化评分规则与适用规则集」真实规范夹具**的唯一选项，理由：

1. **可验证性最强**：
     - 已落盘 189 页 PDF，文件大小 10 052 478 字节；
     - 与 Wikimedia Commons 公共域副本 SHA-1 完全一致（`488e23d812a2007f9b368e4856c7c2fbe4d0c477`），可独立复算校验；
     - 全文 PDF 由住建部 + 国标委官方发布、中国建筑工业出版社出版，链路可追溯。
2. **许可最清晰**：
     - 强制性国家标准，依据原《国家版权局权司〔1999〕50 号》及《强制性国家标准管理办法》第 51 条，不适用中国著作权法第 5 条，**可视为公共域**；
     - 无需登录、无需付费、无需绕过任何限制；可合法入库与归档。
3. **可同时支撑 C19 验收夹具的六类证据需求**：
     - **适用条件**：第 4 章明确监测范围适用于「城市轨道交通新建、改建、扩建工程及运行维护」的明挖、矿山法、盾构法、盖挖法等多种工法；适用条件随施工阶段和工程部位变化，逻辑与 C19 适用规则集「按工序 + 工法 + 风险机理筛选」一致。
     - **指标项**：第 5–7 章按工程部位（区间 / 车站 / 车辆段）列出监测项目，包括地表沉降、管线沉降、建筑物沉降、围护结构变形、支撑轴力、地下水位、衬砌内力、收敛变形等，与 C19 评估指标体系对应。
     - **评分阈值**：第 10 章规定监测控制值（含「监测预警分级」，通常为三级：预警 / 报警 / 极限）。
     - **分级区间**：监控量控制值分「位移 / 内力 / 应力」三档，对应「安全 / 预警 / 报警 / 极限」四级（具体数值在附录 A–G）。
     - **例外条款**：第 3 章「基本规定」给出监测项目调整、监测点加密 / 减稀、监测频率调整的条件；附录 A–G 给出表格化阈值；针对特殊地质条件（岩溶、承压水等）的监测项目调整机制在第 9 章。
     - **可定位章节号**：标准全文为「章—节—条」三层编号体系（如「10.1.2」「附录 A 表 A.0.1」），便于 C19 验证夹具精确锁定证据。

## 6. 版权与再分发注意事项（**重要**）

1. **强制性国家标准**（GB 50911-2013 等带「强制性」标识的国标）：
     - 依据原《国家版权局权司〔1999〕50 号》及《强制性国家标准管理办法》第 51 条，不适用中国著作权法第 5 条规定的版权保护；
     - **可合法入库、归档、整本再分发**；
     - 建议入库时仍标注「强制性国标 / 来源：住建部 + 国标委」以保留完整引用链；
     - 不修改原文、不删除条文号。
2. **推荐性国家标准**（GB/T 开头）、**地方标准**（DB11、DB34、SJG 等）、**团体标准**（T/CI、T/CECS 等）：
     - 受中国著作权法保护；
     - 入库原则：**只引用章节号 + 关键条文摘要 + 出处**，**不整本再分发**；
     - 如需完整条款对照，应保留原件 URL 与采购凭据。
3. **学术论文**：
     - 多数受期刊版权约束（CC BY / 非商业 / 署名 等不同许可）；
     - 入库原则：保留原文 PDF 作为内部参考，**不外发、不上传到开放平台**；
     - 引用时使用正式引用格式（含 DOI / 卷期页）。
4. **不可入库的内容**：
