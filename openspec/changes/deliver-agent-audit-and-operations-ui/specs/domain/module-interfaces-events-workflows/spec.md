## ADDED Requirements

### Requirement: C35 只读端口必须复用 Schema 事实源和所属模块

系统 MUST 用唯一 strict Schema 为任务、复核活动、管理目录、报告策略及报告读取定义用例级接口；共享版本/证据/授权引用必须复用已有契约。预算、工具行动和逐项校验字段必须从原 C08 唯一 Schema 派生安全投影，不建立原型同名第二套事实。接口由所属模块读取已登记事实，不开放上游内部表、通用工件正文或无限关联展开。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 各拥有方实现自己的事实读面
- **WHEN** API 请求任务、复核、管理或报告数据
- **THEN** 只调用对应公开用例，字段与运行时验证来自唯一 Schema，UI 不读取内部持久化结构

#### Scenario: 超界或错误结果族
- **WHEN** 输入超分页/集合上限或端口返回契约外结果
- **THEN** 共享边界失败关闭，不截断为成功、不用自由字符串推断结果类型

### Requirement: C35 报告导出必须沿 C31 与 C04 形成可重放结果

系统 MUST 实现已有 `projection.export` 的报告用途：只消费同工程精确登记的 C31 查询结果及已配置的不可变导出策略，按策略固定格式、章节、范围和资源上限，完整读取允许的投影事实并生成 JSON 内容工件。成功只返回真实 `ExportArtifactRefV1`；原内容工件映射、查询/策略/权限关联和生成审计必须耐久，重放复用同一身份。未登记查询、策略缺失、权限漂移、分页/字节超限或工件/审计失败不得成功；报告不更改领域事实、P/C 或现行配置。

#### Scenario: 同源同策略形成同一逻辑报告
- **WHEN** 导出请求在相同身份、查询结果和策略下重放
- **THEN** 返回原工件引用并可按原来源版本重建安全报告，不重复审计或创建第二份逻辑报告

#### Scenario: 工件或审计失败
- **WHEN** 内容尚未耐久、尾登记事务失败或审计写入失败
- **THEN** 不发布成功导出引用；原请求可安全重试，未登记工件沿现有工件维护规则处理

#### Scenario: 报告再读取权限收窄
- **WHEN** 工件生成后调用方失去原工程、空间、来源或导出权限
- **THEN** 正文读取安全失败，不用已保存的旧授权快照或下载链接绕过当前权限
