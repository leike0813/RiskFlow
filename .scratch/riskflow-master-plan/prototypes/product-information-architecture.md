# RiskFlow 产品信息架构与界面设计系统

## 决议

RiskFlow 采用面向风险业务任务的产品信息架构。顶层导航不直接暴露数据接入层、知识建模层、智能推理层、应用输出层等技术分层；技术分层只约束实现，用户通过工程项目、风险对象与处置任务完成工作。

## 全局应用框架

- 顶栏常驻当前工程、空间区段和工序阶段，所有查询、识别、评估、预警与处置均继承这一工程上下文。
- 左侧为一级业务导航；主工作区承载当前业务对象；需要证据或流程状态时使用右侧上下文区，不使用跨页面悬浮对话框拼接信息。
- 左侧固定为七项业务导航；智能 Agent 采用全局右侧停靠栏，并可展开为全屏工作台。两种形态共享会话、任务与当前业务对象上下文；Agent 输出与业务页面引用同一份结构化记录。
- 风险色只表达风险等级和预警状态，普通操作状态使用中性色或蓝色，避免红橙黄色退化为装饰色。

## 一级导航与页面职责

### 风险态势

- 面向领导和风险管理人员的工程总体视图。
- 展示当前风险等级分布、工序风险分布、监测趋势、待处置预警和近期变化。
- 所有指标均可下钻到风险评估记录或预警信息，不维护独立的看板统计口径。

### 工程项目

- 管理工程、空间区段、工序阶段、工程资料和监测数据。
- 核心页面：工程概览、资料目录、接入任务、监测概览、资料段与版本追溯。
- 工程项目是全局上下文来源，不承担风险识别或评分逻辑。

### 全局智能 Agent

- 不占用一级业务导航；日常交互使用右侧停靠栏，多步骤任务展开为“对话 + 任务执行 + 结构化结果 + 证据引用”的全屏工作台。
- 支持围绕当前工程、工序节点、风险记录、评估记录或预警信息发起任务。
- 内嵌与交互任务共用一个 Agent 任务详情，展示任务类型、状态、冻结输入、工具白名单、硬预算、类型化增量、确定性校验、领域结果和证据；不展示模型内部思维链。
- 内嵌任务在已确认业务运行内自动执行；交互式 Agent 的写命令在提交前等待用户确认。普通 P/C、矩阵和预警不显示 Agent 参与，RI-S57 后不安排同模型 Agent 自我审阅。
- Agent 不维护专属结果格式；生成的风险识别、评估和处置结果分别引用领域 SSOT。

### 风险识别

- 面向 RI-S1–RI-S6 的识别任务与结果管理。
- 核心页面：识别任务、站隧一体化施工工序模型、标准化风险记录、工序风险关联图谱。
- 风险机理条目、规范与类比案例从“知识与规则”引用，不在识别页面复制维护。

### 风险评估

- 面向 RA-S1–RA-S5 的规则适配、指标评分和风险分级。
- 核心页面：待评估风险、风险评估记录、指标评分明细、P/C 风险矩阵、重新评估历史。
- 任一分值都必须就地显示指标实际取值、适用规则、权重和版本入口。

### 预警处置

- 面向 RA-S6–RA-S7 的预警、处置建议、执行反馈与校准建议。
- 核心页面：预警中心、预警详情、处置任务、执行反馈、偏差记录与校准建议。
- 预警详情是闭环主页面，串联触发指标、证据、责任人、措施、执行状态和反馈。

### 知识与规则

- 统一管理风险机理库、规范标准库、类比案例库、指标体系、结构化评分规则、适用规则集、风险矩阵与措施库。
- 核心页面按知识对象分组，不按数据库或检索引擎分组。
- 版本发布、差异对比、审核与回滚均从相应知识对象进入。

### 复核与审计

- 统一承接 LangGraph 人工中断与业务审核任务。
- 核心页面：待复核队列、复核详情、证据追溯、运行记录、版本与操作审计。
- 规则冲突、字段缺失、低置信度、处置建议校验失败和校准建议发布均形成显式待办。

## 跨页面业务对象闭环

页面之间通过领域对象标识跳转，禁止通过页面私有状态复制业务事实：

1. 工程资料与监测数据
2. 站隧一体化施工工序模型
3. 标准化风险记录
4. 工序风险关联图谱
5. 风险评估记录
6. 预警信息
7. 处置建议
8. 偏差记录与校准建议

证据定位、版本与审计、人工复核是贯穿八类对象的横切能力。历史对象只追加、不覆盖；从任一结果都可以沿标识回到上游资料、规则和运行记录。

## 视觉系统

- 目标画布：桌面端优先，汇报截图按 1920×1080 设计；业务页面保持常见桌面分辨率下可用。
- 应用框架：深蓝灰顶栏与侧栏，浅灰画布，白色主要业务表面，弱边框和克制阴影。
- 主操作与运行中状态使用工程蓝；完成使用绿色；风险等级与预警使用甲方风险分级映射后的红、橙、黄等语义色。
- 表格用于记录与规则清单；时间序列用于监测；矩阵用于 P/C 分级；关系图只用于工序、机理和风险要素关系。
- 证据入口紧邻结论、分值和预警原因，不设置需要用户猜测的统一“更多详情”。
- 面向用户的页面不出现 Demo、Mock、兼容性说明、开发进度或专利原文。

## 明日汇报截图映射

1. 风险态势总览：工程总体风险、工序分布、监测趋势和待处置预警。
2. 智能 Agent：业务页与 Agent 停靠栏组合视图或全屏工作台，展示真实任务、受限工具、预算、类型化增量、领域结果和关键证据。
3. LangGraph 智能识别中心：识别任务、RI-S1–RI-S6 状态、标准化风险记录与工序风险关联图谱。
4. 风险评估与预警中心：指标评分、P/C 风险矩阵、触发指标和预警状态。
5. 风险详情与处置追溯：风险事件、适用规则、处置建议、证据链、版本和审计。

## 后续设计边界

- 本决议确定顶层产品结构、对象关系、视觉原则和页面职责。
- 本文只提供高层信息架构与视觉基线；完整产品的角色差异、全部页面、表单、状态、交互、响应式和可访问性由“设计完整产品界面与交互规格”继续确定。
- 五张汇报截图必须在完整产品界面规格完成后，从正式页面和共享组件中派生，不反向约束产品功能与页面结构。
