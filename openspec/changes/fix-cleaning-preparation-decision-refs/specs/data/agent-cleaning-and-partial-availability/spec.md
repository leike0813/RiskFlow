## MODIFIED Requirements

### Requirement: 识别准备只冻结已收口的可用输入

系统 MUST 实现既有 `identification-preparation` 冻结语义，并消费前置契约演进后的复数 `includedSourceSegmentSetRefs[]`。每个 `sourceVersionRef` MUST 按相同顺序对应一个精确资料段集合；排除决定 MUST 指向这些集合内的资料段。`coverageDecisionRef` 与每个 `excludedSegmentDecisionRefs[]` 成员 MUST 是 strict `RouteDecisionRefV1`，其精确版本身份 MUST 绑定对应的确定性决定内容及其正式清洗结果来源，不得以 `ContentArtifactRefV1` 冒充路由决定。至少一份文档达到 `available` 或 `partial` 且整体策略门通过时，系统 MUST 保存可由公共 `IdentificationPreparationSnapshotV1` Schema 完整解析的不可变识别准备快照；不可用文档的全部段保持显式排除，部分可用文档只排除已接受范围。监测结果可用或部分可用时保存精确快照引用，不可用时在覆盖决定中保留原因而不把监测快照作为可消费输入。（RI-S1、RI-S2、RI-S13、RI-S21～RI-S23）

#### Scenario: 多资料部分可用准备成功

- **WHEN** 四份资料的清洗任务完成，其中至少一份为部分可用，所有资料版本与资料段集合一一对应且整体覆盖达到策略门槛
- **THEN** 系统返回一个可由公共 strict Schema 解析的识别准备快照，保留全部资料版本/集合引用、精确 `route-decision` 排除决定、`route-decision` 整体覆盖决定和清洗版本引用
- **AND** 下游可以仅从未排除资料段继续，同时重放每项排除和质量结论

#### Scenario: 内容工件引用不能冒充路由决定

- **WHEN** 覆盖决定或任一排除决定仍是 `content-artifact`、未知引用类型或无法绑定对应决定内容与正式清洗结果来源
- **THEN** 系统在识别准备快照成立前拒绝该 payload
- **AND** 不保存无法通过 `IdentificationPreparationSnapshotV1` strict Schema 的准备快照或发布输入就绪事件

#### Scenario: 全部文档不可用时阻断

- **WHEN** 所有请求文档的清洗结论均为 `unavailable`，或整体覆盖低于冻结策略下限
- **THEN** 系统返回业务阻断并保留清洗结果与原因引用
- **AND** 不创建空准备快照或发布输入就绪事件

#### Scenario: 前置复数契约未就绪时禁止实现

- **WHEN** `evolve-identification-preparation-segment-set-refs` 尚未归档，或运行时仍只接受单数资料段集合字段
- **THEN** C15 实现/启动检查失败并报告契约版本不兼容
- **AND** 不在 C15 内修改公共 Schema、压缩多资料为一个集合或只取第一份资料

### Requirement: 版本、幂等与权限支持精确重放

系统 MUST 使清洗准备、任务、结果、排除决定和识别准备快照只追加且可由精确资料版本、转换记录、监测快照、数据处理/模型/提示/工具/预算/校验策略、授权与命令身份重放。相同作用域、幂等键和规范化载荷 MUST 返回原逻辑结果；同键不同载荷 MUST 返回不可重试冲突。输入或策略变化 MUST 创建新任务与新结果，不得覆盖历史。每次工具读取、最终收口和准备冻结 MUST 重新校验当前工程、空间和资料权限，未授权与不存在采用不可枚举失败。（RI-S14、RI-S21～RI-S23）

系统还 MUST 提供按精确 `IdentificationPreparationSnapshotRefV1` 读取单个准备聚合的受权窄接口。请求 MUST 固定工程、操作者、请求身份、请求时刻、当前授权上下文和准备快照引用；成功结果 MUST 只返回 strict `IdentificationPreparationSnapshotV1`、其绑定的精确 `AgentTaskRefV1`、strict `DataCleaningResultV1` 与 `ContentArtifactRefV1` 结果引用，并验证准备行、任务、结果索引和结果工件相互一致。该接口 MUST 在目标结果可观察及历史成功重放前复验当前授权；不得提供列表、搜索、名称或“最新值”查询，不得返回 C04 读取句柄、资料正文或监测值。成功读取 MUST 原子形成幂等命令回执与一条只追加领域审计；C04 工件访问继续遵守自身审计，重放不得重复审计。

#### Scenario: 相同准备重放不重复副作用

- **WHEN** 调用方以相同工程、幂等身份、输入和全部冻结版本重试清洗准备或识别准备冻结
- **THEN** 系统返回原任务、清洗结果和准备快照引用
- **AND** 不重复模型/工具调用、结果事实、排除决定、审计或 Outbox 事件

#### Scenario: 输入或策略变化形成新版本

- **WHEN** 任一资料版本、转换记录、监测快照、数据处理策略、模型、提示、工具、预算或校验策略发生变化
- **THEN** 系统创建新的冻结准备、Agent 任务和清洗结果
- **AND** 旧结果及引用它的识别准备快照保持不变

#### Scenario: 当前资料权限撤销后拒绝消费

- **WHEN** 任务创建后、工具读取或识别准备冻结前，任一资料正文授权已撤销或请求范围扩大
- **THEN** 系统返回统一授权失败并记录安全审计
- **AND** 不泄露目标存在性、资料正文、监测值或旧观察工件内容

#### Scenario: 当前授权读取精确准备与绑定结果

- **WHEN** 调用方提交一个同工程、当前获准且确实存在的精确识别准备快照引用
- **THEN** 系统返回可由公共 Schema 解析的准备快照、其绑定任务、strict 清洗结果和精确结果工件引用
- **AND** 覆盖与排除引用全部为 `route-decision`，资料版本与资料段集合仍同序一一对应，且只追加一条成功读取审计和一个完成回执

#### Scenario: 精确准备读取不可枚举

- **WHEN** 请求引用缺失、属于其它工程、当前未授权或已撤权，准备 payload 无法 strict 解析，或者任务与结果索引/工件绑定失配
- **THEN** 系统返回同一不可重试授权拒绝公开形状
- **AND** 不返回准备、任务、结果、决定、工件引用或目标存在性差异，不写业务成功读取审计或完成回执

#### Scenario: 精确准备读取幂等且不绕过撤权

- **WHEN** 调用方以相同请求身份和规范载荷重复读取同一准备
- **THEN** 系统返回相同准备、任务、结果和结果工件引用，且不重复 C03 领域审计或 C04 访问审计
- **AND** 同一请求身份改传其它准备引用时返回幂等冲突，首次成功后撤权时仍先拒绝而不重放旧成功

#### Scenario: 精确准备读取不形成正文或枚举旁路

- **WHEN** 下游通过精确准备读取取得成功结果
- **THEN** 返回只包含该准备及其绑定清洗结果的 strict 字段与精确引用
- **AND** 接口不接受列表、搜索、名称或“最新值”参数，也不返回资料正文、监测值、工件读取句柄或任意数据库记录字段
