## ADDED Requirements

### Requirement: 标准库检索正文必须来自精确准备快照中的有权证据段

C17标准库条目可包含可选`retrievalText`，其值 MUST 仅由该条目已有evidence所引用、且属于精确`preparationSnapshotRef`的C11真实资料段正文按证据顺序和统一换行规则确定性拼接。无正文时不得生成摘要；读取超出既有单次、累计或成员字节预算时拒绝且不得截断。验证 MUST 通过窄`checkStandardRetrievalText`接缝复核精确准备、当前权限、证据引用和正文一致性；缺少读取能力、错版、越界、撤权、损坏或正文不符均不得送审。已发布条目不可原位修改，正式正文仍须经既有人工审核和独立发布。

#### Scenario: 有权证据正文进入候选

- **GIVEN** 转换JSON-LD单文档及单标准条目累计工件读取上限为共享16MiB，清洗清单、候选包和其它工件仍保持4MiB，超限拒绝且不截断；模型、工具输出及成员正文预算保持原值

- **WHEN** 条目证据引用均属于精确准备快照，当前主体有读取权限且真实段正文在既有预算内
- **THEN** 系统以稳定顺序生成`retrievalText`并通过窄校验，候选进入原人工审核流程

#### Scenario: 证据或正文校验失败

- **WHEN** 读取能力缺失、准备版本不匹配、证据越界、权限撤销、正文损坏/不符或读取超预算
- **THEN** 系统拒绝候选送审，不截断、不合成正文、不发布且不泄露无权内容

### Requirement: C17 至 C16 内部解析支持调用方显式精确身份

C16内部解析 MUST 支持调用方显式传入精确invocationId：C17 MUST 按当前可信调用与既有解析目标派生该身份，C16 MUST 按传入身份原样复验当前来源与精确发布绑定后继续解析，不得自行改写身份或从字符串推断。未显式提供的既有调用者 MUST 继续按原派生严格验证。该字段只属于内部正式读取，不新增外部HTTP命令、字段或权限分支。

#### Scenario: 显式身份保持既有解析语义

- **WHEN** C17为内部知识解析显式传入按当前可信调用与既有解析目标派生的精确invocationId
- **THEN** C16按该身份复验当前C06来源与精确发布绑定后继续原有解析，不改变工程、业务时刻或发布范围语义
- **AND** 未显式提供时保持原派生严格验证，身份不符或来源不可证明时失败，不新增外部HTTP或权限分支
