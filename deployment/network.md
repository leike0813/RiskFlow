# 三 VM 网络与端口边界（C37 D-01/D-16）

同一台物理服务器内运行三台虚拟机。该拓扑提供的是资源、进程与权限隔离，
**不提供物理故障域隔离、高可用或灾难恢复**；宿主机或磁盘整体故障可能同时
丢失系统与同机副本。

| VM | 角色 | 对外开放 | 内部端口 |
| --- | --- | --- | --- |
| 推理 VM | llama.cpp 与模型（GPU 直通） | 无 | 8081（仅应用 VM 可达） |
| 应用 VM | Web、API、Worker、HTTPS 入口、解析 | **8443**（业务用户唯一入口） | 8080（本机回环）、9443（数据 VM 工件服务） |
| 数据 VM | PostgreSQL、Qdrant、不可变工件 | 无 | 5432、6333、9443（仅应用 VM 可达） |

## 规则

- 业务客户端只访问应用 VM 的 HTTPS 入口；不得直连数据库、向量库、推理或管理端口。
- 内部服务之间使用管理网地址，应用 VM 以 mTLS 调用数据 VM 的工件流服务。
- 管理入口（SSH、运维控制台）与业务入口分离，且只允许受控来源。
- 容器镜像只从离线介质 `docker load`，启动使用 `--pull=never`，运行期不联网。

## 停写边界

维护窗口开始时：先停止 API 与 Worker（停止接收、停止 claim、限时 drain），
再停止工件服务并确认全部写者已停止；此后才可进行同机逻辑副本。
停止顺序不可颠倒——否则会在仍有写者时生成副本，产生不自洽的恢复点。
