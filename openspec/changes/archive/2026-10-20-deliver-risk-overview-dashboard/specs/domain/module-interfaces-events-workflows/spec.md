## ADDED Requirements

### Requirement: OV-D1 仪表盘读取必须独立于历史报告且只组合所属事实

系统 MUST 提供闭合、单工程、只读的仪表盘公共用例，复用现有投影读取资格但不借此获得任何来源领域的读取或写入权限。结果须一次组合分布、待办摘要、资料／监测概况及有界的风险／评估／预警变化页，各来源返回自己的权限／可用状态、范围、统计单位和时点。聚合 MUST 由来源所有者执行并与所属列表共用候选及可见性口径；组合层不得读跨域私表、累计全部目录页、复制领域正文或产生新业务事实。当前授权覆盖的空间与全部必需来源方可参与计数或输出，不先统计不可见总量再在客户端裁剪。工程级复核摘要须明确工程级范围，不冒称空间筛选或个人分派。（RI-S6；RA-S3～RA-S7）

#### Scenario: OV-D1-S01 多来源只读取回真实统计
- **WHEN** 获权工程成员请求仪表盘并且各来源可用
- **THEN** 返回各所属模块的完整可见聚合与有界精确事件，原领域事实、业务收据和模型使用量均不增加
- **AND** 旧 C31 查询登记、结果引用、分页及报告导出保持原协议和重放内容

#### Scenario: OV-D1-S02 来源权限与故障互不冒充
- **WHEN** 某来源无权、未注入、技术失败或分组超界，而其它来源可用
- **THEN** 对应来源分别给出安全状态，其余来源独立可读；不披露无权总量、不生成成功空数组，也不把技术异常折为权限拒绝

#### Scenario: OV-D1-S03 当前权限裁剪在聚合之前完成
- **WHEN** 工程成员只覆盖部分空间或缺少某份必需来源资料权限
- **THEN** 分布、事件和接入概况只计入所属读面同样允许披露的记录，派生记录仍取全部来源权限交集
- **AND** 聚合入口权、旧快照、URL 参数或 Agent 关联都不能放大权限

### Requirement: OV-D2 仪表盘分页与结果边界必须由服务端保持

仪表盘请求和结果 MUST 使用唯一 strict Schema、既有版本引用与安全错误类型。变化页必须固定时间上界、完整排序键和不超过 50 的页大小，游标绑定工程、筛选及位置；每页重查当前权限而不要求历史完整授权摘要等值。分布分组须有明确有限上限，越界不得静默截断。读取只追加原访问／安全审计，不新建业务回执、物化查询、投影表或业务事件；审计失败不可返回无记录的成功。服务端结果非法须在公开边界安全失败。（RI-S6；RA-S5～RA-S7）

#### Scenario: OV-D2-S01 有界稳定分页与当前撤权
- **WHEN** 同时刻事实超过一页、期间新增事实或撤销某对象权限
- **THEN** 原上界内可见事件按精确排序位置续读，新增事实留到刷新，撤权对象不再披露；读取不扫描并传回全部事实

#### Scenario: OV-D2-S02 非法输入结果和日志失败
- **WHEN** 请求含未知字段／错工程游标、返回结果不符合契约或安全审计失败
- **THEN** 对应边界给出类型化安全失败，不吞异常为零值、不新增业务事实或公开内部错误正文
