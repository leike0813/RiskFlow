# 确定完整产品功能规格与用例契约

## Question

基于完整产品范围、领域模型和用户用例，RiskFlow 的每项功能应具有怎样的触发条件、输入、输出、权限、正常流程、异常流程、人工复核、版本与审计行为，才能形成覆盖 RI-S1–RI-S6、RA-S1–RA-S7 且可直接用于设计与验收的产品功能规格？

## Answer

采用“业务用例契约”作为完整产品功能规格的组织方式。每项能力统一规定触发与权限、冻结输入、正常流程与业务事实输出、异常与人工复核、版本与审计、完整产品/MVP 深度；界面、智能 Agent 和外部适配器必须调用同一领域命令并读取同一查询投影。

功能基线覆盖工程与访问、资料与监测接入、知识与规则治理、风险识别、风险评估与重新评估、预警处置与反馈、复核审计、智能 Agent、系统运维与外部集成，并建立 RI-S1～RI-S6、RA-S1～RA-S7 的逐步追踪。内部 LangGraph 节点、解析算法和存储实现不作为独立业务事实或面向用户的零散接口。

确认预警语义：评估越限产生的预警信息可靠入库后立即在工程内生效；“确认预警”只表示已读并接管。外部通知、现场处置和施工措施批准由独立策略与命令控制；误报通过质疑、复核和作废决定处理。

完整规格见：[RiskFlow 完整产品功能规格与用例契约](../prototypes/full-product-functional-spec.md)。
