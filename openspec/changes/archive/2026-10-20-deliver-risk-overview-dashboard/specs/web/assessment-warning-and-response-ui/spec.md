## MODIFIED Requirements

### Requirement: 风险态势必须按有界所属摘要呈现

风险态势页 MUST 通过 `web/risk-overview-dashboard` 的服务端读面组织评估等级、工序分布、变化时间线、待办摘要与接入概况；各来源明确统计范围、单位、时点和口径，不将记录版本、预警与任务相加为风险事件总数。原评估与预警任务摘要的事实含义保持，并保留既有风险总览投影的一页精确运行与追溯引用；历史投影仅由用户请求续页，图表只使用受控聚合或当前有界结果。任一来源失败 MUST 单独显示不可用，不把另一来源冒充完整总量。页面 MUST 不遍历全库或将部分页计数声称为全工程总量，不改原历史投影与报告重放输入，报告导出不属于本页写能力。（RA-S5～RA-S7）

#### Scenario: 摘要失败与范围切换
- **WHEN** 用户切换空间范围或预警摘要来源失败
- **THEN** 页面清除旧范围摘要并分别呈现新范围结果与失败区域
- **AND** 不显示旧总量、静态趋势、假报告导出或跨权限计数

#### Scenario: 原投影引用按页追溯
- **WHEN** 用户从态势页读取运行引用并请求下一页
- **THEN** 系统沿原查询结果和授权范围取得有界页，链接保留精确版本与证据引用
- **AND** 当前摘要不改写查询时点的历史结果，也不触发全量翻页

#### Scenario: OV-A-S01 统计不改变冻结评分依据
- **WHEN** 仪表盘包含多次评估或多个矩阵版本
- **THEN** 统计明确记录版本单位及可比较配置组，详情继续解释各自冻结的 P/C、等级与依据，不在总览重新评分或按当前矩阵重画历史
