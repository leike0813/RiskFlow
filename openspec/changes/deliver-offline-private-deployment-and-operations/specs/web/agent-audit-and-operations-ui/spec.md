## MODIFIED Requirements

### Requirement: C35 页面必须复用 v2 设计并保持既有应用接线

系统 MUST 在 `apps/web` 生产应用中复用 v2 的 Agent、复核审计、报告及系统管理页面分区、视觉层级和键盘交互，使用真实服务端事实和七态骨架。七项业务导航 MUST 保持原顺序；Agent 和系统管理只能从辅助入口进入。页面 MUST NOT 将原型 fixture、角色/状态注入、契约镜像、假回答或假操作作为交付能力。（横切 RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 已接通页面与 v2 分区一致
- **WHEN** 用户打开 C35 Agent、复核详情、审计、报告或系统管理页面
- **THEN** 页面保持 v2 对应设计的主分区和操作位置，事实来自正式 HTTP 接缝，现有 C32–C34 深链仍可达

#### Scenario: 刷新切换与服务异常
- **WHEN** 用户刷新精确版本深链、切换工程，或读取失败/无权/端口未接入
- **THEN** 页面先恢复真实会话和工程上下文，再显示该引用或对应七态，迟到响应不覆盖新上下文，不用静态事实填充

### Requirement: C35 验收必须覆盖真实接缝和可访问性

系统 MUST 在真实 Chromium、`apps/web` 生产构建、PostgreSQL、正式迁移与真实 Cookie 会话上验收上述页面、类型化操作、审计、JSON 下载、撤权和工程切换竞态。合成资料与模型结构化候选 MUST 标明待甲方复核，不把随机模型回答作为期望。键盘可完成停靠切换与确认、取消恢复焦点；关键环境不可用 MUST 非零失败。

#### Scenario: 真实浏览器完成 C35 链路
- **WHEN** 固定环境中登记了合法任务、五类复核、历史活动、报告输入及管理员
- **THEN** 可从登录贯通任务详情/确认、复核、审计、报告工件下载与六项管理动作，证据对应实际入库结果

#### Scenario: 慢读和环境缺失
- **WHEN** 任务查询慢于刷新间隔、页面隐藏/卸载，或数据库/浏览器不可用
- **THEN** 慢读不叠加请求，隐藏/卸载清理刷新；环境缺失不以 skip 或 Mock 计作通过
