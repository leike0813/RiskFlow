# 确定工程资料与监测数据接入范围

## Question

完整产品与 MVP 分别支持哪些 Word、PDF、表格、扫描件、CAD、数据库、API 和监测时序输入；每类输入的登记、解析、质量校验、资料段标识、版本、权限、失败回溯和重处理契约是什么，如何在受限 MVP 中仍保留向完整能力演进的接口？

## Comments

- 已确认输入支持采用三个可验收层级：登记支持、解析支持、业务可用。只有通过质量校验并可进入识别或评估运行的输入，才能声明为业务可用；允许上传或只保存原件不得笼统宣称为“已支持”。
- 已确认 MVP 的业务可用输入为 DOCX、文本型 PDF、经 OCR 处理的扫描型 PDF/PNG/JPEG，以及用于结构化表格和批量监测时序的 XLSX/CSV。DWG/DXF 在 MVP 中仅登记；数据库、API 与实时监测流不进入 MVP，且不建设空连接器。
- 已确认监测数据采用“监测序列 → 不可变监测批次 → 运行时冻结监测快照”。完全重复采样幂等去重；同一采样时间的不同数值创建带更正关系的新批次；迟到数据作为历史补录批次保存并可触发历史补算，任何情况均不覆盖旧值。
- 已确认原始采样不可删除或覆盖，异常值保留质量标记，清洗、单位换算和衍生特征形成版本化处理结果；默认禁止自动插值参与 P/C，只有已发布指标配置明确允许时才可采用指定方法；窗口覆盖率或质量阈值不达标时暂停相关评估。数据清洗采用“固定算法预处理 + Agent 后处理”二级方法，Agent 的生效权限待进一步确认。
- 用户要求 Agent 后处理默认直接执行并自动产出结果，不以人工审阅为生效前提；每个阶段必须保留足以供事后审核的输入、动作、前后值、依据与版本证据。自动清洗的动作约束和失败边界待进一步确认。
- 已确认不为 Agent 清洗另建“自动清洗决定”领域对象。固定算法完成预处理后，Agent 直接调用普通、版本化的清洗工具；工具调用参数、输入输出引用、前后差异、运行与模型版本构成审计证据，最终只形成不可变的版本化清洗结果，通过确定性质量校验后自动成为业务可用输入。
- 最终确认数据清洗由 Agent 主导，固定算法仅作为 Agent 可选用的辅助工具。Agent 可在算法失败或质量不佳时直接处理 raw，并直接判断最终质量与业务可用性；不另设确定性质量门槛、人工生效审批或专门降级策略。系统硬约束只校验结构、权限和审计完整性；原始数据保持不可变，清洗结果版本化，并保存 Agent、模型、提示模板、工具调用、输入输出、前后差异及依据证据。
- 已确认监测接入与 Agent 清洗管线保持指标无关，通过版本化配置映射专利规定的六类监测指标；MVP 验收只强制至少一条“地表沉降”监测序列完整跑通清洗、趋势/加速度/异常评分、评估、预警和处置反馈。甲方样例中的其它指标可以接入，但不作为 MVP 完成前提。
- 已确认完整产品在 MVP 格式基础上，将 DOC/DOCX、XLS/XLSX/CSV、PPT/PPTX、文本/扫描 PDF、PNG/JPEG/TIFF、DWG/DXF，以及数据库、HTTP API 和实时监测流提升为业务可用输入。旧版 DOC/XLS 可受控转换后进入统一解析流程，原件、转换工具版本和转换结果均须保留；PPT/PPTX 解析幻灯片顺序、文本、表格、图片与备注。MVP 格式集合保持不变。
- 已确认文件、数据库、API 和实时监测流统一通过同一接入模块：外部连接只负责获取数据，每次拉取、推送或时间窗口均形成不可变工程资料版本或监测批次，记录/表格/时间段生成资料段标识；LangGraph 只读取已登记的冻结数据，不在运行中直接查询实时外部系统，所有来源共用权限、版本、失败回溯和证据定位规则。
- 已确认允许资料段级别的部分可用：合格资料段可以进入识别或评估，失败资料段隔离并单独重处理；工程资料版本显示排除范围，Agent 判断剩余覆盖是否足以继续运行并保存依据；重处理成功创建新的工程资料版本，不回写旧版本。

## Answer

采用登记支持、解析支持、业务可用三个可验收层级描述输入能力。MVP 业务可用输入为 DOCX、文本型 PDF、经 OCR 处理的扫描型 PDF/PNG/JPEG、XLSX/CSV；DWG/DXF 仅登记，数据库、API 与实时监测流不提供入口。完整产品将 DOC/DOCX、XLS/XLSX/CSV、PPT/PPTX、文本/扫描 PDF、PNG/JPEG/TIFF、DWG/DXF、数据库、HTTP API 和实时监测流提升为业务可用。

所有来源统一形成不可变工程资料版本或监测批次和资料段，LangGraph 只读取冻结输入。监测数据按“监测序列 → 不可变监测批次 → 监测快照”组织，更正和迟到数据只追加。数据清洗由 Agent 主导，固定算法是可选辅助工具；Agent 可直接处理 raw 并判断质量与业务可用性，结果自动生效且全过程留证，不另建清洗决定对象或人工生效门槛。合格资料段允许部分可用，Agent 记录排除范围和覆盖判断。

监测管线保持指标无关并映射六类专利指标；MVP 只强制至少一条地表沉降序列完整跑通清洗、时序特征、评估、预警和处置反馈。登记、解析、权限、失败回溯和重处理均遵循不可变版本、资料段标识与审计规则。

完整规格见：[RiskFlow 工程资料与监测数据接入范围](../prototypes/ingestion-monitoring-scope.md)。
