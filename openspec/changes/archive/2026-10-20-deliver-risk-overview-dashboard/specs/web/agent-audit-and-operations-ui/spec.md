## MODIFIED Requirements

### Requirement: 运行审计与证据必须按所属事实分别分页

系统 MUST 在 `/overview?tab=runs` 保留识别与链运行的独立有界分组，永久解析 `/review-audit/runs` 及已知 `/review/runs` 到同一承载，保全工程、历史修订、原查询结果和精确详情引用；同批更新生产内部链接并移除重复旧页面实现。没有给定修订时仅沿原合法工程上下文解析，已给定历史修订不得换为当前版本。审计仍为独立承载，保留按精确主体和时间边界查询的业务/安全/复核拒绝活动。审计 MUST 显示活动码、安全原因、操作者、精确版本、命令及三类时间；业务追溯继续使用 C31 已成立链边及缺席原因。审计引用不得充当变化时间线正文，任一来源失败不得由另一来源冒充完整。证据抽屉继续只披露定位与脱敏摘要。（RI-S6；RA-S5～RA-S7）

#### Scenario: 独立来源与续页
- **WHEN** 运行、活动或链路超过单页上限，且一个来源失败
- **THEN** 各分组使用自己的游标和错误状态，由用户续页，已成功来源不被清空或标为全部完成

#### Scenario: 历史与无正文权限
- **WHEN** 用户追溯历史版本但无资料正文权限
- **THEN** 页面保留原版本、获准定位及缺席原因，不展示原文、原始日志或凭据

#### Scenario: OV-O-S01 旧运行地址原子切换且不影响复核
- **WHEN** 用户从旧运行链接、内部入口或浏览器历史打开指定工程和历史修订
- **THEN** 在总览运行位置读取同一历史目标，识别与链运行独立分页，不依赖新仪表盘其它来源成功
- **AND** 原复核队列、精确复核详情、审计及报告仍可用，未提前启用六导航或待办替代面
