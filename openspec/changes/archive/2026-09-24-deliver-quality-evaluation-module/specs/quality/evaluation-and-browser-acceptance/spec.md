## Purpose

本能力把识别和评估链的质量判断固定到有来源、有标注、有版本的样例与可重放证据上，并为获授权页面提供质量结果的有界查询与真实浏览器验收，使交付方可以复核结论、缺失项和失败原因。

## ADDED Requirements

### Requirement: 质量数据集必须冻结并标明适用边界

系统 MUST 以不可变数据集版本固定样例来源、脱敏证明或合成标记、工程/空间/工序、来源资料段、人工标注的正负样本全集、风险事件身份、适用性元数据快照、识别与评估输入引用，以及规则、权重、矩阵、模型、提示和配置版本。正式质量结论 MUST 只针对数据集明列的样例和精确运行结果；来源、标签、版本或正文资格缺失时不得补默认值。当前无甲方真实样例时，所有相关报告 MUST 标注“合成样本，待甲方复核”。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 冻结的脱敏样例进入评估

- **WHEN** 样例具有脱敏资格、完整人工标签、适用性快照、各精确输入及配置版本
- **THEN** 系统登记不可变数据集身份，并可按该版本复算同一分母和标签集合

#### Scenario: 样例不足或只有合成样本

- **WHEN** 样例缺少标签、来源资格或必要版本，或尚无甲方真实脱敏样例
- **THEN** 缺项阻止对应正式指标成立；合成样本仍可用于流程验证，但报告显式标记“合成样本，待甲方复核”且不声称真实工程性能

### Requirement: 识别与评估质量指标必须由确定性证据计算

系统 MUST 用冻结标签全集和正式识别结果计算准确率 `(TP+TN)/N`、精确率 `TP/(TP+FP)`、覆盖度 `已产出合格判断的必评项数/必评项总数`；正负标签的事件、工序和资料段匹配口径须固定在数据集版本内。跨来源一致性 MUST 以数据集明确可比较的同一事件来源对为分母，计算结论一致的来源对比例；评估等级匹配率 MUST 与已审核期望等级比较。每项展示分子、分母、失败项及样本来源；分母为零或标签不合格时显示不可计算及原因，不得记为零分、满分或通过。模型输出不得作为单测硬期望。（RI-S55～RI-S6；RA-S4～RA-S5）

#### Scenario: 正式结果与标注对齐

- **WHEN** 冻结数据集列出完整正负标签和可比较来源对，正式运行结果引用可验证
- **THEN** 报告给出每个指标的分子、分母、计算值、样例级判定和对应精确结果引用

#### Scenario: 缺失结果或分母为零

- **WHEN** 正式结果缺失、引用不匹配，或某指标没有合格分母
- **THEN** 系统记录缺失/不可计算原因，覆盖度反映缺口，且不使用相似运行、LLM 自评或旧结果填补

#### Scenario: 精确冻结运行证明正式空结果

- **WHEN** 已授权的精确冻结运行及其全部必评范围有正式终态证明，且某负样例的事件、工序和资料段匹配键在该范围的正式结果全集中不存在
- **THEN** 系统将该样例计为 TN 和有合格正式判断的覆盖项，报告保存终态证明与冻结范围的精确引用；并发重放须得到同一集合摘要，不以单条记录缺席推断空结果

#### Scenario: 精确冻结运行存在正式结果

- **WHEN** 已授权的正式终态证明在同一冻结范围内返回与样例匹配的精确正式记录引用
- **THEN** 系统按该记录与人工标签判定正负匹配，且不把该样例作为正式空结果计数

#### Scenario: 空结果证明缺失或越界

- **WHEN** 终态证明缺失、运行尚未完成、全集不完整、版本/范围不符，或请求跨工程、跨空间及当前 actor 授权
- **THEN** 系统保持该样例未判定且不计 TN 或覆盖；无权与不存在使用同形安全失败，不披露其它运行的记录数量

#### Scenario: 跨空间或无权读取正式结果证明

- **WHEN** 当前 actor 无权、请求跨工程或空间，或所指运行根本不存在
- **THEN** 只读接缝返回同形安全失败，报告不形成该样例的 TN、覆盖或其它空间的结果数量

### Requirement: C22 正式零结果必须提供独立只读组合入口

C22 MUST 允许调用方仅以当前授权复验、精确结果登记读和 C04 工件读组合正式零结果窄读；该入口 MUST 与既有 C22 服务的 `readZeroResult` 共用唯一校验实现，不依赖模型、人工审阅或写端口。C36 只能通过此公开入口核验 C39 已完成运行中的每个正式零结果。

#### Scenario: 只读调用方复用正式零结果校验

- **WHEN** C36 持有精确工作项和零结果引用，并在读取前后具有当前 `risk-identification.assemble-and-infer` 授权
- **THEN** C22 入口与既有服务返回相同的已核验零结果或同形安全失败，不启动模型、人工审阅或写入

### Requirement: 可重放与可审计结论必须引用耐久证据

系统 MUST 对每个样例验证从资料段、工序、机理、标准化风险记录、评估输入快照到评估记录的精确引用链，以及指标取值、适用规则集、权重、矩阵和审计依据；可重放率以同一冻结输入与版本重新执行确定性评估并与正式结果相符的样例数为分子。审计链完整率以所有必需引用均存在、可授权解析且通过完整性校验的样例数为分子。报告及逐项诊断 MUST 成为 C04 不可变证据工件，保存所用命令、代码版本、数据集/运行版本和结果引用；发布索引、审计与回执失败时不得显示正式成功。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 精确版本可复核

- **WHEN** 授权复核者使用报告记载的命令、输入快照和版本重新运行
- **THEN** 得到相同确定性指标与逐项差异，且能从 C04 工件追到原始证据和审计记录

#### Scenario: 证据或审计缺失

- **WHEN** 任一必需工件不可读、完整性失败、引用跨工程或正式审计未成立
- **THEN** 对应样例的可重放/可审计判定失败，报告保留安全原因码，不补造证据或宣布该项通过

#### Scenario: 必审资料段可授权解析

- **WHEN** 当前 actor 在精确工程和空间内按样例冻结的资料版本逐一解析全部 `requiredEvidenceRefs`，拥有方返回同形资料段身份、可解析结果与可核验版本依据
- **THEN** 系统仅保存每项引用及验证收据，结合既有 C04 工件和正式审计证据计算审计链完整率；同一冻结版本重放结果一致，不复制资料正文

#### Scenario: 必审资料段拒绝或漂移

- **WHEN** 任一资料段不存在、无权、跨工程/空间、资料版本漂移或完整性校验失败
- **THEN** 该样例审计链不通过，拒权与不存在同形，且不能借另一资料段或旧 grant 补齐

### Requirement: C36 页面查询投影必须有界且只追加

系统 MUST 由 C36 自有投影在既有 `projection.query` 上仅增加 `quality-evaluation` 查询类型：输入为按项目修订、页大小不超过 50 的列表选择器，或精确 C04 报告引用选择器；输出保留 `queryResultRef`，可附加 `qualitySummaries` 与 `nextCursor`。每项摘要字段闭合为 `schemaVersion`、`projectId`、`reportArtifactRef`、`datasetArtifactRef`、`sampleKind`、`label`、`metrics`（指标码、分子、分母、值/不可计算原因）、`evidenceRefs` 和 `createdAt`，不得含领域正文或任意筛选字段；原查询类型的语义与形状不变。投影只能消费所属模块公开接口及正式事实引用，正文仍由拥有方保存。服务端 MUST 使用当前会话签发的最小工程授权，并在返回前复验工程、空间和资料可见性；无权、跨工程或不存在目标统一拒绝且不可枚举，正文无权时只返回获准定位摘要。相同事件/报告重放不得重复追加，更新报告必须产生新版本而不覆盖历史。（RI-S6；RA-S5～RA-S7）

#### Scenario: 获授权页面读取精确质量报告

- **WHEN** 用户在当前工程查询已正式成立的精确质量报告
- **THEN** 返回有界摘要与 C04 精确证据引用，页面刷新和跨页面返回后按服务端当前投影重建

#### Scenario: 工程切换或撤权

- **WHEN** 页面切换工程、授权被撤销或请求指向其它工程报告
- **THEN** 旧内容立即清除，服务端拒绝越权查询且不披露目标是否存在、数量或正文

#### Scenario: 不可枚举拒绝与旧类型兼容

- **WHEN** 调用方分别查询无权报告、跨工程报告、不存在报告，或使用既有其它查询类型
- **THEN** 前三者得到相同安全拒绝且不能由响应区分目标存在性，既有类型仍按原请求和结果形状处理

#### Scenario: 追加与重放

- **WHEN** 同一正式报告通知被重复消费，或新的报告版本成立
- **THEN** 重复通知只返回原索引；新版本追加独立索引，历史报告仍指向原证据

#### Scenario: 来源版本与资料 grant 精确映射

- **WHEN** 获授权用户读取已索引报告，服务端针对候选摘要的精确 `sourceVersionRefs` 逐项取得 C06 当前签发上下文，并能证明该来源版本对应的 grant 与当前上下文同形
- **THEN** 仅返回这些来源版本对应的有界 `evidenceRefs`；列表与精确查询均保持原分页、结果形状和工程/空间授权，重复读取不追加业务事实

#### Scenario: 来源映射缺失或授权变化

- **WHEN** 某来源版本未获授权、grant 不匹配、签发失败、撤权或并发追加使待返回摘要与预授权集合不一致
- **THEN** 不披露该引用；工程/空间拒权与目标不存在保持同形，不能用其他来源版本的 grant 或过期上下文代替

### Requirement: 跨页面验收必须使用真实浏览器与正式接缝

系统 MUST 提供可运行的真实 Chromium 验收命令，在生产 Web 构建与真实 HTTP/授权/投影接缝上验证登录、导航、工程切换、质量查询、证据脱敏、拒权、刷新和基本键盘焦点行为；验收记录 MUST 包含浏览器版本、命令、数据集/运行引用和失败 trace。浏览器或必需服务不可用时 MUST 明确失败/阻塞，不以 Mock 浏览器、Mock 后端、跳过关键断言或截图外观代替通过结论。

#### Scenario: 真实浏览器完成跨页面链路

- **WHEN** 固定测试环境有真实 Chromium、真实 HTTP 服务及已登记样例报告
- **THEN** 验收从登录走到质量页面、跨页面返回与刷新，核对精确结果引用、授权与键盘可达行为

#### Scenario: 环境不可用或接缝拒绝

- **WHEN** 浏览器二进制、正式投影、认证或证据解析不可用
- **THEN** 命令以非零状态退出并保留失败证据，不改用替身或把跳过场景计作通过
