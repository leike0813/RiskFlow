## ADDED Requirements

### Requirement: 评估候选公共输入与授权调用身份必须闭合

评估候选读取 MUST 使用 strict 操作判别输入：C11 适用性目录要求精确工程修订与空间，外部事件目录要求精确空间且拒绝工程修订字段；C25 pending-catalog 的外部事件分支要求空间，风险记录分支可选空间，均拒绝工程修订字段。C25 对每次 C11 目录读取 MUST 以该次 queryId 与精确 branch 签发下游授权，并只保持或收窄当前已验证范围；拒绝必须返回闭合类型化失败。（RA-S1；RI-S14）

#### Scenario: strict 输入拒绝缺失与伪造范围
- **WHEN** 外部事件候选缺少空间，适用性目录缺少工程修订，或外部事件目录携带工程修订
- **THEN** 公共 Schema 拒绝输入
- **AND** 风险记录候选仍允许省略空间

#### Scenario: 两类入口目录各自获得配对授权
- **WHEN** C25 entry-context 组合适用性与外部事件目录，或 pending-catalog 读取外部事件
- **THEN** 每次 C11 调用的 queryId 与 C06 签发 invocationId 完全一致
- **AND** 业务空间修订映射到当前已验证的同一授权空间身份，不扩大工程、空间或资料范围

#### Scenario: 下游拒绝保持公共失败语义
- **WHEN** 当前授权或下游目录读取被拒绝
- **THEN** C25 返回类型化失败，不报告成功空目录且不抛出未闭合异常

### Requirement: 评估候选来源授权必须通过所属事实有界继承

系统 MUST 由 C11 提供有界窄读取，以 C25 当前读取的原调用身份和 risk-assessment.read 授权复验工程、主体与空间，将当前已验证的来源授权引用定位为精确来源版本，最多 256 项。C25 MUST 仅用这些版本重签每次目录授权并检查空间及来源授权保持或收窄原范围；定位不得读取跨域私表、产生业务写入或增加页面必填字段。（RA-S1；RI-S14）

#### Scenario: 真实来源范围继承
- **WHEN** C25 当前授权包含外部事件证据所需的来源授权，且对应 C11 就绪来源登记存在
- **THEN** C11 返回匹配来源版本，C25 以这些版本为每个目录签发配对授权，外部事件目录可以复验实际来源
- **AND** 页面无需提交额外来源版本字段

#### Scenario: 缺失错配或越界来源不得继承
- **WHEN** 来源授权已撤销、登记不存在或引用错配，或者下游签发包含原范围外的来源授权或空间
- **THEN** 读取返回安全类型化失败，不补成全工程资料权限或成功空目录

#### Scenario: 无来源授权保持空范围
- **WHEN** 当前获权上下文没有来源授权引用
- **THEN** 定位返回空来源集合，不扫描工程资料以自动扩大授权
