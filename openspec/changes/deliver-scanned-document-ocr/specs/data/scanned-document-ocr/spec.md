## Purpose

为 RiskFlow 提供受权限、版本和资源约束的扫描文档 OCR 转换能力，使扫描 PDF、PNG 与 JPEG 能形成保留页码、版面及表格单元格定位的可追溯结构化结果，并在低质量或服务失败时可靠拒绝空成功。（RI-S21～RI-S23）

## ADDED Requirements

### Requirement: 扫描资料只经受权的统一转换入口处理

系统 MUST 只接受已登记、权限状态就绪且媒体类型为扫描 PDF、PNG 或 JPEG 的精确资料版本，并通过统一文档转换 interface 启动 OCR。请求 MUST 固定工程、发起主体、授权上下文、资料版本、原始内容工件、转换策略版本、业务幂等身份和截止时间；处理前 MUST 复验工程、空间与资料正文权限。C13 不得提供绕过统一转换 interface 的第二个公共入口。（RI-S14、RI-S21）

#### Scenario: 获授权扫描资料进入 OCR

- **WHEN** 调用方通过统一文档转换 interface 提交受支持媒体类型、可用内容工件、就绪资料版本和覆盖该资料的冻结授权上下文
- **THEN** 系统读取精确原始工件并启动与该请求绑定的 OCR 转换
- **AND** 返回结果仍引用同一资料版本、原始工件和转换策略版本

#### Scenario: 未授权与不存在不可枚举

- **WHEN** 调用方无当前资料正文权限，或目标资料版本、原始工件不存在或不属于请求工程
- **THEN** 系统在联系 OCR 服务前返回相同的不可重试授权拒绝类别
- **AND** 不泄露目标存在性、文件名、正文、页数或任何 OCR 结果

#### Scenario: 非扫描输入不被错误接管

- **WHEN** 统一转换入口提交文本型 PDF、DOCX、XLSX、CSV 或契约外媒体类型
- **THEN** OCR 通道返回受支持类型不匹配的结构化结果或由统一转换入口选择其它已声明通道
- **AND** 不尝试把非扫描格式伪装成 OCR 成功

### Requirement: OCR 结果保留页码版面阅读顺序与表格坐标

系统 MUST 对每一输入页形成确定页码和页面尺寸，按页保存有序版面区域；文本区域 MUST 保存识别文本、置信度、阅读顺序和页内坐标，标题、正文、图注等版面类别 MUST 使用统一转换契约的闭合类别映射。表格 MUST 同时保存表格区域、行列身份、单元格坐标、跨行跨列信息及单元格文本。所有坐标 MUST 使用声明的坐标系并落在所属页面或表格边界内，不得只返回无定位的纯文本。（RI-S21）

#### Scenario: 中文扫描 PDF 保留页面与版面

- **WHEN** 多页中文扫描 PDF 的 OCR 服务响应包含文本、标题、图注和阅读顺序
- **THEN** 统一转换结果逐页保留原始一基页码、页面尺寸、区域类别、阅读顺序、文本置信度和页内坐标
- **AND** 相同服务响应重放产生相同的区域顺序和规范化坐标

#### Scenario: 表格单元格可以回到原页

- **WHEN** 扫描页包含跨行或跨列的表格且服务返回单元格识别结果
- **THEN** 每个单元格记录其所属页、表格、行列范围、页内坐标和识别文本
- **AND** 下游可由该定位形成 C11 `资料ID-章节ID-资料段ID` 对应的表格资料段而无需重新读取服务私有响应

#### Scenario: 非法结构整体拒绝

- **WHEN** 服务遗漏输入页、重复页码、产生越界或非有限坐标、重复阅读顺序，或单元格位于表格区域之外
- **THEN** 本次转换返回结构化输出校验失败并保存诊断引用
- **AND** 不登记部分资料段集合、不生成空白 JSON-LD 成功结果

### Requirement: 服务模型管线与资源版本完整可追溯

每次 OCR 转换 MUST 固定并记录 OCR 部署、服务构建、版面管线、全部生效模型、转换策略和资源分配的精确版本引用。服务调用只能使用配置中与请求部署引用一致的内网地址和受控参数；业务输入不得提供 URL、模型路径、设备名或任意服务参数。成功结果与失败诊断 MUST 同时记录请求身份、输入/输出字节数、页数、区域/单元格数、开始结束时间和上述版本引用，不得记录模型宿主路径或未授权正文。（RI-S14、RI-S21）

#### Scenario: 精确部署生成可重放结果

- **WHEN** OCR 服务以请求固定的服务、管线、模型和资源版本完成转换
- **THEN** 结果与原始响应工件均关联这些精确引用和处理计数
- **AND** 后续运行可区分同一资料在不同 OCR 版本下形成的转换结果

#### Scenario: 部署身份无法由冻结证据证明时拒绝调用结果

- **WHEN** 受控部署配置与真实 smoke 无法证明预置服务、管线能力和模型集合匹配请求固定的版本引用，或响应违反该冻结协议
- **THEN** 系统返回不可重试的部署不匹配失败
- **AND** 不把该响应转换为业务可用结果或自动切换其它服务/模型

### Requirement: 原始响应和规范化结果先耐久后成立

系统 MUST 在返回业务成功前，将 OCR 服务原始响应和统一转换结果分别保存为 C04 不可变工件，并继承资料版本的工程、空间和资料访问授权；两者 MUST 引用原始内容工件、资料版本、转换策略和 OCR 版本证据。任何写入、哈希校验或权限继承失败 MUST 使业务转换失败，已可靠落位但未被引用的工件只按 C04 孤儿策略处理。（RI-S14、RI-S21～RI-S23）

#### Scenario: 成功结果具有完整工件链

- **WHEN** 服务响应通过协议、结构和质量校验，且两个派生工件均完成耐久写入与校验
- **THEN** 系统才返回统一转换成功结果及其精确工件引用
- **AND** 证据链可从规范化结果回到原始响应、原始内容、资料版本和资料权限

#### Scenario: 工件持久化失败不返回成功

- **WHEN** 原始响应或规范化结果任一工件无法耐久写入、校验或继承权限
- **THEN** 系统返回结构化工件失败
- **AND** 不登记资料段、不返回仅存在于内存的 OCR 内容

### Requirement: 版本化质量门拒绝空成功和有害结构

系统 MUST 以冻结质量策略对 OCR 输出执行确定性质量检查，至少覆盖输入页完整性、非空文本页比例、有效坐标比例、阅读顺序完整性、表格结构完整性、服务置信度以及验收清单声明的关键字段覆盖率。质量策略 MUST 记录各阈值及来源版本；任何硬门未通过时 MUST 返回含逐项结果和失败页/区域定位的质量阻断，不得自动改写关键数值、补造文字或以警告状态冒充成功。甲方未提供真实脱敏样例时，验收清单 MUST 标注为合成样例、待甲方复核。（RI-S21～RI-S23）

#### Scenario: 中文样例达到全部质量门

- **WHEN** 固定中文扫描样例的全部输入页、关键字段、版面区域与表格定位达到冻结质量策略阈值
- **THEN** 系统返回每项质量指标、阈值版本和通过结果
- **AND** 后续统一转换流程可以使用该结果继续形成 JSON-LD 与资料段

#### Scenario: 关键字段或页面覆盖不足

- **WHEN** 任一必需页面缺失，关键字段覆盖率低于阈值，或空文本页、非法坐标、表格结构任一硬门未通过
- **THEN** 系统返回质量阻断并定位失败页、区域或单元格
- **AND** 保留原始响应与诊断证据供 C15 数据清洗和人工判断使用，但不发布业务可用转换结果

### Requirement: 幂等重试与结构化失败保持一致

系统 MUST 使用工程、转换分支和业务幂等键归一化同一请求；同键同载荷重试 MUST 返回原成功结果，或在原部署、策略、输入和资源预算下继续可重试失败，同键不同载荷 MUST 返回不可重试冲突。失败 MUST 区分授权/输入/部署/质量等不可重试原因，与服务不可用、超时、限流及工件暂时故障等可重试原因；重试不得更换 OCR 版本、放宽质量门、增加预算或重复登记资料段。（RI-S23）

#### Scenario: 成功请求幂等重放

- **WHEN** 调用方以相同工程、分支、幂等键和规范化载荷重放已成功转换
- **THEN** 系统返回首次的转换结果与工件引用
- **AND** 不重复调用 OCR 服务、写工件或登记资料段

#### Scenario: 可重试服务失败保持冻结输入

- **WHEN** OCR 服务暂时不可用或超时且冻结重试策略仍有预算
- **THEN** 系统只在原资料版本、部署、模型、策略、截止时间与资源配额内重试
- **AND** 预算耗尽后返回终止失败而不切换模型或返回空结果

#### Scenario: 同键载荷冲突

- **WHEN** 调用方复用已存在的幂等键但改变资料版本、原始工件、部署、策略或授权范围
- **THEN** 系统返回不可重试幂等冲突
- **AND** 原请求、结果和证据链保持不变

### Requirement: OCR 与 llama.cpp 的运行资源相互隔离

系统 MUST 为 OCR 和 llama.cpp 使用不同的部署身份、服务地址、并发控制、取消信号、超时预算和资源分配引用。OCR 队列饱和、请求取消、服务崩溃或资源预算耗尽 MUST 只影响对应 OCR 请求；不得取消、重配、降级或占用 llama.cpp 的调用预算。物理设备、容器和显存/内存配额由部署清单冻结并可在目标环境核对，C13 不得在运行时自行重分配设备。（RI-S21、RI-S51）

#### Scenario: OCR 饱和不阻断模型调用

- **WHEN** OCR 并发达到冻结上限且新的 OCR 请求被限流或排队
- **THEN** 使用独立部署和预算的 llama.cpp 请求仍按其自身状态完成或失败
- **AND** 两类调用记录各自的部署、资源和错误引用

#### Scenario: 单个 OCR 取消保持故障域

- **WHEN** 一个 OCR 请求被取消、超时或服务连接中断
- **THEN** 只终止该请求及其尚未成立的转换结果
- **AND** 其它 OCR 请求、llama.cpp 请求和既有耐久工件不被回滚或取消

### Requirement: 协议替身与真实内网服务分层验收

系统 MUST 使用仅存在于测试目录的协议替身确定性覆盖请求映射、权限、幂等、版本、坐标/表格校验、质量门、超时、取消、断流、限流、工件失败和资源隔离。系统 MUST 另提供显式启用的真实服务 smoke，对操作者预先部署并冻结版本的内网 OCR/版面服务执行中文扫描 PDF、PNG 与 JPEG 样例；smoke 不得下载模型、启动或停止服务，也不得以协议替身结果充当真实 OCR 证据。

#### Scenario: 默认测试无需外部 OCR 服务

- **WHEN** 验证者运行默认目标测试且未显式启用真实服务 smoke
- **THEN** 协议替身覆盖全部确定性契约并明确报告真实 smoke 未运行
- **AND** 生产包不导出替身、静态 OCR 结果或自动成功回退

#### Scenario: 显式 smoke 验证真实服务

- **WHEN** 验证者提供预置服务的精确部署、服务、管线、模型和资源配置并显式启用 smoke
- **THEN** 三类扫描输入通过同一生产 adapter，中文关键字段、页码、版面和表格定位均按冻结清单核验
- **AND** 报告记录版本与资源引用、质量指标和工件引用，不记录正文或模型宿主路径
