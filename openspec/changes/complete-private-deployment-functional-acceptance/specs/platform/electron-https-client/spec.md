## ADDED Requirements

### Requirement: 桌面功能验收与正式离线发布分阶段

后续功能阶段 MUST 以真实功能证据核验完整 Web 独立运行和当前平台 Electron 的导航、TLS/证书、权限、会话、命令确认/幂等、SSE 重连与已受理任务继续。桌面特有行为须有桌面证据，代码存在或浏览器测试不能替代。正式签名、多平台安装、三 VM 与硬件材料缺项不得阻塞已有完整功能证据的当前功能 PASS、集成和归档。

C38 MUST 按 Windows 11 x64、Ubuntu 24.04 x64、macOS 14+ arm64 矩阵提供签名/信任合规离线包及逐平台真实安装和功能证据；安装运行不依赖公网下载或自动更新。签名/公证缺项仍须拒绝正式制包，不增加未签名分发。工程、当前功能与 C38 正式证据分别记录，不能互相替代或冒称未来交付通过；三 VM/4090 取证沿最终部署规格。移动端、PWA 与脱离服务器业务不在范围内。

#### Scenario: C38 无公网环境安装正式客户端

- **WHEN** 操作者在声明的目标系统使用完整离线安装包与部署配置
- **THEN** 客户端无隐式下载地安装运行并连接批准的内网 HTTPS，报告记录平台、桌面与服务端发布身份

#### Scenario: 当前功能验收与 C38 平台证据缺失

- **WHEN** 当前功能证据满足要求，但 C38 的一个或多个正式平台、签名/公证、三 VM 禁网部署或 4090 性能/资源证据尚未取得
- **THEN** 功能阶段可记录功能 PASS 并继续集成与归档；C38 对应证据保持未完成，不将其记录为通过

#### Scenario: 兼容界面更新与正式平台证据

- **WHEN** 兼容的服务端界面更新，或 C38 某个声明桌面平台缺少正式签名材料、介质或真实安装环境
- **THEN** 前者由客户端加载同一 HTTPS 入口的新界面；后者仅将相应 C38 平台交付证据记为未完成，正式包不使用缺项回退
