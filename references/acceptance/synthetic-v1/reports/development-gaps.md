# 功能预验收前置与开发缺口

本记录针对合成材料的导入和功能验证，标识为“合成样本，待甲方复核”。它不代表甲方验收意见。核查基线为 `6fd462e9fc61e92b39903a3087e2e2a8a21c1b5a`，工作区含未提交的 C37 改动；以下路径按当前工作区记录。

| 编号 | 已确认事实和证据 | 对预验收的影响 | 关闭所需证据 |
| --- | --- | --- | --- |
| G-01 | `apps/api/src/http.ts` 的 `HTTP_ROUTE_CATALOG_V1` / `HTTP_SYSTEM_ROUTE_CATALOG_V1` 没有材料上传、工件读取入口；工件流处理仅见 `packages/adapters/src/artifacts/artifact-stream-service-handler.ts` | JSON、DOCX、PDF 等本地材料不能直接取得正式 `content-artifact` 引用；引用型导入命令阻塞 | 在目标环境完成受权工件导入，提供真实回执和摘要，或另开 change 闭合受限上传接口 |
| G-02 | 工程/空间修订服务已有 `reviseContext`，文档转换服务已有实现；当前 HTTP 注册表未暴露相应入口，浏览器测试通过宿主内调用准备数据 | 新虚构工程的版本、空间和转换结果需要环境准备方完成；不能用测试宿主播种代表正式导入 | 当前版本工程/空间配置的正式回执、权限绑定、文档转换审计与资料段标识 |
| G-03 | `apps/api/src/index.ts` 导出 `buildApi`，自身未装配监听宿主。部署服务文件所指启动路径不能由本次只读调查证明可运行 | 本次不启动服务器；需用户提供已有正式服务 URL、账号及接线说明 | 正式宿主、数据库、Worker、模型的健康证据及已激活 OpenAPI 操作清单 |
| G-04 | C24/C25/C30 有识别、评估及流程入口；既有 worker/browser 验收含替身或宿主内播种 | 已有入口不等于本包从干净输入完成全链路。单测和静态样本均不能证明 RI/RA 业务通过 | 从正式导入输入开始的一次完整运行，含零结果终态、资料段→工序→机理→风险→评估→预警→处置反馈的真实引用 |
| G-05 | C36 CLI 消费既有业务结果；`quality-evaluation.sample-snapshot` / `.replay-context` 的生产侧产出尚未核实，现有证据主要来自测试 | 不计算重放率，不发布 C36 正式质量报告；版本引用解析仍需核查 | 生产侧输入快照与重放上下文产出、授权精确读取、完整版本解析及第三方重放记录 |
| G-06 | 本包标签为 candidate，阈值、权重、矩阵、量化规则为模拟配置 | 可以用于开发和内部探索；不能以候选答案判定正式识别准确率或工程安全 | 甲方逐项审核数据、规则、适用性、候选标签与验收口径；产生新版本 |

G-01～G-03 是本包运行的环境前置；G-04～G-05 是后续业务证据核验项。这里没有判定已有领域服务缺失，也没有修改生产接口。需要开发时，应按项目 OpenSpec 流程建立明确范围的 change。

甲方材料到位后，应逐项替换工程地质与设计、风险源清单、风险矩阵、指标及映射、量化标准、权重、监测阈值与样例、措施与通知策略、标签及验收核查要点。保留本包版本和旧运行，形成新包、新运行及差异记录。
