## ADDED Requirements

### Requirement: C35 系统管理必须从当前会话取得独立管理授权

系统 MUST 提供当前会话系统管理身份、安全账号/工程/成员/空间目录及管理命令入口。每次请求由服务端验证 Cookie 会话、账号当前管理员授予、首次改密限制和安全修订；管理授权引用仅在服务端生成并传给 C06，客户端不得提交或覆盖。系统管理 MUST 不借用工程业务 branch 或空业务能力集合，不修改会话元数据的现有形状、不隐式授予工程业务能力。

#### Scenario: 当前管理员无工程身份
- **WHEN** 活跃且已完成首次改密的系统管理员请求目录或六项管理动作
- **THEN** 服务端独立证明管理员身份并调用原管理端口，不要求其先获得工程成员权限

#### Scenario: 旧管理授权与普通用户
- **WHEN** 用户不再是管理员、会话已失效、仍需改密或伪造管理引用
- **THEN** 在任何目录或命令前安全拒绝，不使用登录时的旧授权引用继续执行

### Requirement: C35 管理目录与六项写入必须保持版本和敏感数据边界

管理目录 MUST 有界，仅披露账号显示身份/状态/当前版本、工程访问壳、成员角色/范围与精确版本，不返回密码派生值、秘密、会话 token 或安全内部行。账号创建/停用/重置、工程开通/暂停、成员修订 MUST 复用 C06 的预期版本、幂等收据和原子安全审计；密码不得进入页面缓存、确认摘要、普通日志或收据。

#### Scenario: 管理命令重试与冲突
- **WHEN** 同一管理命令重放，或两个修订使用同一预期版本
- **THEN** 重放返回原引用，版本竞争至多一个胜出，不覆盖已发布修订

#### Scenario: 安全审计失败与密码处理
- **WHEN** 账号创建/重置含密码或安全审计无法持久化
- **THEN** 密码仅用于凭据计算且不进入回执/审计，审计失败回滚访问变更并不返回成功
