## MODIFIED Requirements

### Requirement: C33 识别运行与风险记录只读必须有界且复验当前授权

系统 MUST 为风险识别域提供运行列表、运行详情、风险记录目录与记录详情。运行列表按工程有界返回运行状态引用、状态、阶段、启动者、启动时间与验收/待复核/拒收计数，触发原因只在登记存在时返回；详情保留所选精确运行状态的 I0～I9、工序工作项、合并组、验收路由、关联 Agent/复核与结果汇总，并提供启动者/时间。列表和详情的启动者/时间 MUST 取同一条最早运行状态登记，不以其它恢复者的字典序替代启动者。风险目录保留记录引用、工序、事件摘要、综合置信度、验收方式、当前效力及工序/验收筛选；风险详情保留七字段、记录信封、证据、机理与来源、识别运行、验收决定及真实取代/作废关系。两种详情 MUST 支持精确引用读取，或按同工程单一实体身份定向定位：运行裸身份返回最新登记状态，风险裸身份返回该记录唯一登记版本。两种输入互斥，不接受空引用、冲突选择或任意对象类型；显式状态/记录版本不得换版，最新运行状态无权不得回退旧状态。披露前必须通过当前完整工程、空间与来源权限，成功返回完整精确引用；不存在、错版、跨工程与无权同形失败且不可枚举。运行状态版本随推进改变，精确状态读取保持历史快照，实时跟踪须按裸运行身份重新读取。技术/I/O 故障 MUST 保留原 transient/terminal 语义，不吞成拒权或不存在。列表不超过50并使用稳定游标，详情不依赖目录页或全工程扫描；内部复用登记事实与入口决定，只读不改记录、不创建命令收据、不触发新识别或模型。（RI-S5～RI-S6）

#### Scenario: 获授权调用方读取运行与记录
- **WHEN** 当前工程获权调用方请求首页/游标页或精确任务与风险详情
- **THEN** 返回有界条目或该精确版本正文，完整引用和头部来自同一对象，重复读取不追加业务事实

#### Scenario: 越权或跨工程不可枚举
- **WHEN** 调用方请求其它工程的运行或记录、撤权后再次请求，或给定不存在/错误版本
- **THEN** 同形安全失败，不返回条数、名称、版本或存在性线索，不选择其它可读对象代替

#### Scenario: 等待复核与失败状态如实呈现
- **WHEN** 运行处于等待复核或 Agent 可重试失败状态
- **THEN** 详情返回真实状态及关联复核或失败阶段/错误码，已入库事实计数不回退

#### Scenario: ID-D-S01 页外实体无需目录扫描
- **WHEN** 用户只持有不在首页的任务或风险实体 ID，按无版本入口请求
- **THEN** 所属读面按本工程和实体定向取得运行最新状态或风险唯一登记版本，完整来源/空间当前授权成功后返回精确引用及原详情，不读取目录首页定位

#### Scenario: ID-D-S02 最新候选不可读不得回落历史
- **WHEN** 同一运行存在多个状态版本，最新状态无权而旧状态可读，或给定精确状态/风险记录版本不存在
- **THEN** 请求同形拒绝，不泄露新版本身份，不回落旧版本；显式请求合法旧版本仍沿原当前权限精确读取

#### Scenario: ID-D-S03 新定位不吞技术失败
- **WHEN** 身份定位或其原详情读取发生数据库、工件或审计故障
- **THEN** 返回原技术错误与可重试性，不返回成功空对象，不映射为普通无权/不存在，也不追加业务事实

#### Scenario: ID-D-S04 后续恢复不改启动者
- **WHEN** 同一运行后续由字典序更小的另一账号恢复，并读取列表、实时详情及早期精确状态
- **THEN** 三者头部来自同一最早运行状态登记，早期详情不混入其时间边界后的头部，恢复者不替代启动者
