## 端到端追溯链

资料段标识 → 工序节点 → 风险机理条目 → 标准化风险记录 → 风险评估记录 → 预警信息 →
处置建议 → 偏差记录 / 校准建议。

本包只提供前三个环节的输入锚点：

- 资料段标识：cases[].inputs.sourceSegmentIds（SYN-{DEV|TRIAL}-SEG-序号-{LOG|GEO|LEDGER}）。
- 工序节点：knowledge/process-model.json 的 nodeId 与 cases[].processNode。
- 风险机理条目：knowledge/risk-mechanism.json 的 mechanismId 与适用 nodeIds。
- 后续记录环节（标准化风险记录 → 风险评估记录 → 预警信息 → 处置建议 → 偏差记录 / 校准建议）：
  本包**不提供**任何成品记录，只提供这些环节应使用的配置、评分规则与反馈输入。
  真实记录必须由正式运行产生；运行结果与状态写入 reports/ 下的报告与 run 记录，
  未产生终态证明前不得声称链路贯通。

## 确定性边界

P/C 计算、矩阵映射、阈值判断、适用性校验与 Schema 校验均由确定性领域模块负责。
本包的候选评分由 generate-materials.py 内显式合成分段算式独立计算，
不调用任何被测评估函数；其作用是提供对照，不是断言被测实现正确。
