## MODIFIED Requirements

### Requirement: 类型化任务定义与领域工具白名单

Agent MUST 使用已登记任务类型和领域工具；宿主将任务内资料映射为短选项，解析为真实版本后执行，不让模型填写操作者、授权和长技术身份。分页及已读进度由宿主管理，字段与选项在工具入口检查；通用数据库、Shell、任意文件或联网工具不作为业务能力开放。

#### Scenario: 调用允许的领域工具

- **WHEN** Agent 从任务提供的短选项中选择已登记只读工具和资料
- **THEN** 宿主解析真实版本并在新读取入口检查当前权限及剩余预算后执行

#### Scenario: 拒绝越权或未列入白名单的工具

- **WHEN** 任务请求没有登记的工具或真实来源权限已经撤销
- **THEN** 拒绝工具行动；任务内短选项的普通格式错误可在原预算内反馈修正

#### Scenario: 拒绝通用修改格式

- **WHEN** 模型返回 JSON Patch、整对象覆盖或不匹配任务类型化增量 Schema 的写入内容
- **THEN** 运行时拒绝该动作
- **AND** 不将其转换为领域命令或业务事实

#### Scenario: 模型使用短资料选项

- **WHEN** 助手读取任务内一份资料
- **THEN** 宿主解析真实引用并返回该资料片段及读取进度

#### Scenario: 普通选项错误可修正

- **WHEN** 模型漏填字段或选项不属于任务候选
- **THEN** 返回可理解的结构化纠错，不执行错误工具行动

### Requirement: 类型化增量与确定性校验收口

模型输出 MUST 在统一运行时经原 Schema 和领域规则校验。格式、缺字段、数量及冻结选项错误可在原任务剩余修正次数、token 与时间预算内反馈；网关提供已保存原响应及可修正原因，不自行重试。权限、真实来源资格、专业规则冲突及处置三项约束不由模型反复尝试改变。

#### Scenario: 可修复格式错误

- **WHEN** 候选只因字段、格式、引用或增量完整性不满足 Schema
- **THEN** 运行时记录被拒候选和确定性原因
- **AND** 仅在同一策略与剩余修正预算内请求新候选版本

#### Scenario: 候选越过冻结集合

- **WHEN** 模型填写了冻结候选之外的选择编号
- **THEN** 不执行该增量，反馈可修正的选项错误；真实来源资格与业务冲突不由循环改变

#### Scenario: 不可修正约束失败

- **WHEN** 候选违反权限、来源资格、版本兼容、规则冲突或处置三项约束之一
- **THEN** 运行时记录终止性拒绝和证据引用
- **AND** 不将失败反馈为可循环规避的修正请求

#### Scenario: 结构错误在原任务修正

- **WHEN** 原响应正常结束但缺字段且修正预算有余
- **THEN** 记录本次失败与消耗，反馈错误并生成新候选，原响应保留

#### Scenario: 预算不足停止

- **WHEN** 模型尚未形成合格输出且剩余预算不足
- **THEN** 显示明确终态及已用资源，不以空结果继续

## ADDED Requirements

### Requirement: 任务范围冻结且权限按业务动作检查

任务 MUST 固定发起者、工程和输入范围，统一业务动作入口在每次新资料读取及正式结果提交前应用当前权限。Worker 不依赖旧会话或过期启动授权；内部模块不逐层签发行动凭据。新授权不能扩大已冻结任务来源，账号停用或撤权在下一动作拒绝。

#### Scenario: 任务跨网页登录期限

- **WHEN** 会话到期而原账号仍有权限、预算和有效执行资格
- **THEN** 继续原任务，不更换模型或重置预算

#### Scenario: 撤权后阻止新动作

- **WHEN** 任务发起者失去目标资料权限
- **THEN** 下一读取或结果提交拒绝，保留已完成动作记录

### Requirement: 失败任务证据按当前权限直接读取

系统 MUST 允许有权用户按任务精确引用读取任务类型、终态、安全错误、取消原因、预算与动作候选校验引用；不返回模型正文、思维链或任意工件正文。普通重复读取仅记录访问，不使用写命令去重。入口区分无权、获准范围内不存在及读取故障。

#### Scenario: 旧任务证据重复查看

- **WHEN** 有权用户多次打开同一失败任务
- **THEN** 得到原安全证据，各次访问互不冲突

#### Scenario: 系统异常明确反馈

- **WHEN** 精确证据读取遇到内部技术错误
- **THEN** 返回读取失败与定位引用，不伪装为任务无权
