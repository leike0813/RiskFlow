## ADDED Requirements

### Requirement: 外部事件所有者提供有证据的结构化风险事实

系统 MUST 按工程和精确外部风险事件版本读取已登记事件，并经当前工程、空间、资料和调用身份复验后，从其精确内容工件提供统一风险事实投影。可评估事件工件 MUST 声明工程、外部来源精确版本、事件键和非空结构化标量字段，每项字段固定资料类型、字段路径、真实标量值及非空证据；这些身份必须匹配事件登记，字段证据必须属于登记证据集合。该能力不得从自由文本猜测字段值，不改变已有事件登记、资料段定位查询或原始资料正文的所有权。（RA-S1；RI-S14）

#### Scenario: 精确结构化外部事件进入评估
- **WHEN** 获授权调用方读取一个已登记事件版本，其工件身份、字段与登记证据全部合法
- **THEN** 系统返回原外部事件引用、真实标量和原证据，供准备快照冻结及评估消费
- **AND** 不创建标准化风险记录副本或修改事件登记

#### Scenario: 工件身份或字段证据不符时拒绝
- **WHEN** 获授权事件的工件身份不符、包含重复字段、非法标量、契约外字段、越界证据或超过读取预算
- **THEN** 系统返回类型化契约或业务失败，不返回部分字段、不形成正式评估输入

#### Scenario: 任意已登记正文不能冒充结构化事实
- **WHEN** 已登记事件的内容工件未满足可评估结构化字段契约
- **THEN** 原登记保持有效，但风险事实读取失败闭合
- **AND** 不从登记键、自由文案、零值或最新资料补造缺少的评估字段

#### Scenario: 当前权限失效或精确目标不可读
- **WHEN** 调用身份不匹配、事件不存在、跨工程、错版本或当前授权未覆盖全部事件空间和来源
- **THEN** 系统返回同类不可枚举授权拒绝，不披露正文、存在性或部分证据

#### Scenario: 来源发布变化不改写旧事件事实
- **WHEN** 事件登记后出现新的资料版本或相同来源的其它事件
- **THEN** 获授权的精确读取仍返回原事件工件和原证据对应的同一标量事实

### Requirement: 评估准备向风险事实读取传递当前获准来源范围

C11 MUST 在复验准备冻结调用方后，从当前有效来源授权引用通过自身登记事实有界解析精确资料版本，并将该范围连同本次获准空间传入风险事实读取授权。来源授权引用与资料版本引用 MUST 分别按各自契约解析；下游来源授权不得超出入口当前复验集合。风险事实所有者 MUST 继续复验目标保存的全部空间和来源，C06 的授权收窄规则保持生效。（RA-S1；RI-S14）

#### Scenario: 入口来源授权可用于准备冻结
- **WHEN** 当前准备冻结授权覆盖目标的空间和全部来源，且授权引用能唯一映射至该工程的精确资料版本
- **THEN** C11 签发带该来源范围的事实读取上下文，由正式 reader 收窄复验后冻结准备快照
- **AND** 不增补来源权限、不选择最新资料版本

#### Scenario: 来源范围不能证明时拒绝冻结
- **WHEN** 入口缺少目标来源授权、来源已撤权、映射缺失或歧义，或下游授权包含入口未获准的来源或空间
- **THEN** 系统以不可枚举授权拒绝收口，不返回风险事实、不保存准备成功事实、业务收据或 Outbox
- **AND** 原安全及读取审计按其契约保留
