## ADDED Requirements

### Requirement: 多父工件当前授权使用精确空间并集

本地宿主 MUST 按精确kind、entityId和versionId合并多个父工件的空间引用再提交当前权限复验；同空间不重复，不同精确空间不得丢弃。各父工件原用途、来源权限与完整性校验 MUST 保持，无父工件使用原请求空间。

#### Scenario: 两个父工件共享同一空间

- **WHEN** 新工件合法引用同一空间下的多个父工件
- **THEN** 普通预置与业务请求均按唯一空间并集复验，当前撤权或任一父工件不可访问仍拒绝，未授权时不写工件清单

### Requirement: 工件来源限制独立于逐段证据

宿主 MUST 根据目标工件登记的资料授权限制复验真实来源版本，不因缺少逐段evidence把来源替换为空。C06 MUST 在本工程解析稳定授权身份并检查当前权限及任务冻结上界，未知、跨工程或无权来源拒绝。写入及模型调用 MUST 保留输入的资料限制，不扩大权限、复活旧任务或改变预算。

#### Scenario: 无逐段证据的冻结清单

- **WHEN** 合法冻结清单保留资料授权限制但没有逐段evidence
- **THEN** 由所属登记解析实际来源并在当前有权时读取；撤权、跨工程或任务范围外仍拒绝

### Requirement: 读取块字节在消费者保留后保持稳定

C04 文件流 MUST 在输出边界为每个读取块交付独立字节副本；消费者保留已交付块并在其后继续读取或于 EOF 后拼接时，先前块 MUST NOT 被内部缓冲区复用改写。1MiB 分块、资源限制、EOF消费、访问记录和取消保持；消费终态使用新 C04 `completed`，普通读取不附带全文摘要验证。

#### Scenario: 多块不同内容完整保留后拼接

- **WHEN** 消费者按序读取一个大于单块上限、各区段内容不同的工件，保留每块返回字节并在 EOF 后拼接
- **THEN** 拼接结果与原始内容逐字节一致，`completed` 仅在完整消费及终态记录后判定
- **AND** 重放读取返回一致内容，先前交付块在后续读取发生后仍与其被交付时一致

#### Scenario: 保留块后的取消保持原契约

- **WHEN** 消费者在保留块后取消在途读取
- **THEN** 取消沿原契约收口，先前保留块不被改写，`completed` 不在未完成消费时判定
- **AND** 不新增摘要、整文件缓存或额外读取接口
