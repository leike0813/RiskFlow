## MODIFIED Requirements

### Requirement: 模型部署能力和尺寸由配置冻结

部署 MUST 固定端点、模型身份、能力、上下文及 Embedding 维度，实测记录保留。服务补丁版本变化在同一主次版本且实际协议和模型能力符合时允许使用；主次版本变化或权重、协议、维度不符仍需显式更新部署。供应商不可观测构建不伪造。

#### Scenario: 配置化部署调用成功

- **WHEN** 请求引用的冻结部署支持所需能力，所选后端的模型、协议和尺寸证据与冻结配置一致
- **THEN** adapter 使用配置中的模型别名和端点执行请求
- **AND** 结果只返回精确部署/版本引用与受控元数据，不返回模型路径或服务基址

#### Scenario: 业务不能选择模型名

- **WHEN** 业务请求尝试携带模型名、模型路径、URL 或覆盖部署参数
- **THEN** 请求 Schema 拒绝该字段
- **AND** 发送给所选后端的模型标识只能来自部署配置

#### Scenario: 部署能力或版本不匹配

- **WHEN** 实际模型摘要、协议能力、上下文或维度不相容，或服务主次版本超出配置
- **THEN** 返回部署错误；兼容补丁字符串变化不单独阻断

#### Scenario: 补丁版本兼容

- **WHEN** Ollama 从 0.40.0 变为 0.40.3，模型摘要、协议、上下文及维度一致
- **THEN** 调用正常执行并记录实际版本，不仅因完整版本字符串不同拒绝

#### Scenario: 实际模型能力改变

- **WHEN** 模型摘要或输出维度与声明不同
- **THEN** 返回部署错误，不混用原向量空间

### Requirement: 结构化生成必须按冻结 Schema 提交并经本地 Zod 复验

结构化生成 MUST 使用同一版本化 Zod 输出 Schema 及其生成约束，保留显式结构化模式，包括已接入的单函数参数承载。正常响应须经本地解析和 Schema 验证；格式或字段错误返回原响应引用、真实用量和可修正分类，由任务运行时决定剩余预算内的新候选生成，网关本身不重试或修补内容。

#### Scenario: 双重约束后的结构化结果成功

- **WHEN** `openai-chat` 正常终止并返回满足冻结结构化模式且通过原 Zod Schema 的单个结构化值
- **THEN** 网关返回类型化值、精确部署/提示/Schema 引用、使用量、终止原因和已耐久原始响应引用
- **AND** 下游仍按 RI-S58～RI-S59 执行字段统一、领域规则与仿真约束

#### Scenario: Schema 提示与本地严格复验

- **WHEN** 部署选择 `schema-prompt` 且模型返回单个正常终止 JSON 值
- **THEN** 固定 system 消息包含从同一 Zod Schema 生成的 JSON Schema，原 Zod Schema 决定最终接受或拒绝
- **AND** 不依赖模型遵循提示来替代本地校验

#### Scenario: 非法 JSON 结构失败

- **WHEN** 正常结束的响应不是单个合法 JSON 或带多余正文
- **THEN** 保存原响应及消耗，返回可修正结构错误，由统一运行时在剩余预算内决定下一候选；网关不自行修补或重试

#### Scenario: Zod 复验失败

- **WHEN** 正常响应缺字段、类型或范围不满足输出Schema
- **THEN** 保存原响应和具体字段问题，返回可修正输出错误；通过格式修正后仍执行原业务校验

#### Scenario: 服务端 Schema 约束缺少证据

- **WHEN** 部署请求 `server-json-schema` 但没有真实证据证明目标服务执行该约束
- **THEN** 配置/就绪核验失败
- **AND** 不把服务接受请求或单次合规响应当作严格约束证明

#### Scenario: 输出 Schema 无法安全转换

- **WHEN** 调用方 Zod Schema 无法转换为支持的 JSON Schema 子集
- **THEN** 网关在网络调用前返回不可重试的 Schema 不支持错误
- **AND** 不退化为纯文本生成或依赖不完整提示继续执行

#### Scenario: reasoning 内容不进入持久化或展示

- **WHEN** MiniMax 响应含 `reasoning_content`
- **THEN** 该字段在 C04 持久化、API 返回、日志、界面和验收报告前剔除
- **AND** 可审计的协议证据和普通正文继续受各自原权限及 C04 保护范围约束
- **AND** C04 MUST 保留可审计的协议证据，但不得持久化或展示 MiniMax `reasoning_content`；原始响应正文受 C04 既有受保护权限范围约束，普通日志、界面和验收报告不得披露正文或思维内容

#### Scenario: 格式错误可被上层反馈

- **WHEN** 模型正常结束但 JSON 或字段不合规
- **THEN** 网关保存响应并返回可修正结构错误，上层能够在原预算内修正

#### Scenario: 合规输出保留业务校验

- **WHEN** 输出通过 Zod
- **THEN** 仍由所属业务模块校验来源、规则和专业约束

#### Scenario: 不保存思维链

- **WHEN** 响应包含 reasoning_content
- **THEN** 持久化和展示前剔除，保留实际回答和协议元数据

### Requirement: 原始响应通过 C04 先耐久保存再返回引用

模型响应 MUST 保存为继承资料限制的工件再返回正式结果引用；同步响应可以直接解析同一次有界读取已取得的字节，不为证明保存成功再回读全文。流式响应的正式终态仍等待工件登记和协议消费结束；持久化或实际读取失败如实返回。

#### Scenario: 同步响应先保存后返回

- **WHEN** 同步模型正文已完整接收并且响应工件登记成功
- **THEN** 使用同次有界读取获得的字节解析并返回登记引用，不再从文件存储重复回读验真

#### Scenario: 流式终态等待工件提交

- **WHEN** SSE 已完整结束但原始响应工件仍在提交
- **THEN** 增量可以已经被消费，但终态 Promise 保持未完成直至 C04 `put` 成功
- **AND** 工件失败会使终态失败而非返回悬空引用

#### Scenario: 失败流保存已接收原文

- **WHEN** 流在收到部分有限字节后取消、超时、断开或协议失败
- **THEN** 网关在可安全完成 C04 写入时保存该部分为同权限诊断工件，并仅在结构化错误中返回引用
- **AND** 日志、指标、Outbox 和检查点不复制部分正文

#### Scenario: 工件存储失败时 fail closed

- **WHEN** 模型响应无法登记或实际消费失败
- **THEN** 返回工件错误并记录实际调用用量，不以未登记引用冒充成功

#### Scenario: 同步响应只消费一次正文

- **WHEN** 收到正常结构化响应并成功登记
- **THEN** 直接解析同次读取的有界内容，无需通过文件存储再次完整回读

#### Scenario: 保存失败不伪装成功

- **WHEN** 原始响应工件登记失败
- **THEN** 返回保存失败，已发生调用消耗如实保留

### Requirement: 网络 API 必须保持原网关的授权预算与证据契约

联网模型 MUST 通过既有统一网关使用配置端点、服务端凭据、任务输入和资源预算；当前权限由业务动作入口检查，内部网关不重复签发身份。Ollama Embedding 保留模型摘要、上下文与维度校验，补丁版本使用实际协议兼容规则。上层允许明确的候选纠错，adapter 不自行重试、切换模型或扩大输入。

#### Scenario: 合法联网后端被业务复用

- **WHEN** 冻结部署支持当前能力且业务动作已获准、预算充足
- **THEN** 沿配置端点及服务端凭据调用，Ollama核对模型摘要/上下文/维度并允许同主次版本的兼容补丁，记录实际版本

#### Scenario: 无权资料或秘密进入客户端

- **WHEN** 输入资料不具备联网验收资格，或请求试图携带 API 凭据、任意 URL 或模型覆盖
- **THEN** 在网络副作用前拒绝，秘密不进入 Web、Desktop、日志、DTO 或发布包

#### Scenario: 网络协议失败保持原错误边界

- **WHEN** 上游拒权、限流、超时、断流、结构化约束不支持、向量尺寸或部署身份不符
- **THEN** 返回原闭合模型错误与可用耐久诊断，不补造结果、不透传未授权上游正文、不自动改协议或重发生成

#### Scenario: 后端切换不得复用旧向量空间

- **WHEN** 操作者切换网络 API 与 llama.cpp，或改变 Embedding 模型、版本或维度
- **THEN** 必须形成新部署版本及对应检索代际，按原构建和质量门禁激活，不混用旧向量空间或改写历史结果

#### Scenario: 合法网络调用

- **WHEN** 任务资料资格和模型部署符合，调用预算充足
- **THEN** 返回真实结果、用量和工件引用，沿同一模型协议执行

#### Scenario: 协议或模型错误

- **WHEN** 服务实际能力不符或网络响应无法完成
- **THEN** 返回类型化错误及已有证据，保持原实际消耗
