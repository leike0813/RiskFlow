## ADDED Requirements

### Requirement: 官网表格图片仅解析耐久包内受控载荷

官网表格自闭合img的唯一src MUST 在本次已耐久并完整性验证的ZIP内唯一解析为JPG/PNG，沿既有包及图片资源预检后建立未识别图片引用。外链、data URL、绝对/包外路径、缺失或歧义条目、额外属性和活动内容 MUST 整体拒绝；不得打开服务器文件路径、发起图片网络请求或把图片当成文字。自托管没有相同可验证包上下文时继续拒绝。所有引用及输出受原预算限制。

#### Scenario: 包内图片可追溯

- **WHEN** 官方表格引用本次ZIP中唯一合法图片
- **THEN** 图片引用固定该原响应工件与精确包内路径，正文及质量文字覆盖不包含图片名

#### Scenario: 外部或无法证明的图片

- **WHEN** src越界、条目缺失或歧义、属性不受支持或图片预检失败
- **THEN** 转换失败保留原响应及诊断，不下载外部图片或跳过单元格

### Requirement: 官网图表结构按共享惰性语义映射并保留历史版本

系统 MUST 将官网协议已观察到的图表结构映射到既有共享规范化语义：行内span支持`chart`；块级支持`chart`、`chart_body`、`chart_caption`、`chart_footnote`；`chart`容器沿既有递归规则映射，`chart_body`在验证`chart` span后映射为共享结构要求的惰性图像载荷；图注与脚注保留真实文本及源坐标。图表图像内容 MUST NOT 被推断为文本、指标值或公式值；原图路径与完整原始响应 MUST 保持从原始工件可追溯。

未知类型、未知协议版本、越界坐标与资源超限 MUST 继续拒绝。新转换部署或策略 MUST 通过 C11 正式新资料版本形成新资料段集合并冻结新的转换器部署引用，不得仅换 `conversionId` 覆写原资料版本；原失败记录、原始响应与历史资料版本 MUST 保持可重放，不被改写或清洗为成功。

#### Scenario: 官网图表结构映射为可追溯惰性载荷

- **WHEN** 官网返回包含`chart`、`chart_body`、`chart_caption`、`chart_footnote`及`chart` span的受支持结构
- **THEN** 系统按既有递归映射为共享惰性图像载荷并保留图注、脚注文本与源坐标
- **AND** 图像内容不进入正文、指标或公式值，原图仍从原始工件可追溯

#### Scenario: 未知结构与历史版本不被覆写

- **WHEN** 响应包含未观察类型、未知版本、越界坐标或超出资源限制，或运维以新解析部署重新转换
- **THEN** 前者严格拒绝并保留可成立的诊断；后者使用 C11 正式新资料版本与新转换器部署引用生成新资料段集合
- **AND** 原失败、原始响应与历史资料版本保持原样，不以换 `conversionId` 覆写为成功
