# 待甲方输入与开发缺口

本包在甲方正式输入到位前可用，但它不能替代正式业务输入。以下事项分为「等甲方输入」与
「开发缺口」两类，都不在本材料包内解决。

## 一、等甲方输入（外部前置，缺一不可）

| 事项 | 现状 | 影响 |
|---|---|---|
| 风险评估指标体系与量化标准 | 本包为合成 3 指标（2 可能性 + 1 后果） | 正式评分口径、权重与分级区间待定 |
| 风险矩阵与风险等级 | 本包为显式合成 3×2 矩阵、四级等级 | 甲方矩阵发布后须新增不可变版本，不得原地覆盖 |
| 风险可接受阈值 | 本包按工序给出 level-2/level-3 合成阈值 | 接受准则口径待甲方确认 |
| 监测预警阈值与通知策略 | 本包 8 条合成阈值，单位与边界写明 | 变径段控制值无甲方口径；STD-002 表9.2.2-2 仅适用标准断面 |
| 风险源清单与机理条目 | 本包 6 类机理为合成条目 | 甲方风险源清单与审核状态待导入 |
| 脱敏工程样例与监测样例 | 本包为虚构工程 | 真实准确率无法评估 |
| 专家复核结论 | 候选标签未经复核 | 标签资格保持 candidate，不得进入正式质量索引 |

## 二、开发缺口（本包已定位，未修）

1. **变径段监测控制值待确认**：GB 50911-2013 表9.2.2-2 主要适用于标准断面；本次材料没有
   足以直接采用的变径段控制值。专项设计与甲方审核未到位前，保持模拟配置，不自行换算规范值。
2. **正式导入前置缺口**：当前 HTTP catalog 没有工件上传、工程空间修订及文档转换入口。
   标准化风险记录、评估、预警和处置已有服务与读取入口，但本包从干净输入跑通全链路尚无正式证据。
3. **质量重放证据缺口**：C36 使用的 sample-snapshot 与 replay-context 生产侧产出尚未核实。
   不能据此断言评估引擎没有版本重放能力；本次历史重放用例保持未执行。
4. **发布与版本解析待核验**：已有知识审核、发布和校准治理入口，需要真实人工决定及版本引用。
   本次未取得目标环境和正式回执，发布、版本解析及校准回滚均保持未执行。
5. **扫描件解析差异**：合成地勘扫描件用于验证 OCR 通路；真实扫描件普遍存在条款号噪声
   （STD-001 已记录同类现象），解析结果需要人工复核通道，不能直接进入评分。
6. **Agent 失败闭环**：预算耗尽或必经 Agent 失败时的等待点与人工复核路由尚未在真实运行中验证，
   SYN-BIZ-AGENT-TASK-FAILURE-HUMAN-REVIEW 保持未执行。

## 三、材料包自身不做的事

- 不写业务数据库、不导入播种结果、不生成正式评估记录。
- 不把候选标签写入正式质量索引，也不产出甲方验收结论。
- 不因现有生产宿主未准备而修改生产代码或公共契约；需开发的部分另开 OpenSpec change。

具体代码定位、前置回执与关闭证据见 [开发缺口记录](reports/development-gaps.md)。
