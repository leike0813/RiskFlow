## ADDED Requirements

### Requirement: 评估功能终态使用所属正式运行详情

功能观察器 MUST 支持既有risk-assessment.read的run-read DTO，仅在原runRef与同次启动回执精确一致时读取顶层status，stateVersion作为独立状态版本。完成证明 MUST 包含resultRefs中的assessment-run-result或risk-flow-run-result；辅助阶段、审核和审计引用不得替代正式结果。错运行、错版本、未支持DTO、等待或缺正式结果不得PASS。

#### Scenario: 状态推进后观察同次评估

- **WHEN** 同次启动的评估完成，C34详情保留原runRef并返回独立stateVersion及正式run-result
- **THEN** 观察器以原精确runRef确认终态及正式结果，不用当前状态版本替换启动身份

#### Scenario: 辅助引用不能证明完成

- **WHEN** 详情不属于同次精确运行，或resultRefs只有阶段/复核/审计引用
- **THEN** 观察不通过，不借其它运行或辅助结果判PASS

### Requirement: 功能运行器保存合法异步等待回执

运行器 MUST 对正式Schema验证通过的异步waiting回执保存submitted及真实运行/任务引用，不以kind非succeeded误记提交失败；统一私有引用投影只取正式回执字段。非异步waiting、坏Schema、缺引用及失败 MUST 保持失败，submitted不能作为业务完成证据。

#### Scenario: 工作流返回等待Agent的202回执

- **WHEN** 正式异步入口返回合法waiting及精确运行/任务引用
- **THEN** 保存submitted及原引用供所属终态查询，不重发命令、伪造完成或推断缺失引用

### Requirement: 受控预置登记监测前置配置

provision MUST 支持以既有strict命令登记监测序列修订与可用性策略，复用当前人类会话及engineering-data.write权限、C03事务/幂等和审计。步骤 MUST 仅接受领域payload，宿主注入命令/主体/工程/授权；报告 MUST 返回精确序列或策略版本引用供后续步骤绑定。领域拒绝、错形或权限失败 MUST 停止，不直写表或猜测策略默认值。

#### Scenario: 从正式上下文初始化合成监测

- **WHEN** 有权操作者通过受控步骤提交绑定当前工程与空间修订的序列配置及显式策略版本
- **THEN** 通过既有监测registry正式登记并保存精确引用，后续批次与快照可引用该版本，恢复报告不重复已完成写入

#### Scenario: 监测前置步骤拒绝

- **WHEN** 配置覆盖宿主字段、strict命令无效或领域登记返回失败
- **THEN** 保留失败并停止，不执行后续批次或快照步骤

### Requirement: 当前功能验收与最终部署交付必须分开收口

后续功能阶段 MUST 以完整 Web、正式 API/Worker、真实持久化和获批准网络推理后端的功能行为验收，覆盖权限、人工确认、幂等、后台终态、审计与追溯；合成样本标明待甲方复核。当前范围全部完成且必要审计通过时 MUST 可形成 当前功能 PASS 并按项目流程集成、归档。正式签名、多平台安装、禁网三 VM、本地模型介质与 4090 实测 MUST 移交 C38 最终交付规划，不作为 后续功能阶段 收口条件，也不得在功能报告中记为已通过。

#### Scenario: 无目标硬件完成当前功能验收

- **WHEN** 当前真实业务功能及必要审计均有证据，而正式签名材料、多平台目标机、离线介质或 4090 尚未齐备
- **THEN** 功能阶段可按当前范围形成 PASS，报告明确最终交付项目由 C38 取证，未来输入缺项不阻塞当前集成和归档

#### Scenario: 网络 API 或真实业务证据缺失

- **WHEN** 当前必需的模型 API、授权资料、业务配置或正式后台终态证据缺失
- **THEN** 对应功能项保持 FAIL 或 BLOCKED，单元测试、配置校验成功、模型替身或仅已提交命令不能替代功能通过

#### Scenario: 正式清洗终态在当前有权页面显示

- **WHEN** 已完成的正式清洗任务与准备快照在当前工程存在，且操作者具有当前资料权限
- **THEN** Agent页面显示真实任务状态和预算，资料目录经统一入口权限检查及C04读取完成显示正式清洗状态
- **AND** 清洗摘要读取限当前页精确资料，工程切换/注销取消在途读取并丢弃迟到结果；撤权、缺失或损坏不投影可用状态


### Requirement: 模型与 OCR 必须离线预置并隔离资源

C38 最终本地模型/MinerU 交付 MUST 绑定 llama.cpp 构建、Qwen3.8-27B 权重、启动参数、上下文与维度，以及 MinerU 4.0.12 构建、管线、专用模型与资源分配；主 4090 与辅助 NVIDIA GPU 按服务隔离，embedding 默认保持独立 Ollama 主机，独立实例、预算及显存/内存/GPU 隔离效果须实际核验，启动不下载模型。当前功能验收 MUST 使用冻结身份的真实推理服务，可选批准网络 API；不要求本地推理 GPU、权重、llama.cpp 构建或禁网证明。文档按 adopt-mineru-document-ingestion 的 MinerU 契约提供真实服务，功能阶段显式使用官网精准 API，功能、质量与离线介质证据分开。任何阶段故障均不得自动换模型、扩预算或跳过必经 Agent。

#### Scenario: 联网推理完成业务链路

- **WHEN** 当前实例接入批准的网络 API，聊天、结构化生成和 Embedding 满足已声明能力、预算、模型身份与维度
- **THEN** 正式流程经原网关 port 运行，结果经确定性校验、持久化和审计；报告记录联网后端身份而不要求本地 GPU 或冒称离线运行

#### Scenario: 预置服务身份与真实协议匹配

- **WHEN** 操作者以完整离线模型制品和冻结资源配置启动服务
- **THEN** 三项 llama.cpp 能力、OCR 三媒体及 Embedding 维度使用真实服务通过各自契约核验，并保存精确身份和证据

#### Scenario: OCR 饱和或崩溃

- **WHEN** OCR 队列饱和、超时、取消或服务崩溃，同时执行 llama.cpp 请求
- **THEN** 故障只沿 OCR 的任务与预算收口；llama.cpp 的版本、预算、进程和请求控制保持独立，实际资源影响进入实测报告

#### Scenario: 模型制品或资源证明缺失

- **WHEN** 权重、构建、许可证、窗口/维度或物理资源配置无法与声明身份对应
- **THEN** 部署/验收失败，不能用配置标签、协议替身或另一服务证明原部署可用


### Requirement: 隔离恢复重建已登记双索引代际

恢复维护 MUST 从原正式发布事件和已登记active代际重建独立目标Qdrant的向量与BM25索引，复用正式成员规范化、原模型/策略/预算及原质量门。维护 MUST 在写投影前核对精确事件、代际、成员清单、兼容版本与当前权限；不得删除消费者回执、重新审核发布、伪造事件或改变激活序号。恢复数据库、工件根及Qdrant MUST 与保留源目标隔离，执行结果与失败必须留存运维审计。

#### Scenario: 消费者回执已完成而恢复投影为空

- **WHEN** 恢复数据库保留已完成事件回执与active代际，独立Qdrant尚无对应双索引
- **THEN** 正式维护重建该精确代际并通过成员对账及原七项质量门，消费者回执和激活序号保持
- **AND** 来源/模型/策略/代际漂移或任一质量门失败时不声明恢复完成，保留原实例与恢复根

### Requirement: 发布回退与目标环境验收必须有真实证据

系统 MUST 提供兼容性检查、发布切换和回退手册，区分软件回退与数据恢复；数据库/工件不兼容时不得仅换旧镜像继续服务。后续功能阶段 MUST 以当前真实服务核验功能、重启幂等、权限、恢复损坏检测与索引重建，记录实际版本及证据。C38 最终验收 MUST 冻结硬件、数据规模、并发及批准阈值，在 RTX 4090（24GB）/128GB 最低目标取得禁网安装、本地模型/OCR、资源隔离、容量、性能及恢复证据。缺未来实机输入阻塞 C38 对应交付项；缺当前功能证据阻塞后续功能阶段 对应功能项。

#### Scenario: 兼容版本回退

- **WHEN** 操作者选择已批准且与当前数据库兼容的旧发布并确认切换
- **THEN** 系统保留现有事实和精确配置证据，执行回退后的必要健康、权限及重放核验

#### Scenario: 不兼容回退或缺少真实证据

- **WHEN** 旧发布无法解析当前数据库/工件，或正在执行阶段所需的模型、浏览器或其他必需证据缺失
- **THEN** 回退或该阶段对应验收不成立，报告列出失败/阻塞，不以 Mock 或 skip 计作通过；C38 的目标硬件缺项不阻塞 当前功能验收

#### Scenario: 在批准目标硬件形成基准

- **WHEN** 冻结数据规模、并发、硬件和阈值后完成安装、读写、检索、模型、OCR、恢复与隔离实测
- **THEN** 报告给出延迟分位、吞吐、峰值资源、磁盘容量、逻辑副本停写时间和恢复阶段耗时，并逐项比较批准性能阈值；这些测量不构成生产级 RPO/RTO 或 SLA 承诺

#### Scenario: 目标环境未齐时完成工程检查

- **WHEN** 后续功能阶段 当前功能、工程检查和必要审计已通过，但最终三 VM、目标硬件或离线介质尚未齐备
- **THEN** 当前功能范围可收口、集成和归档，报告保留最终交付移交清单；C38 按最终代码、配置与制品身份完成取证后才声明实机交付通过

### Requirement: 功能验收必须证明正式来源与完整宿主

功能验收 MUST 使用前置 change 的真实 API/Worker、五类共享任务、正式 C19 发布成员、C24 路线、C30 空间及受权工件。当前实例为隔离 synthetic-acceptance 合置宿主，客户端访问同源 HTTPS。来源缺项、错版本、异空间、拒权、模型或 OCR 必需能力不足 MUST 失败或 BLOCKED，不以测试 catalog、静态结果、另一 reader 或空轮询证明就绪。

#### Scenario: 三类正式来源贯通原业务链

- **WHEN** 真实配置成员、路线、空间和工件已通过正式入口登记并经当前权限读取
- **THEN** 同实例识别和评估按精确版本推进，报告记录各来源与结果引用，质量查询保持两阶段资料授权

#### Scenario: 错来源或关键服务缺失

- **WHEN** 来源错版、跨工程/空间、权限撤销、必需模型/OCR 不足或依赖不可用
- **THEN** 实例或相应场景失败/BLOCKED，不能用输入已提交、存活探针或模型 smoke 判为业务通过

### Requirement: 功能报告必须对应同次正式终态与可见交互

报告 MUST 由同次运行的正式只读终态、业务/审计/C04 引用与实际命令组成，覆盖资料和知识、真实检索与候选、复核、风险记录、评估/预警、处置人工决定、执行反馈及权限/重试。人工决定须经正式确认；submitted、awaiting-human、超时、缺引用或关键 skip 不能 PASS。可见外部 Chrome MUST 访问该 HTTPS 宿主完成登录、业务交互和追溯，headless harness 不替代可见验收。报告不得包含秘密、Cookie、资料正文或模型内部思考；合成样本标明待甲方复核。

#### Scenario: 同次业务与可见浏览器具有完整证据

- **WHEN** 同次运行各正式终态与必需引用成立，用户在可见窗口完成正式确认与跨页追溯
- **THEN** 报告绑定代码、包、配置、服务身份及结果链，双向追踪 RI-S1–RI-S6、RA-S1–RA-S7，不声称真实工程准确率

#### Scenario: 人审等待或观察证据不完整

- **WHEN** 人审尚未完成、观察预算耗尽、引用不匹配或任一链路缺正式证明
- **THEN** 报告非零且记录等待/失败/BLOCKED，以原身份续接，不自动采纳、扩预算或补造终态

#### Scenario: 重启与回执故障重投

- **WHEN** 业务提交后响应或事件回执失败并按原身份重试或重启
- **THEN** 正式回执、结果与当前授权被复验，已提交效果不重复，取消态不推进，报告保留同一运行和精确版本

#### Scenario: 只读观察已有正式业务引用

- **WHEN** 使用显式已有正式引用模式，对同实例已完成的精确运行或任务执行当前授权的正式查询
- **THEN** 观察器不发送业务命令或重启模型任务，不制造启动回执，报告声明只读来源并逐项校验精确目标、成功终态与正式主产出；完整业务链另以正式查询索引核对，旧失败父运行和桌面在途场景不被计作通过
