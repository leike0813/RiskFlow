# 项目阶段成果与试用情况

截至2026年10月16日，系统已经完成从工程资料导入、原件查看、内容整理到知识检索的主要流程，并对变径盾构的五个施工工序完成了风险候选生成、检查和汇总。最新一轮共整理出15组风险候选，接下来将安排人工复核，再接入风险评分、预警和处置流程。

本轮使用了构造的工程样例、监测样例和三份实际标准原文。以下结果反映这批资料的试用表现，后续将结合甲方提供的工程资料继续验证。

## 目前已经做出了什么

| 业务工作 | 已展示的效果 |
| --- | --- |
| 导入和查看工程资料 | 可以登记PDF、扫描件、图片、Word及表格资料；用户可以查看原件或下载到本机 |
| 从资料中提取内容 | 五类样例的57项关键字段、25项表格关联和位置检查均符合预先设定的要求 |
| 整理工程知识 | 已完成工序、风险机理、规范、案例和评分配置的审核发布，内容可以关联到来源资料 |
| 查找风险依据 | 在10个测试问题中，前5条检索结果对已标注相关资料的平均覆盖率为96.7% |
| 按工序识别风险 | 扩径准备、变径空间扩挖、刀盘扩径、盾体扩径、缩径转换均已完成风险候选检查 |
| 使用桌面客户端 | 已在现场显示器上演示登录、查看中文PDF、保存原件和查看智能助手任务 |

当前重点是完成新增监测资料的自动整理，随后将监测数据、人工确认的风险和评分规则接起来，演示一次完整的“发现风险、评估等级、触发预警、提出措施、反馈效果”流程。智能助手面板在任务增多后出现的加载问题，也已查明原因，安排一并修复。
