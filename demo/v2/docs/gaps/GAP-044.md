# GAP-044 备份策略、恢复点与恢复操作无契约 schema 与命令

- 类别：G6 规格空白
- 相关页面：P-OP-04

## 缺口

备份策略、恢复点与恢复操作无契约 schema 与命令

## 依据

packages/contracts/src（无 backup/restore 相关 schema 与事件）；demo/v2/src/pages/ops/BackupPage.tsx（RestoreConfirm 两步确认）

## 预设

fixture 自定义备份策略（versionedRef 呈现）与恢复点（建立时间/覆盖范围/校验状态）；恢复操作先经 GAP-041 三态门控，再经页内确认交互（确认范围与后果勾选 + 确认/取消）才进入提交语义；恢复操作进入版本与操作审计（深链 P-RV-06）。

## 待确认

恢复点校验状态枚举、恢复命令的幂等与审计字段是否入契约；恢复确认交互是否固化为外壳级危险操作原语。

## 风险

恢复操作无契约命令与幂等约束时，重复提交与审计断链风险由实现侧自行承担。
