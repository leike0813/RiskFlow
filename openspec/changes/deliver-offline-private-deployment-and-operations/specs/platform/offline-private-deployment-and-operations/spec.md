## Purpose

为 RiskFlow 已归档能力提供可在甲方内网安装与运行的私有部署和运维边界，把软件、模型、配置、数据库、内容工件及恢复证据绑定到精确版本，使三 VM 离线交付、停止、同机逻辑副本、恢复和后续验收均能独立复核，明确单物理故障域的责任边界。

## ADDED Requirements

### Requirement: 生产检查点按当前运行验证真实引用

系统 MUST 为三图检查点写入、待写入、读取与历史枚举提供本次工程、主体、精确运行、线程及授权调用上下文，并核对图状态归属。生产引用校验 MUST 在当前授权复验后，经引用所属模块的公开有界窄口确认精确版本与已提交事实；缺上下文、引用缺失/已回滚、跨工程/运行或技术错误 MUST 失败闭合。检查点连接 MUST 保持独立最小权限，不能直接取得业务表权限。校验不得创建业务事实、第二引用表或使用永真存在性替代。

#### Scenario: 当前上下文与检查点引用一致

- **WHEN** 本次已受权运行读取或写入同线程检查点，其引用由所属模块证明精确版本与已提交归属
- **THEN** 检查点正常保存或恢复，当前授权独立于历史状态且不新增业务事实

#### Scenario: 引用或运行归属无法证明

- **WHEN** 当前上下文缺失/错配，或引用缺失、已回滚、跨工程/运行、版本漂移或所属读取失败
- **THEN** 返回 CHECKPOINT_INCONSISTENT，不保存不一致状态，不从检查点补造业务事实

### Requirement: 评估启动状态不得引用未登记快照

AssessmentGraphStateV1 MUST 仅在 A0 允许缺省 entrySnapshotRef；A0 完成后的阶段 MUST 携带真实精确入口快照。启动不得创建引用形状的未登记 seed。A0 MUST 经原模块冻结或读取入口，并在业务事实提交后更新状态；A0 失败或取消允许保持无快照状态，恢复不得从检查点补造入口。

#### Scenario: 首次评估经过真实 A0

- **WHEN** 首次评估调用开始且 A0 尚未完成
- **THEN** 起始检查点不携带未登记快照，A0 成功后以真实登记引用进入 A1

#### Scenario: 后续阶段缺少入口快照

- **WHEN** A1 或后续阶段状态未包含入口快照
- **THEN** 唯一状态 Schema 拒绝该状态，不以 seed 或默认引用补齐

### Requirement: 当前功能验收与最终部署交付必须分开收口

C37 MUST 以完整 Web、正式 API/Worker、真实持久化和获批准网络推理后端的功能行为验收，覆盖权限、人工确认、幂等、后台终态、审计与追溯；合成样本标明待甲方复核。当前范围全部完成且必要审计通过时 MUST 可形成 C37 功能 PASS 并按项目流程集成、归档。正式签名、多平台安装、禁网三 VM、本地模型介质与 4090 实测 MUST 移交 C38 最终交付规划，不作为 C37 收口条件，也不得在功能报告中记为已通过。

#### Scenario: 无目标硬件完成当前功能验收

- **WHEN** 当前真实业务功能及必要审计均有证据，而正式签名材料、多平台目标机、离线介质或 4090 尚未齐备
- **THEN** C37 可按当前范围形成 PASS，报告明确最终交付项目由 C38 取证，未来输入缺项不阻塞当前集成和归档

#### Scenario: 网络 API 或真实业务证据缺失

- **WHEN** 当前必需的模型 API、授权资料、业务配置或正式后台终态证据缺失
- **THEN** 对应功能项保持 FAIL 或 BLOCKED，单元测试、配置校验成功、模型替身或仅已提交命令不能替代功能通过

### Requirement: 跨虚拟机工件访问必须保持 C04 原契约

系统 MUST 在数据 VM 本地运行 C04 内容存储，通过仅限内网、双向 TLS 且有界的 put/open 流接口供应用 VM 使用。请求 MUST 使用原 C04 DTO 并复验当前工程、资料、空间和能力授权；传输身份不能替代业务授权。应用 VM 的 referenceGuard MUST 与原业务 PostgreSQL 事务共享上下文；维护接口 MUST 在数据 VM 本地运行。中断、截断、超额或读取 receipt 未完成 MUST 失败，不能将未核验字节登记为正式结果。

#### Scenario: 真实跨 VM 写入与读取

- **WHEN** 应用 VM 按原身份提交获授权工件并完整读取
- **THEN** 数据 VM 完成原耐久登记、审计与字节校验，应用事务按同一登记校验引用，不暴露宿主路径或全量缓冲正文

#### Scenario: 断流或传输身份越权

- **WHEN** put/open 截断、超限、超时，或服务身份合法但工程授权失效
- **THEN** 返回稳定失败且 verified 不成功；同身份重试遵守原幂等语义，不绕过权限或替换工件身份

### Requirement: 生产策略与窄读必须解析精确真实来源

系统 MUST 为全部必需组合根提供真实策略、授权和窄读来源；运行策略按不可变、已批准 catalog 的精确引用解析，业务定义按原正式依据集合与所属模块读取。C20 构建质量 MUST 经真实固定数据集和原验收门禁计算，不使用永真门禁；C24 路线和 C30 空间配对 MUST 从正式登记与工件证明。构造引用环只可在监听及后台消费前一次绑定真实委派，缺项或漂移 MUST 阻止就绪。HTTP 受理 MUST 用真实会话分别签发所需下游分支并耐久关联原上下文；后台跨能力调用 MUST 读取该目标分支已签发上下文再收窄和复验，不扩展原 parent 的能力或持久化会话令牌。

#### Scenario: 完整来源装配并保留质量查询授权

- **WHEN** 正式 catalog、数据集、依据集合和全部 provider 已就绪，API 同时接入普通 projection 与质量窄读
- **THEN** 所有声明能力使用原真实来源，质量查询仍执行两阶段资料授权，其它投影沿原端口执行

#### Scenario: 策略漂移或质量门禁失败

- **WHEN** 精确引用缺失、来源不匹配、环未绑定或检索验收失败
- **THEN** 服务或投影不进入就绪，不能从测试常量、其它版本、其它空间或默认策略补足

#### Scenario: 独立知识发布后的受限命令因果授权

- **WHEN** 独立人工知识发布产生正式 identification-basis-published 事件，检索构建需要读取该发布依据
- **THEN** 后台 system 授权绑定原 producerCommandId、精确原授权根及已批准目标 parent 关联，C06 只允许 identification-basis 分支并复验当前权限和有效期，不创建工作流引用；错命令、根、父、分支或失效授权均拒绝

#### Scenario: 评分配置包使用同一正式治理实例

- **WHEN** 本轮隔离验收导入已审核或标明待甲方复核的合成评分配置包
- **THEN** C17 向同一 C16 注入 C18/C19 治理策略，按正式提交、复核、发布及 C19 依据解析完成验收；共享 knowledge-authoring 只登记 C17 定义，范围外的 C19 Agent 编制明确拒绝且不计通过

#### Scenario: 预测、校准、现场和报告按精确部署绑定解析

- **WHEN** 宿主装配每工程的指定预测发布、校准目标、现场工件版本与批准报告策略
- **THEN** 仅使用原正式依据成员、受权 C04 正文和精确 catalog 策略，冻结依据集合与指定发布不符时不可用；缺项、重复现场键或策略漂移阻止就绪，不伪造发布或选择最近版本

#### Scenario: 预测执行器使用运行时已核验策略

- **WHEN** C28 通过原授权读取冻结依据的预测正文并选出唯一指标策略
- **THEN** 生产 resolver 以该完整策略装配既有确定性执行器，返回的 method 和 requiredRef 不符时沿原 executor-unavailable 收口；启动不读取业务正文或维护第二份策略
- **AND** 既有数组调用方保留精确匹配及重复键拒绝行为

### Requirement: 合成验收资料预置必须使用正式权限与模块入口

系统 MUST 提供受控资料预置入口，复用正式部署加载、C06 会话和公开工件、资料登记及转换端口。预置步骤 MUST 固定命令身份并仅引用前序成功结果，严格验证原 DTO，输出安全引用。合成验收配置及策略 MUST 明确 synthetic-acceptance purpose，隔离于正式工程；预期结果和报告不得进入模型输入。缺少 OCR 时扫描资料 MUST 标记 BLOCKED，已支持的文本和结构化资料可继续准备。

#### Scenario: 文本资料按正式身份预置并重试

- **WHEN** 授权用户在已显式初始化且发布与迁移匹配的隔离合成实例预置文本资料，再以原身份重试
- **THEN** 工件、资料登记与转换均经正式权限和审计完成，重试复用原回执，不直接 SQL 插入业务事实或重置已有密码

#### Scenario: 预置缺少授权、版本或 OCR

- **WHEN** 配置或发布版本不匹配、当前用户无资料权限，或扫描资料所需 OCR 未提供
- **THEN** 对应步骤拒绝或 BLOCKED，不构造假授权、转换结果或功能 PASS，安全报告不包含秘密及正文

#### Scenario: 合成现场配置绑定正式工件

- **WHEN** 隔离验收实例预置五工序的资源齐备、资源不足及禁忌约束现场材料
- **THEN** 材料保留合成标记，不含建议结果；运行时按命令的精确现场版本读取已登记、获授权的 C04 正文并完整核验，错工程、空间、版本或未来时间不得参与处置验收

#### Scenario: 合成检索样例用于真实测量

- **WHEN** 检索样例的本地发布键已绑定本代正式知识回执与精确 manifest 成员
- **THEN** 仅查询文本进入 Embedding，相关性等级留在确定性计算中；门禁使用真实 dense、BM25、融合查询的 Recall、NDCG 和延迟，缺成员、拒权或超时均不得通过，报告限定为合成样例功能验收

### Requirement: 部署运维状态与审计必须耐久且独立授权

系统 MUST 将部署作用域操作状态及其追加审计存于 PostgreSQL，阶段与审计同事务转换，精确输入、幂等键、修订与租约共同约束重试。宿主权限与 C06 全工程资料授权 MUST 分别核验；系统管理员不得因此获得正文权限。运行 API/Worker 不得持运维表写权或宿主控制凭据。宿主阶段记录只能用于诊断和恢复接续，数据库审计失败 MUST 阻止完成结论。

#### Scenario: 阶段重放与权限隔离

- **WHEN** 同操作身份重试或另一个主体试图同时维护实例
- **THEN** 原结果按修订复用或互斥拒绝，异载荷冲突；业务主体不能改写运维状态或审计

#### Scenario: 审计失败与授权缺项

- **WHEN** 阶段审计失败、工程枚举遗漏或资料授权不完整
- **THEN** 动作报告失败或待补审计，不能激活/完成，也不伪造工程引用或跳过无权工程

### Requirement: 部署必须遵循三台虚拟机的集中式边界

最终私有部署 MUST 在一台物理服务器内按推理、应用、数据三台 VM 部署：推理 VM 使用 GPU 直通承载 llama.cpp 与模型，应用 VM 承载 Web、API、Worker、HTTPS 入口与必要解析，数据 VM 承载 PostgreSQL、Qdrant 和不可变工件；三 VM 实际隔离证据归 C38。C37 功能环境 MUST 保持上述职责与授权边界，可合置服务并使用批准的网络推理 API，不要求三台实际 VM。普通客户端 MUST 只访问应用 HTTPS，内部服务与管理端口按职责隔离。Electron 不替代服务器能力。同机副本只用于逻辑回退，不承诺独立备份、HA、持续备份、周期演练、生产级 RPO/RTO 或代运维。

#### Scenario: 客户端只访问应用入口

- **WHEN** 桌面或浏览器客户端在批准内网连接完整部署
- **THEN** Web、API 与 SSE 经同一 HTTPS 入口工作，客户端不能直接访问数据库、索引、推理与管理端口

#### Scenario: 同机副本与宿主故障边界

- **WHEN** 部署报告说明 VM 隔离、快照与同机恢复能力
- **THEN** 报告区分逻辑恢复与物理故障，不把同机副本、三 VM 或一次恢复测试声明为独立备份、灾备或可用性承诺

### Requirement: 离线发布包必须完整且版本可核验

C38 最终离线交付 MUST 提供不可变发布清单，固定代码、生产构建、工具链、桌面安装包、容器和系统依赖、模型/OCR、配置、许可证、SBOM 与手册身份。最终离线安装 MUST 仅消费已批准制品，安装和运行不得隐式下载；缺失、身份/架构不符或许可缺项须在启动前失败。C37 功能环境 MUST 固定实际代码、服务、模型 API、配置和样本身份，可显式联网调用批准推理 API，无需离线介质或正式桌面包。测试替身、固定测试秘密、合成结果和开发服务器不得进入生产运行包。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 断网环境完成安装

- **WHEN** 操作者使用完整发布介质在符合冻结宿主条件且不能访问公网的环境安装
- **THEN** 系统核验制品并从本地启动批准服务，留下发布身份与实际安装证据，不发生隐式下载

#### Scenario: 制品不完整或不匹配

- **WHEN** 必需镜像、模型、包、许可证缺失，或实际内容、版本、架构与清单不符
- **THEN** 安装返回稳定失败类别和安全定位，不启动部分业务实例、不换用其它版本

#### Scenario: 已验收界面尚未进入生产构建

- **WHEN** 发布范围声明包含某业务页面，但生产构建没有其真实路由及服务接缝
- **THEN** 对应发布验收失败，不能用参考原型、独立验收 harness 或静态截图证明页面已部署

### Requirement: 部署配置与秘密必须分离并保持原契约

系统 MUST 从受控部署输入冻结公开来源版本、模型能力和尺寸、OCR 管线与模型集合、检索兼容版本、工件限额、Agent/运行策略、网络及资源预算；每个业务模块只接受其既有严格契约，不得通过环境默认值补造规则或修改版本。密码、会话签名材料、数据库连接秘密与 TLS 私钥 MUST 由受限秘密文件提供，不进入发布清单、业务 DTO、日志、指标、命令参数或普通备份描述。配置缺项、精确引用漂移、过宽权限和资源配置矛盾 MUST 在副作用前失败。

#### Scenario: 同一配置可重放

- **WHEN** 同一发布和配置版本在兼容宿主重新装配
- **THEN** 各模块收到相同精确版本和有效预算，业务输入不能改写模型端点、权重路径或策略

#### Scenario: 配置非法或秘密不可用

- **WHEN** 配置缺少必需引用、尺寸或预算不一致，或秘密文件缺失、可被无关主体读取
- **THEN** 部署失败且不建立业务监听或后台执行，不输出秘密及宿主路径

#### Scenario: 秘密轮换保持历史可追溯

- **WHEN** 操作者按批准过程替换签名或数据库秘密并重启实例
- **THEN** 旧会话和连接按所属模块安全语义失效，历史主体、业务版本、审计及工件引用保持，不把旧秘密写进新发布包

#### Scenario: 检索质量输入按精确配置加载

- **WHEN** API 或 Worker 使用批准的 retrievalQuality 配置装配质量门禁
- **THEN** 系统只从 dataRoot 内无符号链接的普通文件加载有界检索数据集，核对工程、数据集精确版本与验收策略；正式实例拒绝合成数据集
- **AND** 实际容器身份及总截止来自该配置，报告耐久保存到 logRoot/retrieval-quality，缺文件、身份漂移或保存失败均不能通过门禁

### Requirement: 初始化必须幂等且运行主体使用最小权限

系统 MUST 将宿主初始化、数据库权限组、部署 LOGIN 主体、领域迁移、检查点准备和首次管理员引导作为显式部署动作。运行进程 MUST 使用按职责授予的非超级用户主体，不得持有迁移或宿主控制权限；首次管理员只可在账号库为空时按 C06 规则创建。重复初始化 MUST 保留已有事实和账号，迁移失败 MUST 阻止业务启动，不能重置数据库、凭据或历史审计。

#### Scenario: 空实例初始化成功

- **WHEN** 操作者在空数据库提交批准发布和秘密输入
- **THEN** 初始化建立所需权限与迁移、检查点和首次管理员，业务进程随后以最小权限启动

#### Scenario: 初始化重放或部分失败

- **WHEN** 同一初始化被重放，或某迁移/管理员引导步骤失败
- **THEN** 已成立事实保持，未完成项可按原身份重试；失败实例不进入就绪态，也不覆盖已有管理员

#### Scenario: 运行主体试图越权

- **WHEN** API 或 Worker 的数据库主体尝试 DDL、改写审计或获取部署控制权限
- **THEN** 请求被拒绝，运行主体不能借初始化连接或角色成员关系扩大权限

### Requirement: 服务生命周期必须使用真实公共接缝
