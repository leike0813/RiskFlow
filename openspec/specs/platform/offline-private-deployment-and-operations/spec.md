# platform/offline-private-deployment-and-operations Specification

## Purpose

为 RiskFlow 提供版本化部署配置、受限初始化、服务组合、工件流、发布校验与逻辑恢复程序，将软件、模型、配置、数据库及内容工件绑定到精确版本，明确当前合置宿主与最终三 VM 交付边界。完整功能和最终实机取证由后续 change 分阶段承担。


## Requirements
### Requirement: 评估启动状态不得引用未登记快照

AssessmentGraphStateV1 MUST 仅在 A0 允许缺省 entrySnapshotRef；A0 完成后的阶段 MUST 携带真实精确入口快照。启动不得创建引用形状的未登记 seed。A0 MUST 经原模块冻结或读取入口，并在业务事实提交后更新状态；A0 失败或取消允许保持无快照状态，恢复不得从检查点补造入口。

#### Scenario: 首次评估经过真实 A0

- **WHEN** 首次评估调用开始且 A0 尚未完成
- **THEN** 起始检查点不携带未登记快照，A0 成功后以真实登记引用进入 A1

#### Scenario: 后续阶段缺少入口快照

- **WHEN** A1 或后续阶段状态未包含入口快照
- **THEN** 唯一状态 Schema 拒绝该状态，不以 seed 或默认引用补齐

### Requirement: 跨虚拟机工件访问必须保持 C04 原契约

跨虚拟机存储 MUST 继续沿既有受控内网流接口、配置化传输身份和服务端业务权限入口访问。普通读取沿登记对象流式传输，不额外要求全文哈希收据；写入登记、正常传输失败、取消、资源限制和父来源权限继承保留。正式跨 VM 实机取证仍由后续交付阶段承担。

#### Scenario: 真实跨 VM 写入与读取

- **WHEN** 应用经现有受控内网流接口访问登记工件
- **THEN** 写入保留原耐久与内容身份，读取应用入口权限决定并直接消费字节，不要求重复哈希收据

#### Scenario: 断流或传输身份越权

- **WHEN** 受控传输中断、超限或服务身份无法通过既有认证
- **THEN** 返回传输或授权错误，不把未完成消费记为成功

#### Scenario: 普通远程读取复用当前语义

- **WHEN** 获准业务动作经既有远程存储读取登记文件
- **THEN** 取得同一对象字节和消费终态，不增加第二套授权或验真

#### Scenario: 传输未完成

- **WHEN** 文件读取中断或取消
- **THEN** 读取失败且不提交基于未完成输入的成功结果

### Requirement: 合成验收资料预置必须使用正式权限与模块入口

系统 MUST 提供受控资料预置入口，复用正式部署加载、C06 会话和公开工件、资料登记及转换端口。预置步骤 MUST 固定命令身份并仅引用前序成功结果，严格验证原 DTO，输出安全引用。合成验收配置及策略 MUST 明确 synthetic-acceptance purpose，隔离于正式工程；预期结果和报告不得进入模型输入。缺少 OCR 时扫描资料 MUST 标记 BLOCKED，已支持的文本和结构化资料可继续准备。

#### Scenario: 文本资料按正式身份预置并重试

- **WHEN** 授权用户在已显式初始化且发布与迁移匹配的隔离合成实例预置文本资料，再以原身份重试
- **THEN** 工件、资料登记与转换均经正式权限和审计完成，重试复用原回执，不直接 SQL 插入业务事实或重置已有密码

#### Scenario: 预置缺少授权、版本或 OCR

- **WHEN** 配置或发布版本不匹配、当前用户无资料权限，或扫描资料所需 OCR 未提供
- **THEN** 对应步骤拒绝或 BLOCKED，不构造假授权、转换结果或功能 PASS，安全报告不包含秘密及正文

#### Scenario: 合成现场配置绑定正式工件

- **WHEN** 隔离验收实例预置五工序的资源齐备、资源不足及禁忌约束现场材料
- **THEN** 材料保留合成标记，不含建议结果；运行时按命令的精确现场版本读取已登记、获授权的 C04 正文并完整核验，错工程、空间、版本或未来时间不得参与处置验收

#### Scenario: 合成检索样例用于真实测量

- **WHEN** 检索样例的本地发布键已绑定本代正式知识回执与精确 manifest 成员
- **THEN** 仅查询文本进入 Embedding，相关性等级留在确定性计算中；门禁使用真实 dense、BM25、融合查询的 Recall、NDCG 和延迟，缺成员、拒权或超时均不得通过，报告限定为合成样例功能验收

### Requirement: 部署运维状态与审计必须耐久且独立授权

系统 MUST 将部署作用域操作状态及其追加审计存于 PostgreSQL，阶段与审计同事务转换，精确输入、幂等键、修订与租约共同约束重试。宿主权限与 C06 全工程资料授权 MUST 分别核验；系统管理员不得因此获得正文权限。运行 API/Worker 不得持运维表写权或宿主控制凭据。宿主阶段记录只能用于诊断和恢复接续，数据库审计失败 MUST 阻止完成结论。

#### Scenario: 阶段重放与权限隔离

- **WHEN** 同操作身份重试或另一个主体试图同时维护实例
- **THEN** 原结果按修订复用或互斥拒绝，异载荷冲突；业务主体不能改写运维状态或审计

#### Scenario: 审计失败与授权缺项

- **WHEN** 阶段审计失败、工程枚举遗漏或资料授权不完整
- **THEN** 动作报告失败或待补审计，不能激活/完成，也不伪造工程引用或跳过无权工程

### Requirement: 部署必须遵循三台虚拟机的集中式边界

部署配置及发布服务模板 MUST 按推理、应用、数据三逻辑角色隔离职责：推理承载模型，应用承载 Web/API/Worker/HTTPS 与解析，数据承载 PostgreSQL/Qdrant/不可变工件。当前可启动合置宿主仅接受 synthetic-acceptance 与本地 C04；正式跨 VM 宿主缺完整装配时 MUST 拒绝启动，配置模板或远程流 adapter 不证明其可运行。客户端只访问应用 HTTPS。同机副本只作逻辑回退，不承诺独立备份、HA、RPO/RTO 或代运维；三 VM 实际部署义务移交 C38 F-03。

#### Scenario: 客户端只访问应用入口

- **WHEN** 桌面或浏览器客户端在批准内网连接完整部署
- **THEN** Web、API 与 SSE 经同一 HTTPS 入口工作，客户端不能直接访问数据库、索引、推理与管理端口

#### Scenario: 同机副本与宿主故障边界

- **WHEN** 部署报告说明 VM 隔离、快照与同机恢复能力
- **THEN** 报告区分逻辑恢复与物理故障，不把同机副本、三 VM 或一次恢复测试声明为独立备份、灾备或可用性承诺

### Requirement: 离线发布包必须完整且版本可核验

发布工具 MUST 校验不可变清单中的代码、生产构建、工具链、桌面包、容器/系统依赖、模型/OCR、配置、许可证、SBOM 与手册身份，并仅从批准的本地介质制备或导入。缺失、身份/架构不符或许可缺项须在副作用前失败，不能隐式下载或换版本。配置示例、测试替身、固定测试秘密、合成结果和开发服务器不得进入正式运行包。真实正式制品、禁网安装及服务运行取证由 C38 F-01/F-03 承接；工具测试不声明实机安装通过。（RI-S1～RI-S6；RA-S1～RA-S7）

#### Scenario: 受控导入核验完整介质

- **WHEN** 发布工具获得完整清单和匹配的本地介质
- **THEN** 工具核验身份并执行有界离线导入，不隐式下载；该回执仅证明程序动作，不替代目标机安装和服务运行取证

#### Scenario: 制品不完整或不匹配

- **WHEN** 必需镜像、模型、包、许可证缺失，或实际内容、版本、架构与清单不符
- **THEN** 安装返回稳定失败类别和安全定位，不启动部分业务实例、不换用其它版本

#### Scenario: 已验收界面尚未进入生产构建

- **WHEN** 发布范围声明包含某业务页面，但生产构建没有其真实路由及服务接缝
- **THEN** 对应发布验收失败，不能用参考原型、独立验收 harness 或静态截图证明页面已部署

### Requirement: 部署配置与秘密必须分离并保持原契约

系统 MUST 从受控部署输入冻结公开来源版本、模型能力和尺寸、OCR 管线与模型集合、检索兼容版本、工件限额、Agent/运行策略、网络及资源预算；每个业务模块只接受其既有严格契约，不得通过环境默认值补造规则或修改版本。密码、会话签名材料、数据库连接秘密与 TLS 私钥 MUST 由受限秘密文件提供，不进入发布清单、业务 DTO、日志、指标、命令参数或普通备份描述。配置缺项、精确引用漂移、过宽权限和资源配置矛盾 MUST 在副作用前失败。

#### Scenario: 同一配置可重放

- **WHEN** 同一发布和配置版本在兼容宿主重新装配
- **THEN** 各模块收到相同精确版本和有效预算，业务输入不能改写模型端点、权重路径或策略

#### Scenario: 配置非法或秘密不可用

- **WHEN** 配置缺少必需引用、尺寸或预算不一致，或秘密文件缺失、可被无关主体读取
- **THEN** 部署失败且不建立业务监听或后台执行，不输出秘密及宿主路径

#### Scenario: 秘密轮换保持历史可追溯

- **WHEN** 操作者按批准过程替换签名或数据库秘密并重启实例
- **THEN** 旧会话和连接按所属模块安全语义失效，历史主体、业务版本、审计及工件引用保持，不把旧秘密写进新发布包

#### Scenario: 检索质量输入按精确配置加载

- **WHEN** API 或 Worker 使用批准的 retrievalQuality 配置装配质量门禁
- **THEN** 系统只从 dataRoot 内无符号链接的普通文件加载有界检索数据集，核对工程、数据集精确版本与验收策略；正式实例拒绝合成数据集
- **AND** 实际容器身份及总截止来自该配置，报告耐久保存到 logRoot/retrieval-quality，缺文件、身份漂移或保存失败均不能通过门禁

### Requirement: 初始化必须幂等且运行主体使用最小权限

系统 MUST 将宿主初始化、数据库权限组、部署 LOGIN 主体、领域迁移、检查点准备和首次管理员引导作为显式部署动作。运行进程 MUST 使用按职责授予的非超级用户主体，不得持有迁移或宿主控制权限；首次管理员只可在账号库为空时按 C06 规则创建。重复初始化 MUST 保留已有事实和账号，迁移失败 MUST 阻止业务启动，不能重置数据库、凭据或历史审计。

#### Scenario: 空实例初始化成功

- **WHEN** 操作者在空数据库提交批准发布和秘密输入
- **THEN** 初始化建立所需权限与迁移、检查点和首次管理员，业务进程随后以最小权限启动

#### Scenario: 初始化重放或部分失败

- **WHEN** 同一初始化被重放，或某迁移/管理员引导步骤失败
- **THEN** 已成立事实保持，未完成项可按原身份重试；失败实例不进入就绪态，也不覆盖已有管理员

#### Scenario: 运行主体试图越权

- **WHEN** API 或 Worker 的数据库主体尝试 DDL、改写审计或获取部署控制权限
- **THEN** 请求被拒绝，运行主体不能借初始化连接或角色成员关系扩大权限

### Requirement: 服务生命周期必须使用真实公共接缝

系统 MUST 提供显式 API 与 Worker 进程入口，装配所声明业务能力所需的真实数据库、工件、授权、模型、OCR、检索、投影和工作流接口；必需依赖缺失时不得将实例声明为完整可用。领域事件和 Agent 任务 MUST 使用既有耐久 Outbox、幂等消费者、租约和硬预算执行，不能以进程内队列或新流程状态机替代。关闭和维护 MUST 停止接收新工作，有界收口在途任务、订阅和连接；技术重启只能复用原版本、原预算和原幂等身份，不重复已提交业务效果，也不自动采纳人工决定。

#### Scenario: 真实实例完成请求和后台消费

- **WHEN** 冻结实例收到合法业务请求并产生既有领域事件或 Agent 任务
- **THEN** 请求通过原公共端口执行，后台消费者使用耐久身份推进，正式结果、审计、事件与检查点可解析

#### Scenario: 缺少必需接线

- **WHEN** 发布声明的能力缺少真实端口、策略、事件消费者或模型部署
- **THEN** 启动/就绪检查明确失败，不能以空实现、测试替身、默认策略或部分端口冒充完整实例

#### Scenario: 进程重启与事件重投

- **WHEN** 进程在事实提交后、响应或事件确认前终止并按同一发布重启
- **THEN** 同身份重试复用已成立回执或结果，租约按原契约恢复，不重复审计、风险、评估、预警或人工决定

#### Scenario: 有界停止未能完成

- **WHEN** 关闭期限到达且仍有在途写入或未知执行状态
- **THEN** 运维动作记录未收口状态，不声明停写或安全备份，不扩大预算或抹去原任务状态

#### Scenario: 真实运行事件从耐久游标恢复

- **WHEN** 获授权调用方订阅精确运行版本，并从该运行已登记的 eventId 重连
- **THEN** 公开 reader 按耐久提交顺序每批最多返回 64 个后续事件引用，Outbox ack 和 API 重启不删除关联
- **AND** 关联只来自事件的显式精确运行引用或原 C06 持久因果引用，与原事件同事务登记；并发事务不得让较小序号迟提交后被游标跳过
- **AND** 未知、跨工程/运行/版本或当前不可读游标失败；每批返回前复验当前空间与来源权限，任何不可读事件使整批失败，不披露正文、内部序号或部分越权引用
- **AND** HTTP SSE 以订阅者当前会话逐事件签发精确来源范围，再由 reader 复验该身份；基础空来源授权不能被扩大，事件生产者的身份不能替代订阅者

### Requirement: 内网访问与观测必须有界且最小披露

系统 MUST 以受控 HTTPS 同源边界提供 Web、API 和 SSE，保持 C09 安全 Cookie、来源验证、耐久游标和背压语义；数据库、索引、模型、OCR 及宿主控制接口不得直接作为普通客户端访问入口。存活/就绪观测 MUST 区分进程存在、依赖可用、业务完整接线和维护状态；C35 健康/模型查询仍由当前系统管理员授权且保持既有条目和时间边界。日志、资源与容量指标 MUST 只包含稳定状态、原因码、引用和计数，设置有限保留，不泄露正文、秘密、URL、宿主路径、模型原始响应或思维链。

#### Scenario: 安全同源访问和重连

- **WHEN** 用户通过内网 HTTPS 登录、查询并断线重连运行订阅
- **THEN** Cookie 属性与来源校验保持，静态深链刷新和 SSE 游标恢复可用，客户端只能访问获准公开接口

#### Scenario: 依赖失败或正在维护

- **WHEN** 必需依赖不可用、业务接线不完整或实例正在停止写入
- **THEN** 就绪检查失败，管理查询如实报告安全状态，不将存活或未配置解释为全部正常

#### Scenario: 慢探针或无权查询

- **WHEN** 管理探针超时、返回非法结果，或普通用户请求系统运维事实
- **THEN** 超时按既有安全原因码收口，拒权与未提供能力保持安全失败，不扩大读取范围或披露内部存在性

### Requirement: 同机逻辑副本必须绑定同一停写边界及全部耐久事实

系统 MUST 以固定备份身份、批准配置和宿主维护权限进入三 VM 协调的维护窗口，确认 API 写入口、Worker、模型/OCR 派生结果提交与工件维护均已停止；停写不成立时禁止继续。同机逻辑副本（下文备份）MUST 绑定同一数据库/文件快照业务引用、每个工程的完整授权哈希清单、数据库全部业务/身份/审计/Outbox/checkpoint 事实、耐久工件以及对应部署配置。备份包和秘密保管必须分离、受限；无完整授权工程不得被静默跳过。逻辑恢复点可用结论 MUST 以副本完整性、隔离恢复核验和 PostgreSQL 只追加运维审计为前提，宿主阶段记录仅用于执行恢复，任何阶段失败只能形成失败或待核验状态。相同身份和输入重试复用原批次，异载荷不得替换已成立备份。

#### Scenario: 完整停写备份成立

- **WHEN** 全部写入者和维护者已收口，操作者获得全部目标工程的恢复级授权并完成同边界数据库与工件副本
- **THEN** 备份记录固定快照业务引用、精确清单、版本、时间和计数；隔离核验通过后才发布可用恢复点

#### Scenario: 停写失败或工程授权不完整

- **WHEN** 仍有未知写入者/在途写入，或任一目标工程、资料和工件未获完整授权
- **THEN** 整批备份失败，不输出部分成功恢复点、不默认授予系统管理员工程正文权限

#### Scenario: 复制、空间或耐久记录失败

- **WHEN** 数据库导出、工件复制、空间检查或最终记录耐久提交失败
- **THEN** 保留安全失败记录与未完成批次，原实例和已有恢复点保持，未完成包不进入可用目录

#### Scenario: 同键重试与异载荷冲突

- **WHEN** 操作者以同一备份身份重试相同输入，或改变目标发布、工程集合与配置
