## Execution Preconditions

开始以下 checkbox 前，主调度 Agent 必须已完成 proposal/design 所列依赖门：以冻结版本更新 `packages/core/package.json`、`packages/adapters/package.json`、根 `package.json`、`config/dependency-policy.json`、`pnpm-lock.yaml` 和两个 package 的 `./persistence`/`./postgres` exports，执行冻结安装、许可证/政策检查并形成 Git checkpoint。实现 worker 不安装依赖、不修改这些门控文件；若门未完成、版本变化或 C01/C02 契约需要变化，停止并交回主调度 Agent。
