## ADDED Requirements

### Requirement: C33 识别运行与风险记录只读必须有界且复验当前授权

系统 MUST 为风险识别域提供四类只读：运行列表按工程返回有界分页的识别运行条目（运行引用、状态、阶段、启动者、启动时间、验收/待复核/拒收计数；触发原因仅在有登记事实时输出，无登记事实时不得伪造）；运行详情按精确运行引用返回该运行的阶段进度（I0–I9）、工序工作项覆盖、合并组与验收路由摘要、关联 Agent 与复核任务引用及结果汇总；风险记录目录按工程返回有界分页的标准化风险记录条目（记录引用、工序节点、风险事件摘要、综合置信度、验收方式、当前效力），支持按工序节点与验收方式筛选；记录详情按精确记录版本引用返回该版本的识别侧正文（七字段、记录信封、证据定位、机理条目与资料来源引用、识别运行引用、验收决定与取代/作废关系）。列表页大小 MUST 有上界（不超过 50）并使用稳定游标；每条目 MUST 在返回前按当前授权复验工程可见性；无权、跨工程或不存在的目标 MUST 同形失败且不可枚举；返回内容 MUST 可由精确版本重放。该读面 MUST 由识别拥有方模块内部组合既有登记事实实现，不反写领域对象、不触发新识别、不调用模型。（RI-S5～RI-S6）

#### Scenario: 获授权调用方读取运行与记录

- **WHEN** 调用方在当前工程具备识别读能力并请求列表首页/游标页或精确详情
- **THEN** 返回有界条目或该精确版本正文，重复读取得到同一内容，不追加业务事实

#### Scenario: 越权或跨工程不可枚举

- **WHEN** 调用方请求其它工程的运行或记录、被撤销授权后再次请求，或引用不存在
- **THEN** 返回同形安全失败，不返回条数、名称或存在性线索

#### Scenario: 等待复核与失败状态如实呈现

- **WHEN** 运行处于等待复核或 Agent 可重试失败状态
- **THEN** 运行详情如实返回该状态、关联复核任务引用或失败阶段与错误码，已入库事实计数不回退，不把暂停或失败伪装为完成

### Requirement: C33 复核队列只读必须携带可决定的精确任务引用

系统 MUST 为复核域提供队列只读：按工程返回有界分页的复核任务条目，每条 MUST 携带完整 `ReviewTaskRefV1`（含复核类型、目标引用与等待运行引用）、复核类型、提交时间与状态；复核对象标签由调用方从目标引用确定性渲染；触发原因仅在有登记事实时输出，不得伪造；目标版本已被取代的任务 MUST 由拥有方计算并标记过期。队列 MUST 支持按复核类型与状态筛选，页大小有上界（不超过 50）并使用稳定游标；条目在返回前按当前授权复验；无权、跨工程或不存在 MUST 同形失败且不可枚举。该读面 MUST 由复核审计拥有方实现，只组合既有复核任务与决定登记事实，不反写、不代为决定。（RI-S6）

#### Scenario: 队列条目足以构造既有决定命令

- **WHEN** 获授权复核人读取队列页
- **THEN** 条目携带的完整任务引用可直接作为既有 `decide-review` 命令的 `reviewTaskRef`，无需第二次取数

#### Scenario: 过期任务显式标记

- **WHEN** 任务目标版本已被更新版本取代
- **THEN** 条目携带过期标记，调用方无需自行比对版本

#### Scenario: 越权或不存在同形失败

- **WHEN** 调用方无复核读能力、请求其它工程队列或游标指向不可见区段
- **THEN** 返回同形安全失败，不披露任务数量或类型分布
